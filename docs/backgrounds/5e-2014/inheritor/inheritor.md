## 特性详解

### 遗产

- 特性 ID：`background-2014-inheritor-feature`
- 动作或触发：由 DM 用作故事钩子。
- 资源与恢复：无。
- 效果：你独享一件重要遗物（d8 表：地图/信/日记等文件、信物、衣物、首饰、奥术书或配方、故事/歌谣/诗/秘密、纹身或身体印记）；DM 可决定其性质（可能为小魔法物品）。
- 实现与校验：叙事特性；遗物选择用 d8 表或自定，可作剧情钩子。

## 创建与校验

- 建议特征表沿用 PHB 民间英雄（Folk Hero）背景；按背景字段约定填写人物特征候选。
- 背景不提供属性提升或专长。
- 遗物性质需与 DM 确认（是否魔法物品）。
