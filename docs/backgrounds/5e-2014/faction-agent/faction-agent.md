## 特性详解

### 安全避难所

- 特性 ID：`background-2014-faction-agent-feature`
- 动作或触发：联络派系支持网络。
- 资源与恢复：无。
- 效果：掌握秘密暗号与手势，可识别并联络秘密支持者网络，获得隐藏安全屋、免费食宿或查找情报的帮助（线人不会为你冒生命危险或暴露身份）。
- 实现与校验：叙事特性，不进入数值计算。

## 创建与校验

- 建议特征表沿用 PHB 侍僧（Acolyte）背景（"faith/faction"互换）；按背景字段约定填写人物特征候选。
- 背景不提供属性提升或专长。
- 第二项技能需从智力/感知/魅力类技能中自选。
