## 特性详解

### 城市基础设施

- 特性 ID：`background-2014-izzet-engineer-feature`
- 动作或触发：获取建筑蓝图。
- 资源与恢复：无。
- 效果：通晓建筑结构，可设法取得特定建筑的蓝图以了解结构、入口弱点或密室（滥用后果自负，公会不保）。
- 实现与校验：叙事特性，不进入数值计算。

### 公会法术（Guild Spells）

- 特性 ID：`background-2014-izzet-engineer-spells`
- 前置：拥有施法（Spellcasting）或契约魔法（Pact Magic）特性。
- 资源与恢复：照常占用职业法术位，无额外恢复机制。
- 效果：把公会法术表中的法术加入你施法职业的法术列表。
- 公会法术（1 级）：混沌箭 chaos bolt、造水/毁水术 create or destroy water、隐形仆役 unseen servant；（2 级）灼热金属 heat metal、绳术 rope trick。
- 实现与校验：仅影响已知/准备法术来源；需校验施法前置。
