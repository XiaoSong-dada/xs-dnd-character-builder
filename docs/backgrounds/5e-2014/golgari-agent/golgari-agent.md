## 特性详解

### 地下城通路

- 特性 ID：`background-2014-golgari-agent-feature`
- 动作或触发：非战斗时带领队伍移动。
- 资源与恢复：无。
- 效果：知晓隐秘地下路线，非战斗时带领同伴在城市两点间移动速度加倍（路上仍有危险）。
- 实现与校验：叙事特性，不进入数值计算。

### 公会法术（Guild Spells）

- 特性 ID：`background-2014-golgari-agent-spells`
- 前置：拥有施法（Spellcasting）或契约魔法（Pact Magic）特性。
- 资源与恢复：照常占用职业法术位，无额外恢复机制。
- 效果：把公会法术表中的法术加入你施法职业的法术列表。
- 公会法术（1 级）：纠缠术 entangle、致伤射线 ray of sickness；（2 级）防毒护罩 protection from poison、衰弱射线 ray of enfeeblement、蛛行术 spider climb。
- 实现与校验：仅影响已知/准备法术来源；需校验施法前置。
