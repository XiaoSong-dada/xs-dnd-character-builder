# 骑士（Knight）

- 稳定 ID：`background-2014-noble-knight`

- 类型：贵族正式变体
- 获得等级：角色 1 级
- 来源：2014《玩家手册》
- 返回父项：[2014 贵族](noble.md)

## 继承与变化

骑士继承贵族的技能、工具和语言框架，但用“侍从”（Retainers）替换“优越地位”。角色拥有三名忠诚的非战斗随从，其中一人通常是贵族侍从，其余可负责马匹、装备或日常事务。

- 随从不会进入明显危险区域，也不是可免费操纵的战斗单位。
- 必须记录三名随从的身份、职责和关系。
- “侍从”与“优越地位”互斥，不能同时获得两个背景特性。

## 变体人物特征候选（项目原创）

- **人格特征（d8，选二）**：1. 我在进入房间前会先检查同伴是否准备妥当；2. 我把礼貌视作纪律的一部分；3. 我会认真维护武具和仪容；4. 我对公开承诺极为慎重；5. 我习惯替弱者站在危险一侧；6. 我会用战术语言描述日常安排；7. 我很少让别人看见疲惫；8. 我总想成为随从可以效仿的人。
- **理想（d6，选一）**：1. 荣誉——承诺比生命更重要（守序）；2. 守护——力量应当保护弱者（善良）；3. 忠诚——我不会抛弃领主与同伴（守序）；4. 正义——头衔不能成为作恶的盾牌（善良）；5. 荣耀——伟大功绩会证明我的价值（任意）；6. 改革——旧骑士制度也必须改变（混乱）。
- **羁绊（d6，选一）**：1. 我的随从是我真正的家人；2. 我必须恢复一支没落骑士团；3. 一位领主将性命托付给我；4. 我的徽记属于战死的导师；5. 我正护送某人完成危险使命；6. 我发誓查清旧日战败的真相。
- **缺点（d6，选一）**：1. 我会把个人荣誉置于团队安全之上；2. 我很难拒绝正式挑战；3. 我对没有纪律的人过于严厉；4. 我不愿让随从看见自己的错误；5. 我会盲目维护已经不值得效忠的人；6. 我把求助误认为软弱。
