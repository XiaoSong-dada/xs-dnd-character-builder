## 效果摘要与校验

角色过去的军衔会被所属或友好军事组织承认，可在合理范围内影响低阶士兵并获得军营或补给渠道。权限受军队、地区、战时状态和当前信誉限制。

创建时必须选择军中职责、组织、军衔和赌具。背景不自动提供武器、护甲熟练或 2024 凶蛮攻击者专长。

## 人物特征候选（项目原创）

- **人格特征（d8，选二）**：1. 我总会确认同伴是否准备妥当；2. 我用简短明确的话表达命令；3. 危险来临时，训练会先于恐惧接管身体；4. 我会把任何营地整理得井然有序；5. 我尊重经受过艰难考验的人；6. 我习惯在休息时玩一局熟悉的赌具；7. 我不会轻易谈论经历过的战场；8. 我总在观察队伍中谁需要支持。
- **理想（d6，选一）**：1. 责任——岗位必须有人坚守（守序）；2. 荣誉——胜利不能建立在卑劣行为上（善良）；3. 国家——我愿为家园承担危险（守序）；4. 独立——士兵不应成为权贵的工具（混乱）；5. 力量——只有绝对优势才能带来和平（邪恶）；6. 同袍——身边战友比任何旗帜重要（任意）。
- **羁绊（d6，选一）**：1. 我必须把阵亡同伴的遗物送回家；2. 旧部队仍是我最亲近的家人；3. 一位长官曾替我承担严重后果；4. 我发誓查明某场战败的真实原因；5. 我一直保护战争中的幸存者；6. 我的军徽提醒我不能再次逃避责任。
- **缺点（d6，选一）**：1. 我很难违抗穿制服的权威；2. 我把所有问题都看成敌我冲突；3. 突然的声响会唤起难以控制的反应；4. 我对缺乏纪律的人非常刻薄；5. 我不愿承认自己需要休息或帮助；6. 我仍对昔日敌人抱有不加区分的仇恨。
