# 间谍（Spy）

- 稳定 ID：`background-2014-criminal-spy`
- 规则集：`5e-2014`
- 类型：罪犯正式变体
- 获得等级：角色 1 级
- 来源：2014《玩家手册》
- 返回父项：[2014 罪犯](criminal.md)

## 继承与变化

间谍继承罪犯的技能、工具、装备框架和“犯罪关系”特性，主要改变人物的叙事身份：联系人可以属于情报网、宫廷、军队或秘密组织，犯罪专长改写为谍报职责。

- 不与罪犯再叠加一套熟练、装备或背景特性。
- 必须记录所属组织、联系人和掩护身份；这些内容不自动赋予虚假身份特性。
- 选择 `background-2014-criminal-spy` 时，父 ID 仅用于继承，不作为第二个已选背景。

## 变体人物特征候选（项目原创）

- **人格特征（d8，选二）**：1. 我会本能地留意谁在偷听；2. 我从不在同一场合说出全部真相；3. 我能迅速模仿目标群体的礼节；4. 我习惯用暗号确认熟人的身份；5. 即使与朋友交谈，我也会控制表情；6. 我会把每个房间记成一张路线图；7. 我总在判断别人掌握了多少信息；8. 平静生活反而会令我不安。
- **理想（d6，选一）**：1. 忠诚——任务和组织高于个人安危（守序）；2. 真相——秘密终究应该被揭开（善良）；3. 平衡——情报能阻止更大的战争（中立）；4. 自由——任何机构都无权拥有我的思想（混乱）；5. 权力——掌握秘密就掌握主动（邪恶）；6. 弥补——我要用现在的任务偿还过去的背叛（任意）。
- **羁绊（d6，选一）**：1. 我的联络人是唯一知道真实身份的人；2. 一份未送达的情报可能改变许多人的命运；3. 我必须保护仍被当作掩护的家庭；4. 敌方特工曾放过我一次；5. 我的组织掌握着我不能失去的秘密；6. 我正在寻找一名失踪的旧搭档。
- **缺点（d6，选一）**：1. 我把每个人都当成潜在威胁；2. 为了维持身份，我可能伤害真正的朋友；3. 我过度相信自己的判断；4. 我无法容忍秘密不在掌控中；5. 一听到旧暗号，我就会冲动行动；6. 我已经分不清哪些情感属于真实的自己。
