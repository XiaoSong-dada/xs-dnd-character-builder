## 特性详解

### 虚假身份

- 特性 ID：`background-2014-dimir-operative-feature`
- 动作或触发：以伪装身份活动。
- 资源与恢复：无。
- 效果：你以另一个公会成员的身份生活，持有配套证件、熟识与伪装（可随时放弃该身份混入无公会人群）。
- 实现与校验：叙事特性，不进入数值计算。

### 公会法术（Guild Spells）

- 特性 ID：`background-2014-dimir-operative-spells`
- 前置：拥有施法（Spellcasting）或契约魔法（Pact Magic）特性。
- 资源与恢复：照常占用职业法术位，无额外恢复机制。
- 效果：把公会法术表中的法术加入你施法职业的法术列表。
- 公会法术（1 级）：易容术 disguise self、睡眠术 sleep；（2 级）侦测思想 detect thoughts、行踪无痕 pass without trace。
- 实现与校验：仅影响已知/准备法术来源；需校验施法前置。
