## 效果摘要与校验

普通民众通常愿意为被视作自己人的角色提供藏身、休息或朴素帮助，只要角色没有给他们带来明显危险。该特性依赖关系与情境，不是强制所有平民服从。

创建时必须选择成名事件和具体工匠工具。熟练来源重复时按 2014 替换规则处理，背景本身没有属性提升或专长。

## 人物特征候选（项目原创）

- **人格特征（d8，选二）**：1. 我更相信行动，而不是漂亮话；2. 看见有人陷入困难，我会立刻帮忙；3. 一旦答应事情，我会坚持到底；4. 我总想找到对所有人最公平的办法；5. 我擅长鼓励身边的人；6. 我宁愿先动手解决，再慢慢思考；7. 我偶尔会误用复杂词语来显得有学问；8. 平静太久时，我会担心自己错过了使命。
- **理想（d6，选一）**：1. 尊严——普通人也值得被认真对待（善良）；2. 公正——权贵不能凌驾于规则之上（守序）；3. 自由——暴政必须受到反抗（混乱）；4. 力量——只有强者才能夺回应得之物（邪恶）；5. 真诚——我不愿假装成另一个人（中立）；6. 命运——我相信自己肩负着更大的责任（任意）。
- **羁绊（d6，选一）**：1. 我一直在寻找失散的家人；2. 我深爱故乡的土地并会保护它；3. 我不会忘记曾欺压乡民的权贵；4. 旧工具提醒我永远不要忘记出身；5. 我发誓保护无法保护自己的人；6. 我希望有一天能与昔日爱人重逢。
- **缺点（d6，选一）**：1. 过去的敌人一直在追捕我；2. 我过分相信所谓的命运；3. 故乡的人知道一个令我羞愧的秘密；4. 城市中的享乐很容易让我沉迷；5. 我有时觉得由自己掌权会比现在更好；6. 我很难完全相信新盟友。
