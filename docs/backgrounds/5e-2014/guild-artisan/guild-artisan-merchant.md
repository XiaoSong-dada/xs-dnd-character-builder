# 行会商人（Guild Merchant）

- 稳定 ID：`background-2014-guild-artisan-merchant`
- 规则集：`5e-2014`
- 类型：行会工匠正式变体
- 获得等级：角色 1 级
- 来源：2014《玩家手册》
- 返回父项：[2014 行会工匠](guild-artisan.md)

## 继承与变化

角色属于商人、公会或贸易组织，而非以亲手制造商品为主。继承洞悉、游说和“行会会员”，并按变体规则用领航工具或额外语言等贸易能力替换工匠取向的选项，装备也改为商旅主题。

- 替换项不能与父背景对应项同时领取。
- 必须记录贸易种类、所属组织及最终工具或语言选择。
- 行会关系提供合理支持和联系，不自动给予商品、商队或无限信用。

官方入口：[2014 Player’s Handbook](https://www.dndbeyond.com/sources/dnd/phb-2014)
