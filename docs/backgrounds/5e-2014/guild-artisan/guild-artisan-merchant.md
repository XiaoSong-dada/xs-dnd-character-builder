# 行会商人（Guild Merchant）

- 稳定 ID：`background-2014-guild-artisan-merchant`
- 规则集：`5e-2014`
- 类型：行会工匠正式变体
- 获得等级：角色 1 级
- 来源：2014《玩家手册》
- 返回父项：[2014 行会工匠](guild-artisan.md)

## 继承与变化

角色属于商人、公会或贸易组织，而非以亲手制造商品为主。继承洞悉、游说和“行会会员”，并按变体规则用领航工具或额外语言等贸易能力替换工匠取向的选项，装备也改为商旅主题。

- 替换项不能与父背景对应项同时领取。
- 必须记录贸易种类、所属组织及最终工具或语言选择。
- 行会关系提供合理支持和联系，不自动给予商品、商队或无限信用。

## 变体人物特征候选（项目原创）

- **人格特征（d8，选二）**：1. 我能迅速估算一件货物的销路；2. 我喜欢与陌生人交换旅行消息；3. 每次谈判前，我都会先建立私人关系；4. 我习惯记录每一笔债务；5. 我总能为多余货物想出用途；6. 我认为准时比华丽承诺更重要；7. 我会把旅途中的见闻讲成生意经；8. 我很难经过市场而不进去看看。
- **理想（d6，选一）**：1. 诚信——信誉比一次利润更长久（守序）；2. 开放——贸易能让不同文化彼此理解（善良）；3. 机会——财富属于敢于行动的人（混乱）；4. 公平——双方都受益才是好交易（善良）；5. 扩张——我的商号终将遍布各地（邪恶）；6. 独立——我不愿受任何领主控制（任意）。
- **羁绊（d6，选一）**：1. 我必须让家族商号恢复名誉；2. 一支失踪商队载着我最重要的人；3. 老顾客曾在危机中救过我；4. 我欠某座港口一笔巨大债务；5. 一张旧路线图可能通往失落市场；6. 我的第一枚利润硬币一直随身携带。
- **缺点（d6，选一）**：1. 我会为利润淡化危险；2. 我不愿承认自己做了亏本买卖；3. 我总怀疑别人想占便宜；4. 稀缺商品会让我失去判断；5. 我把友情也记成了账目；6. 我常许下超出能力的交货承诺。
