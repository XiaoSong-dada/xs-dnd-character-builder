## 特性详解

### 家族人脉（House Connections）

- 特性 ID：`background-2014-house-agent-feature`
- 状态：selectable
- 效果：作为家族的代理人，你总能在家族的飞地获得食宿，你同行的伙伴们也能受益。当家族给你指派任务时，通常会提供必要的物资和交通工具。此外你在家族中有许多旧友、导师和竞争对手，与家族业务打交道时可能遇到他们；他们是否愿意提供帮助，取决于你目前在家族中的地位。属情境社交能力，不进入自动计算。
