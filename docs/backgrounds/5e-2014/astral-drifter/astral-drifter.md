## 完整说明

- 特性 ID：`background-2014-astral-drifter-feature`

- 效果：按原书获得《玩家手册》中的「魔法学徒」专长（施法职业须选牧师）（按原书可自选一位神祇并取得对应的一环法术能力）。该项目按原书为专长授予：该专长已登记为规则条目并由本背景自动授予，效果见专长条目。另有「长寿」提示：实际年龄比外表年长 20d6 岁。
