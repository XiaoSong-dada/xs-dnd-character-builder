## 特性详解

### 法律权威（Legal Authority）

- 特性 ID：`background-2014-inquisitor-feature`
- 状态：dm-only
- 效果：作为教会的审判官，你有权逮捕罪犯。如果没有其他当权者，你有权进行审判，甚至执行判决。然而若你滥用这种力量，你教会的上司可能剥夺你的权利。试行内容（异界传送 Plane Shift），需 DM 同意；属情境社交能力，不进入自动计算。
