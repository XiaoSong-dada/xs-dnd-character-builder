# 角斗士（Gladiator）

- 稳定 ID：`background-2014-entertainer-gladiator`
- 规则集：`5e-2014`
- 类型：艺人正式变体
- 获得等级：角色 1 级
- 来源：2014《玩家手册》
- 返回父项：[2014 艺人](entertainer.md)

## 继承与变化

角斗士把公开战斗视为表演。它继承艺人的技能与“广受欢迎”特性，但表演节目改为竞技项目；工具和装备中的乐器位置可按变体规则换成适合竞技形象的项目。

- 变体提供的是替换，不是额外获得第二种表演装备。
- 角斗士背景本身不自动给予护甲、武器或武器熟练；这些仍由职业等来源决定。
- 必须保存竞技项目、标志性道具和替换结果。

## 变体人物特征候选（项目原创）

- **人格特征（d8，选二）**：1. 我会在战斗前向观众致意；2. 我把伤疤视作职业履历；3. 我总能判断人群期待怎样的结局；4. 我习惯用夸张动作震慑对手；5. 我尊重能公平战斗的人；6. 我会给每一种招式取响亮名字；7. 没有观众时，我反而不知如何表现；8. 我在日常争论中也像面对竞技场一样认真。
- **理想（d6，选一）**：1. 荣誉——胜利必须经得起质疑（守序）；2. 生存——活着离开才是唯一重要的事（中立）；3. 荣耀——我要成为最受传颂的冠军（任意）；4. 解放——没人应该被迫为娱乐流血（混乱）；5. 技艺——竞技应证明训练而非残酷（守序）；6. 团结——共同作战的人就是家人（善良）。
- **羁绊（d6，选一）**：1. 我必须击败曾羞辱我的冠军；2. 一名训练师把我从死亡边缘救回；3. 我仍在保护昔日同队的斗士；4. 我的标志性道具属于一位故人；5. 我答应过某个孩子会再次凯旋；6. 我必须揭露竞技场背后的操纵者。
- **缺点（d6，选一）**：1. 我无法拒绝公开挑战；2. 我把喝彩看得比安全重要；3. 我对退缩的人缺乏耐心；4. 我常低估没有名气的对手；5. 我会把普通冲突升级成较量；6. 失败会让我不顾一切寻求复赛。
