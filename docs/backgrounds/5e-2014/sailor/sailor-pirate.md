# 海盗（Pirate）

- 获得等级：角色 1 级

- 返回父项：[2014 水手](sailor.md)

## 继承与变化

海盗继承水手的技能、工具与装备框架，但以“恶名”（Bad Reputation）替换“船只通行”。一般人可能因角色名声而回避冲突或容忍轻微不当行为，但执法者、强敌和不惧海盗者不受保证。

- “恶名”不是法律豁免、恐惧状态或自动检定成功。
- 必须记录海盗船、职责和恶名来源。
- 不能同时获得“船只通行”和“恶名”。

## 变体人物特征候选（项目原创）

- **人格特征（d8，选二）**：1. 我会把每次谈判都看成登船前的试探；2. 我喜欢用恶名先替自己开路；3. 我从不背对不熟悉的人；4. 我会公平分配共同夺得的东西；5. 我总能讲出比真实经历更离奇的故事；6. 我把旧伤和通缉令都当作荣誉；7. 我尊重敢于反抗的人；8. 我不喜欢别人碰我的私人箱子。
- **理想（d6，选一）**：1. 自由——没有王冠能统治海面（混乱）；2. 规矩——即使海盗也必须遵守分赃原则（守序）；3. 恐惧——让敌人害怕比杀死他们更有用（邪恶）；4. 财富——冒险只为下一批宝藏（中立）；5. 忠诚——船员就是我选择的家人（善良）；6. 改过——我要证明恶名不是我的全部（任意）。
- **羁绊（d6，选一）**：1. 我的旧船仍被仇敌占据；2. 我把宝藏埋在只有自己知道的地方；3. 一名旧船员掌握着我的真实过去；4. 我必须报答曾隐藏我的港口居民；5. 我发誓为被背叛的船长复仇；6. 我正寻找一面象征自由的旧旗。
- **缺点（d6，选一）**：1. 我会用威胁代替本可成功的交涉；2. 我无法容忍别人质疑自己的胆量；3. 我总认为规则只适用于别人；4. 宝藏传闻会让我忽略明显陷阱；5. 我会因旧日恶名迁怒无关者；6. 我很难相信没有共同冒险过的人。
