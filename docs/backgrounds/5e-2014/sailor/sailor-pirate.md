## 继承与变化

海盗继承水手的技能、工具与装备框架，但以“恶名”（Bad Reputation）替换“船只通行”。一般人可能因角色名声而回避冲突或容忍轻微不当行为，但执法者、强敌和不惧海盗者不受保证。

- “恶名”不是法律豁免、恐惧状态或自动检定成功。
- 必须记录海盗船、职责和恶名来源。
- 不能同时获得“船只通行”和“恶名”。
