# 罪犯（Criminal）

- 稳定 ID：`background-2024-criminal`
- 规则集：`5e-2024`
- 获得等级：角色 1 级
- 来源：2024 Free Rules、SRD 5.2.1
- 内容边界：开放规则，采用项目原创表述整理到实现级
- 返回：[背景总索引](../../../dnd-backgrounds.md)

## 定位与必选项

角色曾依靠盗窃、潜入或地下社会关系谋生。叙事身份可以改写为抵抗组织成员或调查者，但规则字段不随叙事自动变化。

| 字段 | 内容 |
| --- | --- |
| 属性候选 | 敏捷、体质、智力 |
| 属性分配 | 候选中的一项 `+2`、另一项 `+1`，或三项各 `+1` |
| 起源专长 | 警觉（Alert） |
| 技能熟练 | 巧手、隐匿 |
| 工具熟练 | 盗贼工具 |
| 装备 | 2 把匕首、盗贼工具、撬棍、2 个小包、旅行服和 16 GP；或 50 GP |

## 效果与实现校验

- 警觉专长会影响先攻，并允许在满足条件时与自愿盟友交换先攻；先攻加值应标记来源，交换属于战斗内动作而非永久数值。
- 盗贼工具熟练不等同于自动成功开锁，也不自动给予巧手检定专精。
- 属性提升只能落在敏捷、体质和智力，最终值不得超过 20。
- 装备包与 50 GP 二选一，禁止两者同时领取。

## 兼容边界

不要自动获得 2014 罪犯的“犯罪关系”特性或间谍变体。旧版转换必须使用显式兼容流程。
