# 学者（Sage）

- 稳定 ID：`background-2024-sage`
- 规则集：`5e-2024`
- 获得等级：角色 1 级
- 来源：2024 Free Rules、SRD 5.2.1
- 内容边界：开放规则，采用项目原创表述整理到实现级
- 返回：[背景总索引](../../../dnd-backgrounds.md)

## 定位与必选项

角色曾在图书馆、庄园或修道院间求学，对历史和奥术知识有系统了解。选择时必须完成属性分配及魔法学徒的法术和施法属性选择。

| 字段 | 内容 |
| --- | --- |
| 属性候选 | 体质、智力、感知 |
| 属性分配 | 候选中的一项 `+2`、另一项 `+1`，或三项各 `+1` |
| 起源专长 | 魔法学徒（法师） |
| 技能熟练 | 奥秘、历史 |
| 工具熟练 | 书法工具 |
| 装备 | 长棍、书法工具、历史书、8 张羊皮纸、长袍和 8 GP；或 50 GP |

## 效果与实现校验

- 魔法学徒（法师）给予两项法师戏法和一项 1 环法师法术，并需要选择合法施法属性。
- 1 环法术的长休免费施放与法术位施放是两种资源路径；戏法不消耗法术位。
- 属性提升只可落在体质、智力和感知，最终值不得超过 20。
- 装备包与 50 GP 互斥，所有法术和熟练必须保留背景来源。

## 选择提示

非常适合希望提高智力并取得知识技能的法师、游荡者或其他学术型角色，也可以为非施法职业提供少量奥术。
