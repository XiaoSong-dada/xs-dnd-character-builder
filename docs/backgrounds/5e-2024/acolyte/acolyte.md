# 侍僧（Acolyte）

- 稳定 ID：`background-2024-acolyte`
- 规则集：`5e-2024`
- 获得等级：角色 1 级
- 来源：2024 Free Rules、SRD 5.2.1
- 内容边界：开放规则，采用项目原创表述整理到实现级
- 返回：[背景总索引](../../../dnd-backgrounds.md)

## 定位与必选项

角色曾在神殿、教团或圣地服务，学习仪式、宗教知识与少量神术。选择时必须完成属性加值分配，并处理起源专长中的法术选择。

| 字段 | 内容 |
| --- | --- |
| 属性候选 | 智力、感知、魅力 |
| 属性分配 | 候选中的一项 `+2`、另一项 `+1`，或三项各 `+1` |
| 起源专长 | 魔法学徒（牧师） |
| 技能熟练 | 洞悉、宗教 |
| 工具熟练 | 书法工具 |
| 装备 | 书法工具、祷文书、圣徽、10 张羊皮纸、长袍和 8 GP；或 50 GP |

## 效果与实现校验

- 魔法学徒（牧师）给予两项牧师戏法和一项 1 环牧师法术；必须记录法术、施法属性、免费施放次数与来源。
- 免费施放的 1 环法术在长休后恢复，也可使用适当法术位施放；不能把“已准备”“免费次数”和“法术位”混为一项状态。
- 两项属性加值不能落在同一属性，最终属性不得超过 20。
- 背景熟练与职业等来源重复时不能重复增加熟练加值，应进入重复处理流程。

## 选择提示

适合希望强化智力、感知或魅力，并希望在 1 级获得少量神术能力的角色。侍僧不要求角色拥有牧师职业。

## 兼容边界

不要与 `background-2014-acolyte` 的语言、装备和“信徒庇护”背景特性叠加。旧版侍僧转换到 2024 时应使用旧背景兼容流程，而不是同时选择两个侍僧条目。
