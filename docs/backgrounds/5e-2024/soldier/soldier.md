# 士兵（Soldier）

- 稳定 ID：`background-2024-soldier`
- 规则集：`5e-2024`
- 获得等级：角色 1 级
- 来源：2024 Free Rules、SRD 5.2.1
- 内容边界：开放规则，采用项目原创表述整理到实现级
- 返回：[背景总索引](../../../dnd-backgrounds.md)

## 定位与必选项

角色接受过军事训练并有战场经历。选择时要决定具体赌具，并完成力量、敏捷、体质三项候选中的属性分配。

| 字段 | 内容 |
| --- | --- |
| 属性候选 | 力量、敏捷、体质 |
| 属性分配 | 候选中的一项 `+2`、另一项 `+1`，或三项各 `+1` |
| 起源专长 | 凶蛮攻击者（Savage Attacker） |
| 技能熟练 | 运动、威吓 |
| 工具熟练 | 一种自选赌具 |
| 装备 | 长矛、短弓、20 支箭、所选赌具、医疗包、箭袋、旅行服和 14 GP；或 50 GP |

## 效果与实现校验

- 凶蛮攻击者每回合限定一次，只在武器攻击命中并结算武器伤害骰时提供重掷式选择；不能复制额外修正或附加伤害骰。
- 赌具必须保存具体种类，不能只记录“任意赌具”这一未完成状态。
- 属性提升只可落在力量、敏捷和体质，最终值不得超过 20。
- 装备包与 50 GP 互斥，弓箭与箭袋均应作为独立物品记录。
