## 玩法定位与创建选择

2014 侏儒提供智力和对魔法心智豁免的防护。创建时必须选择森林侏儒或岩石侏儒。

## 特性详解

### 1级：属性提升

- 特性 ID：`race-2014-gnome-ability-score-increase`
- 动作或触发：创建角色。
- 资源与恢复：无。
- 效果：智力 +2。
- 实现与校验：标记基础种族来源并叠加子种族加值。

### 1级：黑暗视觉

- 特性 ID：`race-2014-gnome-darkvision`
- 动作或触发：常驻。
- 资源与恢复：无。
- 效果：60 尺黑暗视觉。
- 实现与校验：使用 2014 视觉规则。

### 1级：侏儒狡黠

- 特性 ID：`race-2014-gnome-gnome-cunning`
- 动作或触发：对魔法产生的智力、感知或魅力豁免。
- 资源与恢复：无。
- 效果：相应豁免具有优势。
- 实现与校验：必须同时满足属性范围与魔法来源；非魔法豁免不享受优势。
