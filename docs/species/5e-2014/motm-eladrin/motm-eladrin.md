# 雅灵（多元宇宙） - 5e-2014

## 来源与基础

- 独立主种族 `race-2014-motm-eladrin`；Eladrin；来源 `motm-2022-index`。
- 生物类型：类人生物，亦视为精灵；类型相关目标条件仅提示。
- 本地 CHM 1769 与创建总则1771；商业内容只保留必要元数据及原创机械摘要。
- 不继承旧版父项，不覆盖旧种族、2024物种或其特性ID。
- 体型：中型；步行30尺；黑暗视觉60尺。
- 属性任选不同两项+2/+1或三项各+1，最高20；通用语加一门自选语言。

固定技能：`skill-perception`，同类熟练不叠加。

## 必选与依赖

选择存入现有 `selections`，在时间线收集；按等级、父选择、候选和来源统一校验。失效原值保留但停用。

- `race-2014-motm-eladrin-season`：1级，选择季节；改变季节需完成4小时出神长休；玩家确认条件后调整。
- `race-2014-motm-eladrin-fey-step-ability`：1级，妖精步能力属性；妖精步能力属性

季节与智力/感知/魅力选择都有效才授予妖精步资源及季节附加特性；缺选或非法属性仍保留原始选择，但不输出对应收益。季节具体选项在两页面与导出中展示。
