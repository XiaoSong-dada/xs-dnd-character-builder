## 特性详解

### 1级：动物强化（1 级选择）

- 特性 ID：`race-2014-simic-hybrid-animal-enhancement-1`
- 动作或触发：创建角色时选择。
- 资源与恢复：无。
- 效果（三选一）：
  - 蝠鲼滑翔：坠落伤害最多减免 100 尺，每坠落 1 尺可水平滑翔 2 尺；
  - 攀爬能手：攀爬速度 = 步行速度；
  - 水下适应：可水中呼吸，游泳速度 = 步行速度。
- 实现与校验：选择不可更换；速度类效果按移动方式注册。

### 5级：动物强化（5 级选择）

- 特性 ID：`race-2014-simic-hybrid-animal-enhancement-5`
- 动作或触发：5 级时选择；酸液喷吐为动作。
- 资源与恢复：酸液喷吐次数 = 体质调整值（至少 1），长休恢复。
- 效果（三选一）：
  - 抓握附肢：天然武器 1d6 + 力量调整钝击，命中后可附赠动作擒抱；不能用于武器/精细操作；
  - 甲壳：未穿重甲时 AC +1；
  - 强酸喷吐：30 尺内单目标，DC = 8 + 熟练 + 体质调整，2d10 强酸伤害（11 级 3d10、17 级 4d10）。
- 实现与校验：5 级选择与 1 级选择互相独立；次数随长休恢复。
