## 特性详解

### 1级：猫之敏捷

- 特性 ID：`race-2014-tabaxi-feline-agility`
- 动作或触发：移动时选择（无动作消耗）。
- 资源与恢复：使用后，必须有一个回合移动 0 尺，之后才能再次使用。
- 效果：本回合内速度翻倍（含步行与攀爬等移动方式）。
- 实现与校验：翻倍作用于当前速度；不与其他速度加值重复翻倍。
