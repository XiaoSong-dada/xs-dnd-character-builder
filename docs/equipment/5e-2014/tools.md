## 备注

- 代码中现有的 `artisan-tools`（一套工匠工具）、`gaming-set`（一套赌具）、`musical-instrument`（一件乐器）、`con-tools`（一种行骗工具）是背景起始装备用的**笼统条目**；PHB 具体工具条目（上表 `pending` 部分）为"添加物品"内置库补全批次的目标，补全后笼统条目保留用于背景装备场景。
- 工具的"熟练"授予（熟练一项工具）与使用检定规则属规则层后续批次。
