- **类型**：新＝2024 全新子职；修订＝2014 子职的 2024 版本。
- **有效期次**：同概念取最新一期，详见 [来源与修订映射](来源与修订映射.md) §3。
- **状态**：`待核验`→`已核对`→`已闭合`→`已接入`；本表初始为 `待核验`。
- **批次**：对应 [分批 TODO 计划](../2024扩展内容引入-TODO计划.md)。

## 4. 实施注意

1. 每条子职实施时必须登记等级节点、必选项、互斥、资源与派生影响；不能只在 `subclasses-2024.ts` 增加标题。
2. 修订类子职（对应 2014 条目）在实现时逐条比对机制差异，不复制 2014 数据、不隐式共享 ID。
3. 破誓者为 DM 选项语义，不进入普通玩家默认候选。
4. 有效期次以 [来源与修订映射](来源与修订映射.md) §3 为准；旧期次不生成候选。
5. 名称以 CHM 目录为准，译名差异见 [来源与修订映射](来源与修订映射.md) §4。
