# 角色卡导出需求（PDF / XLSX / JSON）

> 状态：需求与路线已确认（2026-08-20 用户确认），进入实施准备阶段；模板调研与归档已完成。
> 已确认决策摘要：角色卡必须中文；PDF 采用自绘中文版面（print CSS）；XLSX 采用 exceljs 自生成；仅中文；免费工具；导出入口仅角色卡页内，个人中心暂不开发。详见「7. 已确认决策」。

## 1. 背景与目标

用户需要：角色完成后点击「导出」，可以导出 **PDF 角色卡 / XLSX 自动计算卡 / JSON 数据文件**，便于线下跑团打印、在 Excel 中继续编辑或备份迁移。

目标产物：

- 一份已核验的免费模板清单，模板文件归档到 `docs/export-templates/`（本阶段已完成）。
- 一份可执行的需求文档：三种导出格式的需求项、技术路线对比、授权合规边界、验收标准。
- 需求与路线决策记录：PDF 版面来源、XLSX 生成方式、语言版本均已确认（见「7. 已确认决策」）。

## 2. 现状调查（已核验）

### 2.1 JSON 导出（已有，无需模板）

- `app/src/services/character-json.ts` 已提供 `CharacterJsonService.exportDraft / importDraft`，schemaVersion 3，含错误码与中文提示，规则集限制 `5e-2014`。
- 结论：JSON 导出能力已存在，本需求仅评估是否补入口与文件命名，不涉及模板。

### 2.2 PDF / XLSX 导出（当前无）

- 项目 README 明确「当前未包含 PDF 导出」；`src/services` 无 xlsx/pdf 相关模块。
- 角色卡预览（`CharacterSheetStep.vue`）已有完整的中文版面与派生数值展示，是 PDF 版面的事实数据源。

### 2.3 免费模板调研结论（全部实际联网核验，2026-08 核查）

### 2.4 关键结论

- **PDF 官方模板可用**：官方 2014 填表 PDF 带表单字段，pdf-lib 可填；但版面为英文、A4/信件纸，字段名需逆向导出。
- **XLSX 开源模板可用**：DRA6N 的 xlsm 是 MIT 协议，含公式自动计算；但浏览器端写 xlsx 不保留 VBA 宏，需验证公式保留情况。
- **中文方案空白**：官方无简体中文填表 PDF；自绘版面（参考 MIT 打印卡 + 现有中文角色卡组件）是唯一零授权风险的中文路线。
- **版权底座**：SRD 5.1 为 CC BY 4.0，卡面字段、数据口径均可基于它设计并署名。

## 3. 需求项

### R1 JSON 导出（已有，补齐入口）

- 在导出菜单中提供「导出 JSON」，复用 `CharacterJsonService.exportDraft`，文件名为 `角色名-dnd5e-v3.json`（含 schemaVersion 后缀便于识别）。
- 不改变 schema、不改导入逻辑；2024 旧草稿继续走现有只读隔离导出路径。

### R2 PDF 导出（路线已确认：自绘中文 print CSS）

导出内容（数据范围）：

1. 基础信息：角色名、职业（等级）、种族/出身、玩家名、阵营、经验值；
2. 六项属性与调整值、熟练加值、被动感知；
3. 生命值、AC、先攻、速度；
4. 技能熟练/专精列表；
5. 攻击与法术攻击、法术豁免 DC、法术位摘要；
6. 已选法术（按环级分组，与角色卡页签一致）；
7. 背包与金币、特性速览；
8. 数值必须与页面派生结果一致（同一派生函数输出）。

实现要点（已确认走自绘路线）：

1. 新增独立打印版面组件（中文），复用规则层派生函数，数值与页面一致；
2. 通过 `@media print` 样式 + `window.print()` 输出 PDF（A4），不引入 pdf-lib、不携带官方 PDF 模板；
3. 官方 2014 填表 PDF（`docs/export-templates/`）仅作为版面参考底稿，不进入运行时；
4. 中文打印字体兼容（系统字体 + 打印预览检查）；
5. 未确认选择的角色不允许导出（复用现有校验）。

> 曾评估的路线 A（官方英文填表 PDF + pdf-lib 填充）已否决：英文版面不符合「角色卡必须中文」，且官方 PDF 仅个人使用授权。

### R3 XLSX 自动卡导出（路线已确认：exceljs 自生成）

1. 新增 exceljs 依赖，自生成 `.xlsx`（非 `.xlsm`，浏览器端不保留宏）；
2. 中文工作表与列名；版面参考 DRA6N MIT 模板的字段组织（六属性自动调整值、熟练加值、技能列表、HP/AC 派生、法术位）；
3. 数值复用规则层派生函数，与页面一致；公式保留「值 + 来源」可读性，不要求 Excel 内重算所有派生；
4. 需验证：Excel / WPS / LibreOffice 打开兼容性、中文无乱码、列宽与冻结表头。

> 曾评估的路线 B（以 DRA6N xlsm 为底稿填充）已否决：英文版面不符合中文要求，且浏览器端填充 xlsm 的宏/公式保留风险高。

## 4. 非目标与边界

- 不引入后端服务；导出全部在浏览器端完成。
- 不做多职业、2024 规则导出（当前仅 5e-2014 单职业）。
- 不复制官方模板的版权设计资产用于商业发布；本产品为免费工具，运行时模板仅用自绘与 MIT 参考，不采用官方 PDF（见「7. 已确认决策」）。
- 不开发个人中心导出入口（仅角色卡页内导出）。
- 不导出 DM 房规、未完成的半成品草稿（仅导出通过校验或显式确认的角色）。
- 中文社区角色卡 PDF 授权不明，本阶段不采用。

## 5. 涉及模块与依赖方向（实施时以最终路线为准）

```text
导出入口（角色卡页内）
  -> services/character-json（已有，JSON）
  -> 打印版面组件（R2 自绘中文）+ @media print 样式 + window.print()
  -> services/export-xlsx（新增，exceljs）
  -> rules/derive + rules/repository（唯一数值事实源）
```

- 新增 `src/services/export-xlsx.ts`；PDF 路线不新增导出服务，只新增打印版面组件与打印样式；依赖方向不变（services 不反向依赖 views）。
- 模板归档位置 `docs/export-templates/` 为调研与版面参考底稿，**不进入运行时**（已确认自绘路线，无需复制到 `app/public/templates/`）。
- 新增依赖（exceljs）需按项目约定评估浏览器环境适配（worker 中也可用）；不引入 pdf-lib。

## 6. 验收标准（实施阶段生效）

1. 三种导出入口在手机宽度下可操作；导出文件名含角色名与版本标记。
2. PDF：打印预览在 A4 下完整、中文无乱码，关键字段与页面一致。
3. XLSX：打开后属性调整值、熟练加值、HP/AC、法术位等值与页面一致；中文无乱码。
4. JSON：导出文件可被 `CharacterJsonService.importDraft` 原样导入，schemaVersion 不变。
5. `pnpm test`、`pnpm build` 通过；新增导出服务的单元测试覆盖数值一致性与非法角色拒绝导出。
6. 授权合规：产物内/说明内满足署名要求（CC BY 4.0 署名 SRD、MIT 保留版权声明）；运行时模板仅自绘，不携带官方 PDF。

## 7. 已确认决策（2026-08-20 用户确认）

| # | 决策点 | 最终决定 |
|---|---|---|
| 7.1 | PDF 路线 | **自绘中文 print CSS**（路线 B）；官方英文填表 PDF 仅作版面参考底稿 |
| 7.2 | XLSX 路线 | **exceljs 自生成**（路线 A）；DRA6N xlsm 仅作字段组织参考 |
| 7.3 | 语言 | **仅中文**，角色卡必须中文 |
| 7.4 | 商用属性 | **免费个人工具**；运行时模板仅用自绘与 MIT 参考，不采用官方 PDF |
| 7.5 | 导出入口 | **仅角色卡页内**；个人中心导出暂不开发 |

以上决策已落实到 R1—R3 需求项与「4. 非目标与边界」。实施时不再变更上述路线；如实现中发现某条路线不可行，先更新本文档再调整。

## 6a. 实施状态（2026-08-20 登记）

- R1 JSON 导出入口：已实现——角色卡页底部「导出」弹层菜单提供 PDF / XLSX / JSON 三项；JSON 项复用 `CharacterJsonService.downloadDraft`（`emit('export')` → `exportDraft`），文件名 `角色名-<id>.json`，schema 与导入逻辑未改动；2024 旧草稿继续走只读隔离导出路径。
- R2 PDF 导出：已实现——自绘中文打印版面 `CharacterPrintSheet.vue`（Teleport 到 body），数据与 XLSX 共用 `buildCharacterExportData` 同一事实源；`@media print` + `window.print()` 输出 A4 PDF（全局 `@page`/打印隐藏规则在 `src/styles/index.scss`）；`afterprint` 自动关闭打印视图；官方 PDF 仅作版面参考，未进入运行时。
- R3 XLSX 导出：已实现——`src/services/export-xlsx.ts`（exceljs 4.4.0，动态 import 按需分包，不进入 SSG 预渲染路径）；数据组装纯函数 `src/features/character-export/build-export-data.ts`（中文工作表与列名、区块标题、冻结前两行）；hook `exportXlsx` 触发下载，文件名 `角色名-dnd5e.xlsx`。
- 经验值字段：草稿模型无经验值字段（`CharacterDraft` 未登记 XP），导出以「等级」代替，未引入新规则数据；如后续需要经验值展示需另立项。
- 测试：`test/features/character-export/build-export-data.test.ts`（数据一致性）、`test/services/export-xlsx.test.ts`（工作簿读回）、`CharacterSheetStep.test.ts` 导出入口用例（菜单三项、JSON/XLSX emit、PDF 打印视图 + afterprint）。
