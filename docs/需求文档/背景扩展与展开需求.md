# 背景扩展与展开需求

## 1. 背景与目标

用户反馈：当前项目的 2014 背景存在两个缺口：

1. **背景缺少展开介绍**：`OriginStep` 背景卡片只有一行摘要，无法查看技能、工具、语言、背景特性等完整信息（种族与装备已支持展开，背景在“种族装备效果展开展示需求”中被明确排除，本次立项补齐）。
2. **背景数量偏少**：希望像种族扩展一样补充 2014 版扩展背景。

本轮目标：**理解需求并整理文档（不写代码）**，为下一步程序实现做铺垫。已确认决策：

- 来源范围：精选常用一批 = **SCAG 12 个 + GGR 9 个公会背景 + MOT 1 个运动员**（共 22 个基础背景，另含 City Watch 的调查员子变体说明）。
- 实现深度：**现有 18 条背景与全部新增背景都完整进入车卡**（implemented），并补全展开介绍。
- 展开位置：**仅起源步骤（OriginStep）展开**，角色卡背景区本轮不动。

## 2. 现状调查（已核验）

### 2.1 程序现状

| 模块 | 现状 |
|---|---|
| `app/src/rules/data/origins-2014.ts` `backgrounds2014` | 18 条：13 个基础背景 + 5 个正式变体（间谍/角斗士/行会商人/骑士/海盗）；仅 3 条 `implemented`（侍僧、学者、士兵），其余 15 条 `index-only` |
| `app/src/types/rules.ts` `BackgroundRule`（171–186 行） | 字段：`summary / parentBackgroundId / variantIds / skillIds / toolIds / languageChoices / featureName / recommendedClassIds / status / sourceIds`；**无 `description` 字段**（与 `RaceRule.description` 不同，背景无法展开详情） |
| `OriginStep.vue`（107–128 行） | 基础背景与正式变体均用不可展开的 `OptionCard`；`dm-only` 徽章逻辑在背景卡片未实现（当前无 dm-only 背景，可暂缓） |
| 派生/校验 | 背景技能/工具/语言经 `draft.backgroundSkillIds / backgroundToolIds / languages` 处理，与 status 无关 |

### 2.2 文档现状

- `docs/dnd-backgrounds.md`：13 个 `5e-2014` 核心背景 + 5 个变体 + 16 个 `5e-2024` 出身。
- `docs/backgrounds/5e-2014/<bg>/<bg>.md`：18 个资料文件，含机械索引表、特性详解、创建与校验、人物特征候选（8 人格/6 理想/6 羁绊/6 缺点）、官方入口——可作为展开介绍 `description` 的原创转述依据。

### 2.3 考察核验结论（2026-08-11，dnd5e.wikidot.com + 5e.tools + Aurora Builder 交叉核验）

**来源勘误（重要）**：

- **SCAG 背景是独立完整背景**（技能/工具/语言/装备均独立给出），不是"替换 PHB 背景技能"的变体；其特性按原书标注为 **Variant Feature**，且**建议特征表（人格/理想/羁绊/缺点）借用 PHB 对应背景**（Far Traveler 自带完整特征表）。替换关系：City Watch→士兵、Clan Crafter→行会工匠、Cloistered Scholar→学者、Courtier→行会工匠、Faction Agent→侍僧、Inheritor→民间英雄、Knight of the Order→士兵、Mercenary Veteran→士兵、Urban Bounty Hunter→罪犯、Uthgardt Tribe Member→化外之民、Waterdhavian Noble→贵族。
- **MOT 只有 1 个新背景 Athlete（运动员）**；无 Mariner 背景（Ghosts of Saltmarsh 的 Marine 是士兵变体）。Athlete 无"运动等级骰子"机制，唯一掷骰元素是擅长项目 d8 表。
- **GGR 公会法术（Guild Spells）** 前置条件为拥有**施法（Spellcasting）或契约魔法（Pact Magic）**特性，效果是把公会法术表中的法术**加入施法职业的法术列表**（照常占用法术位），**无短休恢复机制**。
- 9 个公会背景的 1/2 级公会法术与技能/工具/语言/装备已逐项核验（俄佐立、波洛斯、底密尔、葛加理、古鲁、伊捷、欧佐夫、拉铎斯、瑟雷尼亚）；第 10 个公会背景 Simic Scientist 未纳入本次精选。

## 4. 非目标与边界

- **不写程序代码**（本轮为考察 + 文档铺垫）。
- 不复制商业规则书正文：新增背景只记录稳定 ID、技能/工具/语言、装备要点、原创玩法摘要、兼容边界与官方链接。
- 角色卡（CharacterSheetStep）背景展示区本轮不做展开。
- 不纳入：Simic Scientist（待核验）、SCAG 之外的其他商业背景（AI/ERftLW 龙纹/Strixhaven 等）、2024 出身数据。
- 公会法术未核验前不进入自动计算；法术名属公开数据可登记展示。
