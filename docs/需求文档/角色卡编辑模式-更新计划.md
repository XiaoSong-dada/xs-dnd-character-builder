# v1.0.0 角色卡编辑模式更新计划

> 目标版本：**v1.0.0**  
> 实施状态：**已完成，随 v1.0.0 发布**。

## 目标

在不覆盖原始车卡选择的前提下，为角色卡增加显式编辑模式。人工修改以可重算差值保存，并同步角色卡、摘要、跑团助手、PDF、XLSX 与 JSON；同时在应用根级禁用移动端双击放大并保留捏合缩放。

## 实施阶段

1. 将 `CharacterDraft` 升级为 schema v6，新增独立 `CharacterManualEdits`，统一迁移 v2—v5 与 JSON 导入。
2. 建立“系统基线 → 上游调整 → 依赖重算 → 下游差值”的两阶段派生，以及有效环位、有效法术与清空人工编辑纯规则接口。
3. 由 Store 统一归一化写入，并协调最大生命值、已消耗环位和休息快照。
4. 在角色卡四个目标页签接入编辑开关、双击/键盘输入、中文校验、恢复确认及人工法术弹窗。
5. 让跑团助手、摘要与 PDF/XLSX/JSON 统一消费有效数据；人工法术按 ID 去重并保留来源。
6. 根级应用 `touch-action: manipulation`，保留滚动、捏合缩放和骰盘动态手势策略。
7. 更新规则、架构、需求、版本与发布记录，并完成全量测试、构建和移动端验收。

## 核心验收

- v2—v5 自动迁移到 v6；无人工数据时结果与 v0.9.2 一致。
- 上游属性/熟练修改正确重算依赖，下游差值不重复累计；数值边界与一键恢复符合需求文档。
- 最大生命值 30、当前 20 改为最大 40 后当前为 30；恢复时同样保持已损失生命。
- 全职业及无施法职业可使用 1—9 环人工环位并从完整系统法术库添加法术。
- 角色卡、摘要、跑团助手、PDF、XLSX、JSON 的最终数值与法术一致。
- `pnpm test:run`、`pnpm build` 通过，浏览器无控制台错误，移动端手势无回归。
