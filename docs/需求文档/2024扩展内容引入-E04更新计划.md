## 2. 适配模型（E04-01）

### 2.1 原则

1. **新条目、独立数据**：2024 版本按 UA 正文重新录入，不复用、不继承 2014 运行时的特性、数值、选项或法术；ID 使用 `subclass-2024-ua-*`。
2. **2014 条目只读保留**：不修改 `subclasses-2014.ts`／`subclass-features-2014.ts`；既有 2014 草稿与选择零影响。
3. **适配登记表**：新增 `app/src/rules/data/subclass-adaptations-2024.ts`，登记 `{ concept, from2014Id, to2024Id, sourceId, note }`，用于：
   - 角色卡／详情提示「本子职存在 2024 版本」；
   - B13 后续批次的适配合集与避免重复；
   - 测试断言 2014／2024 一一映射。
4. **DM 选项语义**：破誓者沿用 `availability: 'dm-only'`，不进入普通玩家默认候选；界面给出「需 DM 允许」提示。
5. **来源按来源批次**：5 项统一 `source-2024-ua-subclass-update`，`status: 'selectable'`，游玩测试标记。

### 2.2 适配登记表结构（草案）

```ts
export interface SubclassAdaptation2024 {
  readonly concept: string            // 中文概念名
  readonly from2014Id: string         // subclass-2014-*
  readonly to2024Id: string           // subclass-2024-ua-*
  readonly sourceId: string
  readonly note?: string              // 译名差异、重做范围等
}
```

### 2.3 译名与文档

- 2024 条目用 UA 译名（骁骑士、醉拳武者、精魂守卫道途），2014 条目保持现有译名（骑兵、醉拳宗、先祖守卫道途）；在 `docs/dnd-classes.md` 对应职业章节记录映射。
- 实施时同步核对 CHM 目录与正文的差异（精魂守卫道途旧称、醉拳武者英文名 `Warrior of Intoxication`）。

## 3. 设计

### 3.1 文件与 ID

- 新文件 `app/src/rules/data/ua-subclass-update-2024.ts`，导出特性、子职、选项与适配表。
- ID：`subclass-2024-ua-barbarian-storm-herald`、`subclass-2024-ua-barbarian-spiritual-guardian`、`subclass-2024-ua-fighter-cavalier`、`subclass-2024-ua-monk-intoxication`、`subclass-2024-ua-paladin-oathbreaker`；特性 `ua-subclass-update-2024-<slug>`。
- 装配：`subclasses-2024.ts` 追加；破誓者 `availability: 'dm-only'`。

### 3.2 特性与资源

| 子职 | 必选项 | 资源与结算 |
| --- | --- | --- |
| 风暴先驱 | 风暴灵光环境（荒漠／海洋／苔原） | 灵光效果与伤害为摘要级；狂暴次数沿用职业 |
| 精魂守卫 | 精魂护卫效果选择（按 CHM 的选项） | 精魂之盾随狂暴伤害成长→摘要；选项用 `optionIds` |
| 骁骑士 | 附赠熟练技能／工具选择 | 果决印记、守御战技、坚守阵线按 CHM 登记；无额外消耗池的按摘要 |
| 醉拳武者 | 额外熟练选择 | 玄酒琼浆（临时酒类资源）、醉态摇曳按 CHM |
| 破誓者 | 无（DM 选项） | 咒唤亡灵、憎恨灵光、超然抗性、恐惧之王；法术表始终准备 |

### 3.3 校验与提示

- 未启用 `UA 子职业更新` 时 5 项不出现在候选池；破誓者即使启用也不进入普通玩家默认候选。
- 角色卡／详情显示来源、游玩测试标记与「存在 2014 版本」提示（由适配表驱动）。
- 关闭来源保留选择并标记失效；重开恢复。
