# 导出角色卡按附件参考模板调整需求

> 来源：GitHub Issue #18《更改导出角色卡》（2026-11-04）附件
> 状态：已实施（v1.14.1 发布；PDF 与 2014/2024 自动卡均接入）
> 适用规则集：D&D 5e 2014 / 2024

## 1. 原始诉求

用户提供了三份参考文件：

1. `2_DnD_5E.pdf`：三页 Letter、334 个 AcroForm 字段的 2014 中文角色卡；
2. `DND 5E人物卡（法术查询列表整合版v4.4.5）.xlsx`：2014 自动计算卡；
3. `dnd5e2024人物卡模板v1.3.xlsm`：2024 自动计算卡。

补充说明：**导出的 PDF 按附件 PDF 模板；导出的自动卡按对应版本的自动卡模板。**
后续确认：自动卡沿用项目现有「字段映射」表契约；导出只是扩展能力，不能拖慢项目整体加载。

## 2. PDF 部分

- 运行时模板 `app/public/templates/character-sheet-zh-plus.pdf` 替换为 `2_DnD_5E.pdf`；
- 原始文件归档到 `docs/export-templates/2_DnD_5E.pdf`；
- 字段集合与页面结构不变（334 字段 / 3 页），继续复用现有 AcroForm 填充、字体与扁平化链路；
- 映射版本 `CHARACTER_SHEET_PDF_MAPPING_VERSION` 从 7 升到 8；
- 参考模板修正了 18 项技能的中文标签顺序；导出映射从“按旧模板错位行映射”改为“按同名字段直连”，解决旧模板中体操/运动等技能数值显示到相邻行的问题。

## 3. XLSX 自动卡部分

### 3.1 模板

| 规则集 | 运行文件 | 来源 | 大小 |
|---|---|---|---|
| 2014 | `app/public/templates/character-sheet-2014.xlsx` | `docs/export-templates/DND.5E.v4.4.5.xlsx` | 约 1055 KiB |
| 2024 | `app/public/templates/character-sheet-2024.xlsx` | `docs/export-templates/dnd5e2024.v1.3.xlsm`（去掉宏/ActiveX） | 约 719 KiB |

- 两张卡都追加了「字段映射」工作表，模板版本 4，契约与旧版相同：
  `A=字段 Key、B=工作表、C=目标单元格、D=说明、E=字段类型、F=必需级别`，`I1=模板版本`；
- 字段类型支持 `input`（只写非公式输入格）、`formula-cache`（保留公式写缓存值）、`value`（允许覆盖公式的显示值）；
- 模板生成脚本：`app/scripts/build-xlsx-templates.mjs`；映射数据：`app/scripts/xlsx-mappings/*.json`；
- 2024 模板转换时移除 `vbaProject.bin`、ActiveX 控件与相关关系；输出仍是标准 xlsx，避免宏安全提示。

### 3.2 写入范围

- 身份：角色名、玩家名、职业、种族、背景、阵营、等级、经验值、背景故事；
- 六项属性值、豁免熟练与修正、18 项技能熟练与修正（专精写入模板的专精标记或修正格）；
- 战斗：AC 修正、先攻、速度、最大/当前/临时生命值、生命骰；
- 特性与资源、物品、攻击（2014 四项 / 2024 三项）、钱币、法术位（2014）；
- 2014 法术列表（最多 30 条）；2024 自动卡**暂不写入法术列表与法术位总数**，导出时给出明确 warning，法术在卡内「施法」页选择。

### 3.3 性能

- 自动卡模板位于 `public/templates/`，**不进入 JS 包**，只在点击导出时 fetch；
- 导出不再 `import('exceljs')` 解析整本工作簿，改为 `fflate` 解包 + 直接修补目标单元格 XML；
- 旧构建中 ExcelJS 异步 chunk 约 940 KiB，并进入 PWA 预缓存（旧 50 项 / 7,614.6 KiB）；新构建不再生成该 chunk，PWA 预缓存降为 48 项 / 6,698.1 KiB（-916.5 KiB），导出时也不再下载；
- 首屏 JS 基本不变：app 主包 3,715,492 B → 3,715,984 B（+492 B），路由 index 280,691 B → 281,464 B（+773 B）；
- Node 实测单次填充：2014 约 1.0–1.5 s，2024 约 0.4–0.8 s（含解包、XML 修补与重新压缩）；旧方案读取 2024 `.xlsm` 在 2 分钟后仍未完成并占用约 1 GiB 内存；
- 首次页面加载不增加任何模板或 ExcelJS 请求；离线资源仍需用户主动「一键下载」。
