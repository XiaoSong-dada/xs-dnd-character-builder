- [x] **LV-A01：等级卡头部加入 ±1 步进**

    `.allocation__level`（卡片）> `.allocation__level-head`（左标签 + 右步进 `− N级 ＋`）+ `<label class="allocation__slider">`（滑杆 + 说明）；

  - 要点：步进块必须放在 `<label>` **之外**（避免 `<label>` 内嵌按钮导致点击同时命中滑杆）；滑杆的 `input[type="range"]` 仍留在 `.allocation__slider` 内，既有选择器与 `aria-label` 不变。

- [x] **LV-A02：步进复用滑杆提交通道与边界**
