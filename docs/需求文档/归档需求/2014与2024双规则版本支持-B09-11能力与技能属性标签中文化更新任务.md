# B09-11 能力与技能属性标签中文化 · 更新任务

- 对应问题：角色卡「能力」页签的技能／豁免行显示英文属性简写（如「DEX调整值」「DEX 15」），派生公式、法术页签与校验提示同样存在。
- 实现日期：2026-09-15。
- 状态：已完成并提交。
- 依据：[B09-11 更新计划](2014与2024双规则版本支持-B09-11能力与技能属性标签中文化更新计划.md)（含逐处定位与范围）。

## 1. 根因

所有英文简写都来自同一处写法：`src/rules/derive.ts` 等文件里的 `ability.toUpperCase()`（6 处派生标签／公式）、`SpellcastingStep.vue` 法术头部 1 处、`origins.ts` 校验提示 1 处。数值与结构本身正确，属于文案口径问题。

## 2. 改动

| 文件 | 改动 |
| --- | --- |
| `src/rules/data/ability-labels.ts`（新增） | 叶子模块：`ABILITY_KEYS`、`ABILITY_LABELS`（力量／敏捷／体质／智力／感知／魅力）与 `formatAbilityModifierLabel`（`敏捷调整值`） |
| `src/rules/data/feats-2014.ts` | 属性键与标签改为引用叶子模块并再导出（既有导入路径不变） |
| `src/rules/derive.ts` | 6 处 `toUpperCase()` 全部替换：技能来源标签、豁免来源明细、无甲防御公式、武器命中／伤害来源、法术攻击／法术 DC 来源 |
| `src/views/character-builder/components/SpellcastingStep.vue` | 法术头部「INT施法」→「智力施法」 |
| `src/rules/origins.ts` | 背景属性超上限提示「INT 加上…」→「智力加上…」（去空格） |

范围外保持不变：物种／起源文案、源码注释、DC／AC／CR／GP／DM 等惯例缩写、法术详情（B09-10 已处理）。
