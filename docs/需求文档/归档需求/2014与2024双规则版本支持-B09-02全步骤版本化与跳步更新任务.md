# B09-02 全步骤版本化与跳步 · 更新任务

- 对应 TODO：B09-02（[B09 更新计划](2014与2024双规则版本支持-B09更新计划.md) 第 4.2 节）。
- 实现日期：2026-09-15。
- 状态：已完成。
- 已接受的产品默认：Q-B09-5 2024 来源步骤不提供"只用核心"按钮，仅说明核心书始终启用（已按此实现）。

## 1. 目标与范围

- 目标：车卡全部步骤使用草稿自身版本解析候选、派生与校验；无施法职业与未达施法等级可明确跳过。
- 本次范围：
  - `sources`：`SourcesStep` 按版本渲染；2024 只展示核心书说明，隐藏 2014 扩展书开关与工具栏。
  - `class`：`ClassStep` 按版本取职业目录与成长速览。
  - `timeline`：`FeatChoicePanel` 按版本取专长目录、资格判定与来源开关判定，徽标显示版本与数量。
  - `spells`：`SpellcastingStep` 的来源筛选、施法来源名称与始终准备法术解析按版本；无施法配置与未达施法等级沿用既有提示并允许继续（跳步语义）。
  - `sheet`：`CharacterSheetStep` 的规则解析（职业／子职／物种／背景／法术／物品）与 `AddManualSpellModal` 候选按版本；法术抄录耗时按版本解析法术。
  - `exports`：`buildCharacterExportModel` 的名称解析、来源开关判定按版本。
  - 其余步骤（origin／abilities／equipment／identity／validation）在 B06—B08 已按版本实现，本批只做缺口复核与回归。
- 不包含：改版另建与影响提示（B09-03）；角色卡文案清理与提示级校验呈现（B09-04）；物品库版本分派（B09-06）；跑团（B10）与导出承载（B11）。

## 3. 跳步语义

- 法术步骤在 `getSpellcastingConfig` 返回空（无施法职业）或目标等级低于 `startsAtLevel`（如 2024 三级子职施法、半施法者 1 级）时显示说明性提示，且 `canContinue` 判定为可继续（`validateSpellSelections` 对无配置返回 true）。
- 步骤顺序与深链参数不变，跳过状态不写入草稿数据。
