# 法师抄录法术书需求

> 实施状态：**已实现**（v0.6.3，2026-08）。实施与验收见《抄录法术书-更新计划.md》。

## 1. 背景与目标

法师职业可通过**抄录**把额外法术写入自己的法术书（2014 规则：每个环级消耗 50 GP 与 2 小时），从而在升级自动获得之外学习新法术。当前项目法术书数量**严格等于**升级自动获得的数量（1 级 6 个，每级 +2），没有任何额外抄录途径，与规则不符。

本次目标（已确认）：

- 在**角色卡「法术」页签**新增「抄录法术书」能力，花费金币把额外法术写入法术书；
- 该能力**抽象为共享功能**，**跑团助手「法术」页签同样可调用**；两侧操作的是**同一份草稿**的法术书（`spellSelections.spellbookSpellIds`），数据天然共同；
- 抄录与**金币联动**：费用 = 环级 × 50 GP，从冒险净增金币（`adventureGold`）扣除；
- 抄录**不可撤销**（本版本不提供移出/退款），时间消耗（2 小时/环级）**仅作提示文案**，不记录；
- 跑团助手「法术」页签**下方新增「未准备法术」区**（法术书中未准备，与角色卡对应区一致）。

## 2. 现状调查（已核验）

### 2.1 施法数据层（`class-2014-wizard`，`src/rules/data/arcane-casters-2014.ts`）

| 项 | 现状 |
|---|---|
| 施法模式 | `spellbook`（法术书 + 准备），智力施法，1 级开始 |
| 法术书 | `spellSelections.spellbookSpellIds`；数量上限严格 = `spellbookSpellsByLevel`（`6 + 等级×2`，升级自动获得，免费） |
| 准备法术 | `preparedSpellIds`，必须来自法术书；数量 = 智力调整值 + 法师等级（`preparedFormula: 'ability-plus-level'`） |
| 戏法 | `cantripIds`；抄录不涉及戏法 |

### 2.2 当前限制抄录的三个硬编码点

| 位置 | 现状 |
|---|---|
| `src/views/character-builder/components/SpellcastingStep.vue` `toggleSpellbook` | `current.length < requiredSpellbookCount` 才允许写入，超名额法术无法入书 |
| `src/rules/validate.ts`（`spellbook-count` 校验） | `spellbookSpellIds.length !== requiredSpellbook` 报错「法术书内容尚未完成」（严格等于，超了就报错） |
| 角色卡「未写入法术书」区（`CharacterSheetStep.vue` `wizardWriteToBook`） | 只读展示，提示「升级时可扩充」，无抄录操作 |

### 2.3 金币系统（现成，可直接联动）

- 持有总额 = `currency.gp`（起始，只读） + `adventureGold`（冒险净增，**唯一事实源**，可为负）；
- 角色卡物品页签已有「添加/减少/设置」按钮 → `emit('changeAdventureGold')` → `store.updateDraft({ adventureGold })`；
- 跑团助手 `useSessionPanel.ts` 的 `changeAdventureGold` 走 `store.updateDraftById(id, { adventureGold })`，**与角色卡共享同一事实源**，任何一侧扣减另一侧自动同步；
- 约束：持有总额不得为负。

### 2.4 跑团助手「法术」页签现状（`SessionPanel.vue`）

- 展示：戏法列表 + 已准备法术（按环级分组，含法术位使用/恢复、施放弹层）；
- **没有**法术书展示、**没有**未准备法术区、没有抄录入口；
- 空状态文案「暂无已准备法术」。

### 2.5 天然兼容点

- 法术专精/招牌法术（`candidateKind: 'spellbook-level-N'`）从法术书取候选，抄录入书的法术**自动可被选择**，无需改动；
- 准备法术候选（`prepareFromBook` = 法术书中未准备）自动包含抄录法术，角色卡/跑团助手「准备」按钮天然支持抄录法术；
- 导出（`build-export-data.ts` 195–201 行）法术书按 `spellbookSpellIds` 全量导出，抄录法术自动进入 PDF/XLSX/JSON。

## 3. 需求项

### R1 抄录入口与共享抽象（必须）

- **角色卡「法术」页签**为抄录主入口：在法术书区或「未写入法术书」区提供「抄录法术」操作，打开抄录界面；
- **跑团助手「法术」页签**同样提供「抄录法术」入口，调用与角色卡**同一套共享能力**；
- 共享能力抽象为独立模块（两个明确调用方，符合上提公共模块条件），包含：规则层纯函数（候选池、费用、校验、应用）+ 抄录界面组件与 hooks；
- 两侧操作同一草稿的 `spellSelections` 与 `adventureGold`，法术书内容完全一致（共同事实源）。

### R2 抄录候选池（必须）

- 候选 = **法师职业法术池**（`classSpellIds`）中：`环级 ≥ 1`、`环级 ≤ 当前最高可施放环`（`getMaximumSpellLevel`）、**尚未写入法术书**的法术（与升级扩充同池）；
- 已在法术书中的法术不重复出现；
- 戏法不可抄录（候选过滤 `level > 0`）；
- 候选按环级分组展示，每项展示环级与抄录费用。

### R3 费用与金币联动（必须）

- 抄录费用 = **环级 × 50 GP**（2014 规则，规则层常量 `TRANSCRIBE_COST_PER_LEVEL = 50`）；
- 抄录时从 `adventureGold` 扣减（`nextAdventureGold = adventureGold - cost`），持有总额 = `currency.gp + nextAdventureGold` **不得为负**；
- 金币不足时拒绝抄录，提示中文原因（如「金币不足：抄录 3 环法术需要 150 GP，当前持有 120 GP」）；
- 扣减与入书在**同一次草稿更新**中完成（`store.updateDraftById` 一次 patch 同时写 `spellSelections` 与 `adventureGold`），避免中间态；
- 抄录成功后金币面板（角色卡物品页签、跑团助手）自动同步显示扣减结果。

### R4 抄录动作与数据记录（必须）

- 确认抄录后：法术写入 `spellSelections.spellbookSpellIds`，**法术书数量允许超过** `requiredSpellbookCount`（超出部分即抄录所得）；
- `SpellSelections` 新增 `transcribedSpellIds: readonly string[]`（抄录获得的法术 ID，为 `spellbookSpellIds` 的子集），用于区分「升级免费获得」与「抄录获得」及展示花费；
- 花费按法术环级实时推导（环级固定，`50 × level` 恒定），不冗余存储 cost；
- 抄录**不做二次确认之外的额外确认**：金币扣减为数值调整，但抄录本身是单向操作，确认弹层内明确展示费用与扣减后余额；
- 抄录的法术与升级获得法术同等地位：可被准备、可被选为法术专精/招牌法术、可导出。

### R5 不可撤销（必须）

- 本版本**不提供**抄录法术的移出、删除或退款；
- 升级/降级导致的法术书名额变化**不影响**已抄录法术（抄录法术始终保留在书中，且不占用升级免费名额）；
- 抄录记录一经产生不提供删除入口。

### R6 校验与既有界面兼容（必须）

- `src/rules/validate.ts` `spellbook-count` 校验由「严格等于」改为「**至少达到**」（`length < required` 才报错），并新增校验：`transcribedSpellIds ⊆ spellbookSpellIds` 且全部在职业池内；
- 车卡流程 `SpellcastingStep.vue` 的法术书写入上限（`toggleSpellbook`）**保持现状**（车卡阶段不提供抄录，入口只在角色卡/跑团助手）；但重新编辑进入该步骤时，若法术书已含抄录法术（数量 > required），界面需兼容展示：抄录法术标记「已在书中（抄录）」且不可移除，计数展示如实显示；
- 准备法术、法术专精/招牌法术的既有校验与候选逻辑不因抄录法术存在而失效。

### R7 跑团助手「未准备法术」区（必须，用户新增需求）

- 跑团助手「法术」页签**下方新增**「未准备法术」区：展示**法术书中未准备**的法术（即 `prepareFromBook` 候选），与角色卡对应区一致；
- 该区每项提供「准备」按钮：点击后写入 `preparedSpellIds`（受准备数量上限约束，满员显示「已满」禁用），与角色卡 `togglePrepare` 同一语义；
- 该区不提供施放操作（未准备法术不可施放，符合 2014 规则）；
- 空态（无未准备法术）时不渲染该区或显示轻量空态。

### R8 抄录界面展示（必须）

- 抄录界面（弹层）展示：候选法术（名称、环级、费用）、当前持有金币、扣减后余额预览、总费用合计、时间提示文案（「按规则每环级需 2 小时，本次抄录共需 X 小时」——仅提示，不记录）；
- 抄录成功后：法术书区即时出现该法术，并带「抄录」徽标；展开可查看来源说明（费用）；
- 角色卡与跑团助手两侧数据一致（同一草稿，无需额外同步逻辑）。

### R9 导出（必须）

- 导出（PDF/XLSX/JSON）法术书**自动包含**抄录法术，不改变导出结构（现有导出已按 `spellbookSpellIds` 全量导出）；
- JSON 导出包含 `transcribedSpellIds`，导入后抄录标记保留。

### R10 持久化与迁移（必须）

- `CharacterDraft.schemaVersion` 由 `3` 升至 `4`；
- `SpellSelections` 增加 `transcribedSpellIds: readonly string[]`；
- `src/services/draft-storage.ts`：新增 v3 → v4 迁移（旧草稿补 `transcribedSpellIds: []`），复用现有 `migrateV2` 迁移链路模式；
- `src/services/character-json.ts`：JSON 导入兼容 v4，v3/v2 导入按迁移链路补全；
- 旧草稿迁移后行为不变：法术书数量 = 原 `spellbookSpellIds` 数量，抄录记录为空。

## 7. 已确认决策（用户确认）

1. **入口**：角色卡「法术」页签为主入口；能力抽象共享，跑团助手「法术」页签同样可调用；两侧法术书为同一份草稿数据（共同）。
2. **候选池**：仅当前登记的法师职业法术池（`classSpellIds`），环级 ≤ 当前最高可施放环、未入书的法术。
3. **不可撤销**：本版本抄录后不允许移出/删除/退款（符合规则不可逆语义）。
4. **时间不记录**：2 小时/环级仅作提示文案，不持久化、不参与计算。
5. **费用**：环级 × 50 GP，扣 `adventureGold`，持有总额不得为负。
6. **跑团助手补展示**：法术页签下方新增「未准备法术」（法术书中未准备）区，支持「准备」操作。

## 8. 待实施时确认点

1. 抄录界面形态：`UiModal` 弹层（与施放弹层一致）还是页内面板（实现时按现有交互惯例定）。
2. 「抄录法术」入口按钮位置：法术书区标题行 vs 「未写入法术书」区列表项按钮（实现时按视觉自然排布，功能一致）。
3. 跑团助手「未准备法术」区的「准备」按钮与角色卡 `togglePrepare` 的语义完全一致（长休换准备），是否需要独立的「长休后自动刷新」提示文案。
4. 规则层函数落点：`src/rules/spellcasting.ts` 扩展 vs 新建 `src/rules/spellbook.ts`（实现时按函数归属内聚性定，倾向新建文件保持职责清晰）。
