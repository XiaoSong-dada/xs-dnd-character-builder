## 1. 背景与用户目标

用户希望整个产品能够兼容 D&D 2024 规则，并保留 2014 规则的使用能力。

用户明确要求先了解两版规则差异，再思考兼容方案；目前已完成核心差异整理及 B00 产品范围定稿，不修改业务代码。下一步制定 B01 规则核验与覆盖矩阵更新任务。

### 1.1 已确认需求

- 产品目标为同时支持 2014 与 2024，而不是将所有角色统一替换成 2024。
- 车卡第一步能够选择对应规则版本：2014 或 2024。
- 规则版本与目标等级等初始设置放在同一页，不另设只选择版本的步骤。
- 规则研究参考项目中的《DND 五版不全书》，先理解规则，再进入后续方案设计。
- 初始交付为需求文档；后续已制定分批 TODO 并完成 B00 文档定稿，尚未开展兼容功能实现。

### 1.2 目标项目与范围

- 产品实现对象固定为 `dnd-character-builder/app`。
- `跑团车卡辅助` 为视觉原型项目，本需求不要求修改原型。
- “整个系统兼容”按角色生命周期理解：创建、升级与重新编辑、规则计算与校验、保存与恢复、导入导出、角色卡、跑团助手。
- 现有 1—20 级单职业能力作为需求整理基线；用户本次未要求开放多职业。
- 本轮最终范围为 2024《玩家手册》角色内容，以及《城主指南》中产品涉及的物品规则；扩展书后续另行规划。

### 1.3 首批、后续与延期范围（B00-01、B00-05、B00-06）

| 层级 | 定稿范围 |
| --- | --- |
| 首批职业 | 战士＋勇士、法师＋塑能学派，均覆盖 1—20 级 |
| 首批起源 | 2024 PHB 全部核心物种与背景，包含对应分支和必选项 |
| 首批配套 | 上述构筑可合法选择的完整专长、法术及普通装备，初始装备选择完整可用；法术包含物种、背景、专长带来的跨职业候选，不限于法师职业法术 |
| 后续核心内容 | 其余核心职业、全部目标核心子职、剩余核心内容，以及目标魔法物品 |
| 本轮不纳入 | 2014 内容向 2024 的适配、旧 2024 草稿转换、扩展书支持 |

魔法物品首批暂不开放，仍属于后续目标内容。B01 负责逐条登记 ID、来源和数量，不能因参考资料存在就标记已核验；目录收录、正常可选和自动计算的完成度分别记录。

按职业分批开放。每批必须完成创建、保存、跑团、导出与 2014 回归验收，支持声明明确到职业、子职、等级及配套内容；未完成子职和物品不进入正常候选。首批开放不代表全部完成，最终依据本轮核心内容清单验收。

### 3.3 当前研究的限制

- 已整理影响系统结构的核心机制，不是逐条职业能力、全部子职、专长、法术、装备与魔法物品的完整差异审计。
- 本次以 2014 与 2024 核心规则对比为主，不将 2014 扩展可选规则概括为所有 2014 角色的默认行为。
- 不全书正文、其中的翻译注解、外部官方补充、勘误和测试材料仍需分层记录；实现依据以不全书规则正文为主，翻译注解只能作为解释线索，不能替代正文。
- 具体实现前需要确认不全书对应章节和项目采用的版本日期；外部勘误只作为补充差异记录，不再作为本项目条目进入下一阶段的必要证据。
- 规则内容继续使用原创摘要与来源索引；本地资料作为项目权威不等于可以把完整商业正文复制到新增业务数据中。

## 4. 已识别的核心规则差异

以下为依据项目内《DND 五版不全书》正文整理的研究结论及其产品含义，不是已实施功能清单；外部规则页面只作补充出处与差异记录。

### 4.1 属性、背景、物种与语言

| 机制 | 2014 核心规则 | 2024 核心规则 | 产品含义 |
| --- | --- | --- | --- |
| 初始属性加值 | 主要来自种族、子种族 | 来自背景，物种不提供属性加值 | 属性来源链与校验按版本处理 |
| 背景收益 | 技能、工具或语言、背景特性、装备 | 三项候选属性、起源专长、两项技能、一项工具、装备 | 背景影响属性和专长，不只是人物描述 |
| 背景属性分配 | 核心背景不提供属性加值 | 在指定三项属性中选择一项 +2、另一项 +1，或三项各 +1，不超过 20 | 不能默认为六项任意分配 |
| 物种与分支 | 种族、子种族体系 | 按物种提供血统、传承或祖先等选择 | 同名种族与物种不能直接共享效果 |
| 语言 | 按种族、背景及其他来源获得 | 通用语加两门标准语言，其他特性可额外提供 | 独立记录语言来源、候选范围与数量 |
| 属性生成 | 标准数组、随机生成及可选购点 | 保留标准数组、随机生成和购点 | 基础生成与后续属性加值应分开 |

补充：

- 两版规则标准数组均为 15、14、13、12、10、8；2024 采用不全书规定的 27 点购点，基础值 8—15，14 花费 7 点、15 花费 9 点。
- B00-03 已确认：2014 保留现有自由购点团规，2024 使用官方购点；两版均保留标准数组和自定义录入，不在本轮增加两种购点任意切换功能。此处为未来行为要求，当前代码尚未改变。
- 2024 PHB 物种目录及能力有调整；例如人类提供额外起源专长。半精灵、半兽人未作为该书的独立核心物种列出，不等于所有旧版相关内容都自动禁止。
- 2014 与 2024 同名物种能力的体型、速度、感官、法术、次数及恢复条件需要逐项核对。

### 4.2 专长与属性提升

- 2014 专长属于可选规则，通常替代职业提供的属性提升；项目现已默认开放该选项。
- 2024 区分起源、通用、战斗风格、传奇恩惠四类专长；属性值提升本身也是专长。
- 专长候选必须同时考虑授予来源、允许分类、等级与其他前置条件、是否允许复选。
- 2024 核心职业在 19 级提供传奇恩惠节点，但具体可选范围仍按职业特性授权处理，不能写死为仅允许传奇恩惠。
- 同名专长可能改变效果；不能仅给 2014 条目增加分类后用于 2024。
- 属性上限须尊重具体特性的例外，不能将所有高等级提升一律截断到 20。

### 4.3 职业与升级节点

2024 的 12 个核心职业均在 3 级获得子职；2014 的牧师、术士、邪术师在 1 级，德鲁伊、法师在 2 级，其余核心职业通常在 3 级。统一初次获得等级不代表后续子职特性等级全部统一。

| 职业 | 前期已识别的 2024 代表性变化 |
| --- | --- |
| 野蛮人 | 武器精通、原初学识、凶蛮打击，以及狂暴维持与恢复调整 |
| 吟游诗人 | 激励使用与恢复、魔法奥秘等变化 |
| 牧师 | 1 级圣职选择，引导神力与神圣干预重写 |
| 德鲁伊 | 原初职能；荒野变形的已知形态、临时生命值与恢复规则变化 |
| 战士 | 武器精通、战术思维等新能力，回气次数与用途变化 |
| 武僧 | 武艺骰从 d6 起步，功力使用与恢复、拨挡攻击、震慑拳变化 |
| 圣武士 | 1 级施法、附赠动作圣疗，至圣斩改为法术相关机制 |
| 游侠 | 1 级施法，宿敌围绕猎人印记及其资源、强化效果重写 |
| 游荡者 | 武器精通、以偷袭骰换取效果的诡诈打击，可靠才能提前至 7 级 |
| 术士 | 先天术法、2 级超魔法、3 级子职 |
| 邪术师／魔契师 | 1 级魔能祈唤、契约恩赐纳入祈唤体系、3 级子职 |
| 法师 | 3 级子职，学者、记忆法术等能力 |

以上为差异摘要，不是完整职业规则表，中文名沿用研究资料表达，不构成此次批量更名要求。

产品需要按版本、职业和等级确定所有应获得能力；直接创建高等级角色也要补齐此前必选项。2014 已支持的工匠不能因出现在当前职业列表中而自动被认定为 2024 原生职业；其 2024 来源与支持范围需另行核验。

### 4.4 法术与施法

- 多个 2024 职业按职业表确定准备数量，不能默认复用 2014 的属性调整值加职业等级等公式。
- “准备法术”的术语不代表各职业都能长休后任意更换；数量、候选池、替换时机和替换数量应分别判断。
- 吟游诗人、术士、邪术师仍有升级替换限制；圣武士、游侠与牧师、德鲁伊的长休替换范围也存在区别。
- 始终准备法术、职业正常准备、法术书、免费施法、契约魔法与普通法术位不能合并为单一数量。
- 2014 的附赠动作施法限制与 2024“每回合通过施法至多消耗一个法术位”的通用限制不同；不能简化为每回合只能施展一个非戏法。
- 同名法术需要独立核对施法时间、距离、目标、专注、伤害或治疗、升环与其他效果。

### 4.5 装备、战斗与跑团资源

| 机制 | 主要差异 | 产品含义 |
| --- | --- | --- |
| 武器精通 | 2024 增加精通词条，须由相应特性解锁 | 武器熟练与精通分开，按角色选择展示可用效果 |
| 初始装备 | 两版职业、背景的装备与金币选项需独立核对 | 不直接复用旧装备包或重复领取互斥收益 |
| 长休 | 2014 通常恢复至多总生命骰一半，至少 1 个；2024 恢复全部已消耗生命骰 | 休息结算跟随版本，职业资源还需按具体特性恢复 |
| 力竭 | 2014 分级效果；2024 每级 D20 检定减 2、速度减 5 尺，6 级死亡 | 状态说明与适用修正独立处理 |
| 突袭 | 2014 影响首回合行动与反应；2024 主要为先攻劣势 | 先攻及提示遵循对应规则 |
| 擒抱、推撞 | 2014 主要为对抗检定；2024 纳入徒手打击选项并由目标进行豁免 | 检定提示及 DC 来源改变 |
| 激励 | 2014 提供优势；2024 英雄激励允许掷骰后重掷一个骰子 | 两版资源含义与操作提示不能混用 |
| 魔法物品与能力 | 同名条目的效果、动作、充能或恢复条件可能变化 | 物品、能力摘要与自动效果需要逐项核验 |

这些差异应覆盖系统已有的相关功能；本文不要求新增完整战斗回合模拟器。未支持自动结算的情境效果应准确展示边界，不能以描述存在冒充自动实现。

## 5. 由规则研究提出的产品约束

本节包含项目既有隔离原则及 B00 已确认的产品约束；具体规则分派和存储实现仍由后续任务制定。

### 5.1 规则版本贯穿角色生命周期

- 每个角色绑定一个明确主规则版本，保存、恢复和导出时保留该版本。
- 候选内容、等级时间线、派生计算、合法性校验、角色卡与跑团资源使用一致版本。
- 已确认相同的基础数学可以共用；两版同名条目的 ID、效果和来源独立。
- 原始选择与派生结果分离，并保留属性、熟练、专长、法术、装备和资源的来源说明。
- 支持 2024 不应改变已有 2014 角色的计算与使用行为。

### 5.2 双版本支持与跨版本内容适配分开

- “分别创建 2014、2024 角色”是本次明确目标。
- B00-05 已确认：本轮两版独立，2024 角色不开放选择 2014 旧版内容；相关适配归入延期 B13，不合并两版候选池。
- 官方明确的旧背景与物种适配包括：采用旧种族时忽略其属性加值；旧背景按兼容规则补属性加值；背景未提供专长时才补一个自选起源专长。
- 上述说明不能推导出“所有旧内容原样可用”，也不能推导出统一删除所有旧背景收益。其他保留、替换和冲突必须按具体规则核验。
- 旧子职不能只调整获得等级就被视为已经适配；与新版基础职业的依赖与冲突需逐条研究。

### 5.3 已有角色与切换安全

- 修改版本可能影响背景、物种、职业、子职、专长、法术及装备，不能静默转换或删除。
- 既有选择不应在未解释影响的情况下参与另一版本计算。
- B00-04 已确认：新角色尚未产生职业等构筑选择时可直接修改版本；已有构筑改用另一版本时另建角色，保留原卡，不复制版本相关选择，不在同一角色内保存两版构筑。
- 旧角色的原始选择、人工调整、图片及跑团数据不得因新版本开放而改变。
- 旧 2024 草稿继续只读隔离并允许原样导出；不因版本标签相同而自动视作合法新草稿，转换不纳入本轮。
