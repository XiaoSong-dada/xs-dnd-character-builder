## 1. 目标与范围

- 目标：2024《城主指南》348 项魔法物品按来源与机制接入纯规则层；同调、充能、一次性消耗与恢复时机完成登记；2024 仓库可按稳定 ID 解析并在草稿校验中生效。
- 本次范围：
  - 数据：348 项目标条目（209 `selectable`／139 `index-only`），稳定 ID 沿用 B01 运行时 ID 草案 `equipment-2024-<english-slug>`。
  - 来源：新增 `source-2024-dmg`（2024 核心书，`category: 'core'`、`selectable: false`，在 2024 仓库中始终启用）。
  - 字段：类别（武器／护甲／盾牌／药水／卷轴／戒指／权杖／法杖／魔杖／奇物）、稀有度（普通／珍稀／传说／神器／多种稀有度）、同调（无需同调 178／需同调 136／条件同调 34，其中仅限施法者 9）、动作边界（`itemAction`）、充能与一次性消耗及恢复时机（`magicItemUsage`：有充能 69、一次性 141、黎明恢复 47、短休 4、长休 10）、状态引用 67 条、原创机制摘要。
  - 装配：`magicItems2024` 接入 `rulesRepository2024.equipment`；2014 仓库不解析任何 2024 魔法物品 ID。
  - 生成：新增 `scripts/build-magic-items-2024.mjs`，从 B01 两份矩阵生成 `data/magic-items-2024.ts`（构建期生成、提交进仓库，运行时不再解析 Markdown）。
- 不包含：物品库 UI 的版本化加载与筛选（B07-05a；`AddItemModal` 仍固定 2014 目录）；来源关闭与购买／增删联验（B07-05b—d）；充能与消耗品的运行时结算（B10）；导出适配（B11）；+1／+2／+3 聚合条目的具体型号拆分与自动加值（当前登记型号区间，留待物品实例与后续批次）；生物、随机表与 DM 依赖条目的自动化（保持 `index-only` 与提示）。

## 2. 共享能力改动

- `EquipmentRule` 新增：`itemAction`（动作边界）、`magicItemUsage`（充能／一次性／恢复时机）与 `stateReferences`（状态引用）；新增 `MagicItemUsageRule` 类型。
- `sources-2024.ts`：新增 `source-2024-dmg`；`isSourceEnabled` 对 2024 核心来源始终启用，不进入来源开关。
- `repositories.ts`：2024 仓库装备装配由 `equipmentWithPacks2024` 扩展为 `[...equipmentWithPacks2024, ...magicItems2024]`。
- 现有版本化派生路径（`weapon-attacks.ts`、`derive.ts` 按草稿仓库解析 `magicBonus`、`armorClassBonus`）无需新增分支；2024 聚合条目未登记固定 `magicBonus`。

## 3. 数据与生成

- 新增 `scripts/build-magic-items-2024.mjs`：解析《魔法物品-DMG2024》与《魔法物品-机制索引》，按运行时 ID 一一对应校验（348／348，无缺漏），归一化类别与英文名，输出 `data/magic-items-2024.ts`（约 209KB，348 条）。
- 数据来源与版权：只登记结构化事实（类别、稀有度、同调、动作、资源、状态）与原创机制摘要；不复制《城主指南（2024）》正文，效果以原文为准。
- 聚合条目：`equipment-2024-armor-1-2-3`、`shield-1-2-3`、`weapon-1-2-3`、`ammunition-1-2-3`、`rod-of-the-pact-keeper-1-2-3`、`wand-of-the-war-mage-1-2-3` 共 6 条，名称与摘要标注 +1／+2／+3 型号范围。
- 字体：PDF 导出子集重建，覆盖新增文本用字（薇、笙、焖、蝰等）。
