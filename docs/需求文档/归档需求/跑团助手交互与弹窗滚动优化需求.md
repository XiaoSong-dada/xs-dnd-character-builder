# 跑团助手交互与弹窗滚动优化需求

> 实施状态：**已实现**（v0.6.4，2026-08）。实施与验收见《跑团助手交互与弹窗滚动优化-更新计划.md》。

## 1. 背景与目标

用户反馈三项体验问题（已确认方案）：

1. **生命值钳制**：跑团助手加血超过最大生命值时目前弹错误提示并拒绝，操作繁琐；目标为**自动满血**；同时减血低于 0 时**自动归零**（双向钳制，均不报错）。
2. **手机端双击放大**：跑团助手页面快速连点血量/金币/法术位/力竭等按钮会触发浏览器双击缩放，与赛博骰娘体验不一致；目标为**抽象可复用的「取消双击放大」能力**，跑团助手与赛博骰娘两页复用。
3. **弹窗滚动**：抄录法术书与新增物品弹窗内容过长时，整个弹窗（含标题、页脚确认按钮）一起滚动，操作不便；目标为**封装「标题与页脚固定、仅内容区滚动」的弹窗**，应用于这两个弹窗。

## 2. 现状调查（已核验）

### 2.1 生命值交互（`app/src/views/session-assistant/hooks/useSessionPanel.ts` `changeHp`）

```ts
const next = state.currentHp + delta
if (next > maxHp.value) { operationError.value = `生命值不能超过最大生命值（${maxHp.value}）`; return }
if (next < 0) { operationError.value = '生命值不能低于 0'; return }
```

- 越界（上/下）均**报错并拒绝**，无钳制；
- 界面：`SessionPanel.vue` 生命值区「− / ＋」按钮 + 输入框（空输入按 1），显示「当前 / 最大」。

### 2.2 双击放大（赛博骰娘参考实现）

| 位置 | 现状 |
|---|---|
| `src/views/dice/index.vue`（页面根） | `touch-action: manipulation`（静态） |
| `src/views/dice/components/DiceTray.vue` | 静态 `touch-action: manipulation`（211 行附近）+ **动态策略** `resolveTrayTouchAction`（交互启用时 `'none'` 以便拖拽骰盘、禁用时 `'manipulation'`） |
| 跑团助手 | **无任何 touch-action 处理** |

- `manipulation` 语义：保留页面滚动与双指捏合缩放，禁用双击缩放与触摸点击延迟；
- 全局工具类先例：`src/styles/flex.scss`（如 `.flex-between`），经 `index.scss` `@use` 全局生效。

### 2.3 弹窗结构（`src/components/ui/UiModal.vue`，8 个使用方）

```html
<Teleport to="body">
  <div class="ui-modal">
    <section role="dialog">   <!-- max-height: min(80dvh, 42rem); overflow: auto -->
      <header>…</header>      <!-- 随内容滚动 -->
      <div class="ui-modal__body">…</div>
      <footer>…</footer>      <!-- 随内容滚动 -->
    </section>
  </div>
</Teleport>
```

- 整个 `section` 单一滚动容器：标题与页脚随内容滚动，长内容时确认按钮不可见；
- 受影响弹窗：抄录法术书（`SpellbookTranscriptionModal`，候选列表长）与新增物品（`AddItemModal`，物品列表长）；且两者内部 `ListShell` 各有 `max-height`（12rem / 15rem）独立滚动，与外层滚动形成**嵌套双滚动条**；
- `AddItemModal.test.ts` 断言使用内部选择器（`.add-item-modal__qty button` 等），不依赖 `.ui-modal` 类名，弹窗组件替换不影响。

## 3. 需求项

### R1 生命值双向钳制（必须）

- 加血后 `next > 最大生命值` → 自动钳制为最大生命值（满血），**不弹错误提示**；
- 减血后 `next < 0` → 自动钳制为 0（归零），**不弹错误提示**；
- 实现：`changeHp` 计算后统一 `clamp(next, 0, maxHp)`；`operationError` 不再为 HP 报错（法术位/力竭等越界提示保持现状）；
- 输入逻辑（空输入按 1）与显示「当前 / 最大」不变。

### R2 「取消双击放大」能力抽象与复用（必须）

- 在 `src/styles` 新增通用工具类（如 `.touch-manipulation { touch-action: manipulation; }`，参照 `flex.scss` 工具类模式，经 `index.scss` 全局加载）；
- **跑团助手**：页面根（`src/views/session-assistant/index.vue` 或 `SessionPanel` 根，实现时取最小作用面）应用该工具类——快速连点血量/金币/法术位/力竭等按钮不再双击缩放，保留页面滚动与双指捏合缩放；
- **赛博骰娘复用**：`dice/index.vue` 页面根静态 `touch-action: manipulation` 改为复用该工具类；`DiceTray.vue` 的**静态 manipulation 部分**同样复用，**动态 `resolveTrayTouchAction`（交互启用时 `'none'` 拖拽骰盘）保留不动**，不得破坏骰盘拖拽交互。

### R3 封装「标题/页脚固定、内容滚动」弹窗（必须）

- 新增 `src/components/ui/UiScrollModal.vue`（与 `UiModal` 同级的通用弹窗封装）：
  - 接口与 `UiModal` 一致：`props { open, title }`、`emit close`、`Teleport to body`、插槽（默认内容 + `footer`）；
  - 结构：`section` 为 flex column，`max-height: min(80dvh, 42rem)` 保留；`header`/`footer` `flex-shrink: 0` 固定；内容区 `flex: 1; min-height: 0; overflow-y: auto` **仅内容滚动**；
  - 遮罩、关闭按钮、标题样式与 `UiModal` 保持一致。
- **应用于**（仅这两个弹窗，其余 6 个 UiModal 使用方不动）：
  - 抄录法术书弹窗 `SpellbookTranscriptionModal`：`UiModal` → `UiScrollModal`；
  - 新增物品弹窗 `AddItemModal`：`UiModal` → `UiScrollModal`。

### R4 消除嵌套滚动（必须）

- 抄录弹窗内部 `ListShell` 移除 `max-height="12rem"`；新增物品弹窗内部 `ListShell` 移除 `max-height="15rem"`——内容统一由弹窗内容区滚动，不再出现内外双滚动条；
- `UiModal` 本体及其余 6 个使用方**行为不变**。

### R5 测试与回归（必须）

- 跑团助手 HP：现有「输入 100 点 ＋ → 超过最大值被拒并提示」用例改为「超过最大值 → 自动满血（max / max）、无错误提示」；新增「减少超过当前值 → 归零（0 / max）、无错误提示」用例；
- 抄录弹窗与新增物品弹窗回归：现有用例保持通过（内部选择器不变）；确认长内容场景弹窗标题与页脚固定、内容区滚动（结构断言可选）；
- 骰娘回归：现有骰娘测试全量通过（动态 `'none'` 交互不受影响）。

## 7. 已确认决策（用户确认）

1. **弹窗范围**：新封装的滚动弹窗**仅**应用于抄录法术书与新增物品两个弹窗，`UiModal` 本体及其余使用方不动。
2. **HP 钳制**：加血超上限自动满血、**减血低于 0 自动归零**，均不报错。
3. **双击放大抽象**：`touch-action: manipulation` 抽象为可复用能力，跑团助手与赛博骰娘两个页面复用。
4. **嵌套滚动**：移除两个弹窗内部 `ListShell` 的 `max-height`，由弹窗内容区统一滚动。
