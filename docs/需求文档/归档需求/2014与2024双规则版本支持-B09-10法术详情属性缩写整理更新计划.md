# B09-10 法术详情属性缩写整理 · 更新计划

- 制定日期：2026-09-15。
- 对应问题：2024 法术**展开后的详情**文本含英文属性缩写（如「DEX豁免」），应显示为中文（「敏捷豁免」）。
- 依据：本轮只读统计（见第 2 节）；2024 详情文案由 B05 批次撰写时使用英文缩写，2014 详情为中文，两版口径不一致。
- 状态：计划制定完成，待按"制定任务文档 → 实施 → 验证"执行；按用户要求不自动提交。

## 1. 需求边界（严格限定）

| 项 | 处理 |
| --- | --- |
| 法术卡片**展开后的详情文本**（`spells-2024.ts` 的 `description` 字段） | ✅ 整理为中文 |
| 卡片标题行（`等级 · 中文名`／`englishName`，由 `formatSpellLabel` 渲染） | ❌ 不改 |
| 英文法术名／数据名／勘误编号（Alarm、Bestial Spirit、ER-007、PHB2024 等） | ❌ 不改 |
| 惯例缩写 DC／AC／CR／GP／DM、骰式（1d6）、成分（V、S、M）、单位 | ❌ 不改 |
| 物种／起源／职业／子职等其它数据文件与源码注释 | ❌ 不涉及 |
| 法术 ID、环级、学派、施法参数等结构化字段 | ❌ 不改（无 schema 变化、无需迁移） |

UI 依据：展开内容 = `spell.description`（`SpellcastingStep.vue:214/238/262`，`CharacterSheetStep.vue:765/781/810/826/845`）；标题行 = `formatSpellLabel(spell)`。

## 2. 现状统计（仅该字段）

- 2024 法术 391 条，**164 条（42%）详情含英文属性缩写，共 208 处**；2014 详情 0 处。
- 按缩写（法术数／出现次数）：DEX 51／55、WIS 50／55、CON 40／43、STR 17／24、INT 15／17、CHA 14／14。
- 按环级（受影响／总数）：0 环 9/34、1 环 26/64、2 环 20/63、3 环 23/52、4 环 20/41、5 环 24/48、6 环 15/34、7 环 10/21、8 环 10/18、9 环 7/16。
- 其他同类残留（同一字段）：`HP` 78 处（如"不能恢复HP""0HP"）、`HD` 1 处（魔魂壶 `HP/HD/STR/DEX/CON`）。
- 写法共 6 类（替换规则必须全覆盖）：
  1. `X豁免…`（约 153 处，主体）
  2. `X(技能)` 半角括号（`INT(调查)` 9+、`STR(运动)` 6+、`INT(奥术)` 1）
  3. `X检定`（如 `STR检定`）
  4. `X优势`／`X劣势`（如 `STR劣势`）
  5. 多属性并列（`STR/DEX/CON`、`INT/WIS/CHA`、`HP/HD/STR/DEX/CON`）
  6. 其余位置（如 `对DC` 前的 `STR(运动)`）

## 3. 修复设计

### 3.1 替换规则

| 原 | 新 |
| --- | --- |
| STR／DEX／CON／INT／WIS／CHA | 力量／敏捷／体质／智力／感知／魅力 |
| HP／HD | 生命值／生命骰 |
| 半角 `(技能)` | 全角 `（技能）` |
| 分隔符 `/`、`；`、`、` | 保持原样（只替换词，不重排句式） |

按 6 类写法处理：`X豁免`、`X(技能)`、`X检定`、`X优势`／`X劣势`、并列列表、其余；多属性并列逐项替换（`STR/DEX/CON` → `力量/敏捷/体质`）。

### 3.2 实施方式

1. 一次性脚本（不入库）只对 `spells-2024.ts` 中 `description: "…"` 内的文本做替换，**禁止**触碰 `englishName`／`name`／`slug` 及其它字段。
2. 替换后输出 before／after 统计（受影响条目数、各缩写出现次数、剩余匹配数应为 0）与逐条 diff 摘要，人工抽查。
3. 抽查覆盖：每环至少 2 条，并覆盖 6 类写法各至少 1 条（含 `INT(调查)`、`STR检定`、`STR劣势`、`STR/DEX/CON`、`HP/HD/…`）。

### 3.3 防回归测试

- 在 `test/rules/spells-2024.test.ts` 增加断言：所有 `description` 不含 `\b(STR|DEX|CON|INT|WIS|CHA)\b`，且不含 `\b(HP|HD)\b`。
- 在 `test/rules/spell-descriptions-2014.test.ts` 增加同样的属性缩写断言（现况自然通过，作为双版本口径守护）。
- 断言基于 `spells2024` 数据导出，直接锁住"展开详情"这一处。

### 3.4 字体与门槛

- 新增中文文本（如"生命值／生命骰"）后执行 `app/tools-subset/make-subset.py`，并重跑 `test/services/pdf-font.test.ts`。
- 每步门槛：`vue-tsc -b`、`vitest run`、`vite-ssg build`、`git diff --check`。
