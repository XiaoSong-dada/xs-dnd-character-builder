# 跑团助手 2024 显示修复 · 更新计划

> 缺陷来源：2024 角色在跑团助手中「能力」页签子职/职业特性为空、「法术」页签为空、「物品」显示英文 ID。
> **执行状态：已完成（未提交，等待用户指令）**。

## 1. 根因

会话助手显示层固定使用 **2014 单例仓库**做名称/条目查询，而草稿解析、派生与候选使用版本感知仓库：

- `app/src/rules/repository.ts:123`：`export const rulesRepository = rulesRepository2014`（B02 兼容入口）。
- `SessionPanel.vue` / `useSessionPanel.ts` 通过该单例查询 equipment／class／subclass／race／background／feat／spell／option；2024 的稳定 ID 在 2014 数据中不存在，于是回退为空或英文 ID。
- 对照：角色卡 `CharacterSheetStep.vue:47` 使用 `computed(() => getRulesRepository(props.draft.ruleset))`，因此 2014/2024 均正常。

## 2. 修复内容

### `app/src/views/session-assistant/components/SessionPanel.vue`
- 移除 `@/rules/repository`、`data/class-features-2014`、`data/subclass-features-2014` 导入；新增 `const repository = computed(() => getRulesRepository(props.draft.ruleset))`。
- 全部查询改为 `repository.value.*`：
  - 装备：`equipmentName/Description/Summary`、`weaponBonusLabel`、`handleAddItem` 的可装备判定。
  - 特性：`classFeatures` / `subclassFeatures` 改用 `getClass()?.features` / `getSubclass()?.features`（保留等级过滤）；`className` / `subclassName` / `raceName` / `subraceName` / `backgroundName`。
  - 专长：`featAndAsiEntries` 改用 `repository.value.getFeat(optionId)`。
  - 法术：已准备法术与戏法的 `getSpell(id)`。
- `<AddItemModal>` 补 `:ruleset="draft.ruleset"`（此前默认 2014 目录，2024 草稿可能加入 2014 物品）。

### `app/src/views/session-assistant/hooks/useSessionPanel.ts`
- 移除 2014 单例导入；新增 `repository` computed。
- `className`、`classHitDie`、法术书未准备列表（`unpreparedFromBook`）改为版本仓库。
