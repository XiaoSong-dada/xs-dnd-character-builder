# 关于本站更新计划

> 依据《关于本站需求文档》制定，目标版本 v0.8.0。

## 1. 实施目标

- 将“个人中心”完整替换为“关于本站”，导航与路由迁移至“关于”和 `/about`；
- 展示项目简介、永久免费声明、B站、GitHub、QQ 群反馈入口与可选“请杯咖啡”收款码；
- 不展示作者介绍、赞助名单、打赏记录或友情链接；
- 真实收款码由本地环境提供并排除 Git 追踪。

## 2. 实施步骤

1. 扩展 `siteConfig` 与环境变量声明，接入微信、支付宝可选收款码 URL；
2. 建立 Git 忽略的本地素材目录并配置本机 `.env.local`；
3. 将 `views/profile` 替换为页面 Hook 与私有组件内聚的 `views/about`；
4. 更新底部导航、信息图标、路由 meta、sitemap、robots 与 vite-ssg 清单；
5. 补充配置、页面交互、路由与 SEO 回归测试；
6. 同步架构、路由、SEO、README、CHANGELOG 与版本号；
7. 运行全量测试、生产构建、预渲染产物和 Git 安全检查。

## 3. 验收重点

- `/about` 可直接访问与预渲染，`/profile` 进入 404；
- QQ 群号复制成功与失败都有用户可见反馈；
- 双收款码可直接展示和点击放大，单项/无配置/加载失败均正常降级；
- 页面明确声明本站永久免费、打赏自愿且不解锁权益；
- `git ls-files` 与待提交变更均不包含真实收款码和 `.env.local`；
- `pnpm test:run` 与 `pnpm build` 全部通过。

## 4. 当前状态

- 配置、页面、路由、SEO 与核心测试：已实现；
- 文档同步：已实现；
- 全量测试：74 个测试文件、556 个用例通过；
- 生产构建与 vite-ssg 预渲染：通过，`/about` 产物包含唯一 H1、独立 meta、正文和公开入口；
- Git 安全检查：真实收款码与 `.env.local` 均未被追踪；
- 实施状态：已完成。
