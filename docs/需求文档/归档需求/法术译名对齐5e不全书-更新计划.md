## 目标与范围

- **根因**：全量法术名与 5e 不全书（CHM v2025.11.8）对照，**489 条中 273 条不一致**；用户确认以 5e 不全书译名为准（用户指定例外，与专长 46 项更名同一先例）。
- **已确认方案**：仅改 `spells-2014.ts` 的 `name` 展示字段（273 条）；`id`（基于英文名）、`englishName`、`description`、`summary` 均不动 → 草稿存档、导入导出完全兼容；展示层与导出（PDF/XLSX/JSON）自动跟随。
- **不改动范围**：description/摘要文本、其他类别名称（职业/专长/物品等）、2024 规则数据；不复制 CHM 正文（仅短名称术语）。

## 关键实施细节（已核验）

1. **兼容性**：`id = spellId(englishName)`，改名不影响 id；已 grep 核验组件与测试中无受影响的法术中文名硬编码——`CharacterSheetStep.test.ts` 断言「魔法飞弹」「魔能爆」两条法术与 CHM 一致，无需修改；`spell-descriptions-2014.test.ts` 断言为 `description` 内容（wish 含「愿望」），不涉及 `name`。
2. **改名位置**：`spells-2014.ts` `spellSeeds` tuple 第二项（`['English Name', '中文名', level, ...]`）。
3. **定稿来源**：需求文档第 5 节 273 条对照表（由 CHM 索引 `.chm_output/DND五版不全书v2025.11.8/index.json` 全量对照生成：489/489 命中、0 未匹配；匹配管线含英文名大小写不敏感、"/"两侧空格归一、结尾字母边界防前缀误匹配、别名表 Summon Lesser Demon(s)；按来源优先匹配同源章节，排除 PHB 2024）。分析脚本为临时产物（`C:\tmp\spell-compare\`，不入库），需求文档表为可审计记录。
4. **同名冲突**：273 条更名后全量 489 条 `name` 无重复（脚本已核验）；Message（传讯术）/Sending（短讯术）同名自动消解，无需额外人工改名。
5. **既有定稿覆盖**：本次会再次变更《名称译名规范化需求》中 16 条已定稿条目（烙印斩击→印记斩、圣焰击→焰击术、远距传讯→短讯术、死亡之指→死亡一指等，清单见需求文档 4.2），属标准切换，登记为用户指定例外。
6. **版本号**：当前 v1.1.4，本次发布拟 **v1.1.5**（执行时确认）。
