## 1. 目标与范围

目标：把《5e 不全书》收录的 11 个第三方合作内容的 251 条法术录入 2014 目录，来源可显式开启，条目显示「合作内容／需 DM 同意」提示；默认关闭，不影响不使用第三方的草稿。

范围内：

| 域 | 数量 | 内容 |
| --- | --- | --- |
| 第三方来源 | 11 | 见 §2.1 |
| 法术条目 | 251 | 中英文名／环级／职业归属（或特殊获取）／来源／`ritual`／原创中文摘要 |
| 来源模型 | 1 | `RuleSource.defaultEnabled` + `contentKind: 'third-party'` + 来源步骤分组与提示 |
| 测试文档 | — | 默认关闭、开启后可选、关闭不破坏旧草稿、名称唯一性、`docs/rules.md` |

范围外：第三方书的其他内容（职业、子职、专长、种族、背景、魔法物品）；不全书未翻译的第三方内容；自动比对校验（D-06）。

## 3. 设计

### 3.1 来源模型（S03-00）

- `app/src/types/character.ts`：`RuleSource` 增加 `readonly defaultEnabled?: boolean`（缺省视为 `true`）；`contentKind` 联合类型扩展为 `'official' | 'playtest' | 'third-party'`。
- `app/src/rules/data/sources-2014.ts`：11 个第三方来源 `category: 'supplement'`、`selectable: true`、`defaultEnabled: false`、`contentKind: 'third-party'`。
- `app/src/rules/source-books.ts`：`getDefaultEnabledSourceIds('5e-2014')` 过滤 `defaultEnabled !== false`；`normalizeEnabledSourceIds` 白名单、`isSourceEnabled` 行为不变（显式开启后即生效）。
- `app/src/views/character-builder/components/SourcesStep.vue`：来源分为三组——核心（只读）、正式扩展（现有）、合作内容（第三方，含「合作内容／需 DM 同意」提示）；「全部启用」按钮的语义需确认（建议仍启用全部可选来源，含第三方，但保留「只用核心规则」按钮；也可改为「全部启用」不含合作内容——实施时二选一并写入文档）。
- 旧草稿兼容：v2—v4 的 `inferEnabledSourceIds` 已按草稿引用内容推断来源，第三方来源开启后可正常恢复；关闭来源沿用既有非破坏语义。

### 3.2 法术条目（S03-01—S03-03）

- 落在 `spells-2014.ts`：seed + `spellDescriptions` 摘要 + 可选字段。
- 稳定 ID：`spell-2014-<英文名小写连字符>`；重名法术按系列分别登记时需避免 ID 冲突（同一英文名的两条要显式区分，如加系列后缀，实施时定稿）。
- `classIds`：按各书注释映射到 `class-2014-*`；标签与「受污染」不进 `classIds`，另行登记说明。
- `sourceIds`：对应系列 ID；`ritual` 按 CHM 行填布尔。
- 中文名／英文名以 CHM 为准；摘要为原创中文转述，不复制正文。

### 3.3 提示与展示（S03-05）

- 来源步骤：合作内容分组 + DM 提示（参考现有「破解奥秘为游玩测试内容」提示的写法）。
- 法术条目：来源标签显示为「合作内容」；详情说明「非官方内容，需 DM 同意」。
- 更新公告与 `docs/rules.md` 同步说明第三方范围与默认关闭。

### 3.4 不改动项

- 不把第三方来源加入默认开启；不改 `SpellRule` 结构；不接入第三方其他内容类型；不做自动比对校验。
