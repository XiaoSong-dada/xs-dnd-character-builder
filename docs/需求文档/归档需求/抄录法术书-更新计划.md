# 法师抄录法术书 · 更新计划

> 依据《docs/需求文档/抄录法术书需求.md》制定。本文件为实施计划存档，执行时按阶段推进。
> **执行状态：已完成**（v0.6.3，2026-08）。

## 目标与范围

- **规则层**：新增 `src/rules/spellbook.ts`（纯函数）：抄录候选、费用（环级 × 50 GP）、金币校验、抄录应用（一次 patch 原子写回 `spellSelections` 与 `adventureGold`）；`validate.ts` 法术书校验由「严格等于」改为「至少达到」并新增转录子集校验。
- **类型与持久化**：`CharacterDraft.schemaVersion` 3 → 4；`SpellSelections` 新增 `transcribedSpellIds`；`draft-storage.ts` / `character-json.ts` 迁移与导入兼容；`stores/character-drafts.ts` 默认值同步。
- **共享功能**：新增 `src/features/spellbook-transcription/`（Modal 组件 + hooks），角色卡与跑团助手两个调用方复用。
- **角色卡**：`CharacterSheetStep.vue` 法术页签新增「抄录法术」入口与「抄录」徽标。
- **跑团助手**：`SessionPanel.vue` 法术页签新增「抄录法术」入口与**「未准备法术」区**（法术书中未准备，支持「准备」操作）；`useSessionPanel.ts` 增加准备切换与抄录写回。
- **明确不做**：抄录撤销/移出/退款；时间（2 小时/环级）持久化；车卡流程 `SpellcastingStep` 提供抄录；戏法抄录；非法师职业抄录；规则版本切换。

## 已确认决策（用户确认）

1. **入口**：角色卡「法术」页签为主入口；能力抽象共享（`features/spellbook-transcription`），跑团助手「法术」页签同样可调用；两侧操作同一草稿的 `spellSelections` 与 `adventureGold`，法术书共同。
2. **候选池**：仅法师职业法术池（`classSpellIds`），环级 ≥ 1、≤ 当前最高可施放环、未入书的法术；不含戏法。
3. **不可撤销**：本版本抄录后不允许移出/删除/退款；升级/降级不影响已抄录法术。
4. **时间不记录**：2 小时/环级仅作弹层提示文案，不持久化、不参与计算。
5. **费用与金币**：环级 × 50 GP，扣 `adventureGold`，持有总额不得为负；入书与扣款同一次 `updateDraftById` patch 原子完成。
6. **跑团助手补展示**：法术页签下方新增「未准备法术」（法术书中未准备）区，支持「准备」操作，受准备上限约束。

## 待执行时确认点

1. **弹层形态**：`UiModal` 弹层（与施放弹层/导出菜单一致）为默认方案；若移动端候选列表过长，考虑页内面板滚动（375px 宽度下弹层高度），实现时按实际渲染定。
2. **入口按钮位置**：默认法术书区标题行「抄录法术」按钮 + 「未写入法术书」区卡片「抄录」按钮双入口（需求一致、路径短）；若视觉过挤只保留标题行入口。
3. **多选 vs 单选**：需求文档按「多选 + 合计」设计（弹层内勾选多个法术一次确认）；若交互负担过大可退化为单选逐个抄录，不影响规则层与数据模型。
4. **跑团助手「取消准备」**：本计划未准备区只提供「准备」按钮；已准备区是否对称提供「取消准备」（与角色卡一致）按实际需要决定，不阻塞本需求。
5. **规则函数落点**：新建 `src/rules/spellbook.ts` 保持职责内聚（spellcasting.ts 已 164 行，不继续膨胀）。
6. **store 写回通道**：共享 feature hook 直连 `store.updateDraftById`（与 `useSessionPanel` 模式一致）；角色卡侧不动现有 emit 通道。
