# 种族熟练项接入 · 更新计划

> 依据《docs/需求文档/种族熟练项接入需求.md》制定。本文件为实施计划存档，执行时按阶段推进。

## 目标与范围

- 为项目中全部提供熟练项的种族接入：**固定技能熟练**（11 条）、**自选技能熟练**（13 处，一次性全做）、**武器/护甲熟练**（10 条，展示级）、**工具熟练**（矮人/战俑/维达肯/吉斯洋基，含选择 UI）。
- 技能熟练派生并入种族来源，来源标注"来自种族"；2014 无重复替换机制（重叠不叠加）。
- **TODO（后续批次）**：工具熟练参与检定派生（需先建工具检定模型）；武器熟练来源区分；矮人石工/岩石侏儒工匠知识等特殊 expertise 类检定。

## 关键实施细节（已核验）

1. **技能 ID 体系**：18 项技能 `skill-*`（`derive.ts` 134—152 行）；工具选项 `tool-*`（`martials-2014.ts` 105—108 行：`tool-thieves-tools`/`tool-artisans-tools`/`tool-musical-instrument`/`tool-poisoners-kit`），名称经 `rulesRepository.getOption` 解析；背景工具 `backgroundToolIds` 同体系。
2. **工具选择选项**：复用现有 `tool-*` 选项列表（含"一种工匠工具"大类，与武僧工具检查点一致）；具体工匠子类（炼金/酿酒等）不新增选项（如需细分属后续）。
3. **父种族继承**：子种族熟练 = 父链全部 + 自身（精灵子种族继承察觉；地底矮人继承矮人武器/工具；兽化人基础察觉 + 子系各加固定项）。变体人类 `replacesParentBonuses` 只替换属性，人类无熟练，无冲突。
4. **草稿兼容**：`raceSkillChoices`/`raceToolChoice` 为可选字段，旧草稿缺省空数组/undefined，行为不变。
5. **换种族清理**：`useCharacterBuilderPage` 更新种族/子种族时重置自选结果（与 `raceAbilityChoices` 同模式，实现时核对 hook 位置）。
6. **角色卡来源展示**：`derive.ts` 来源数组加"来自种族"detail 后，角色卡技能 note（`sources.map(detail)`）自动显示，无需改角色卡。
