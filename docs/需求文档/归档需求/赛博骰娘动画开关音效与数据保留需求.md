# 赛博骰娘动画开关、音效与数据保留需求

## 1. 文档状态与范围

- 整理日期：2026-09-04。
- 状态：需求已确认并实现；验证记录见同目录更新计划。
- 目标：产品主项目 `app` 的 `/dice`「赛博骰娘」页面。
- 最初仅整理需求；后续已获用户授权按更新计划实施，仅修改产品项目，不调整原型图。

## 2. 用户已明确的目标

1. 增加「跳过动画」开关，打开后不播放动画，直接计算并展示数值。
2. 骰娘投掷动画需要有投掷声音。
3. 页面切换不能使骰娘数据重置。数值必须保留；如果保留动画较麻烦，可以清空动画。

优先保证结果可靠保留，不以保留 3D 场景或动画进度作为实现前提。

## 3. 现状核验

- `app/src/views/dice/index.vue` 组装骰型选择、骰池、骰盘和结果面板，当前没有用户控制的「跳过动画」开关。
- `app/src/views/dice/hooks/useDicePage.ts` 将骰池、结果和待公布结果保存在页面内部状态中，重新创建页面时初始化为空。
- 当前投掷先通过 `prepareRoll` 生成结果，再进行物理预演和动画播放，播放结束后公布结果。已有渲染不可用、物理失败和超时后的文字结果降级流程。
- 当前存在系统「减少动态效果」适配，但它不等同于用户主动选择的「跳过动画」开关。骰娘模块未发现音效接入。
- 页面卸载时会终止 Worker 并清理计时器，但结果未交由独立于页面生命周期的状态管理。

以上为代码阅读结论，本次未执行浏览器复现。

## 4. 功能需求

### R1 跳过动画

- 页面提供含义明确的「跳过动画」开关，开启后点击投掷直接展示逐颗结果及总和，不等待物理预演、动画播放或动画超时。
- 跳过动画仍使用相同的随机规则、骰型范围、骰池限制和 `d100` 换算规则，不能改变数值的生成方式或公平性。
- 主动跳过动画属于正常投掷方式，不显示为设备故障或超时降级。
- 关闭开关后，后续投掷恢复动画流程。
- 切换开关本身不得触发重新投掷、改变或清空已得到的结果。

### R2 投掷音效

- 播放投掷动画时配有骰子投出、滚动或碰撞的声音，使听觉与投掷过程匹配。
- 声音随本轮投掷结束而停止；离开页面、取消动画或动画异常终止时，不应在其他页面继续播放。
- 同一次投掷不得因重复回调或重新进入页面重复播放声音。
- 音效加载或播放失败不能阻塞结果计算与展示。
- 不要求首期实现逐颗骰子、每次碰撞的精确声音模拟，具体音效素材与实现方式留待开发阶段选择。

### R3 页面切换后保留数据

- 在应用内离开骰娘页面，再通过导航或浏览器前进、后退返回时，已产生的逐颗点数与总和必须保持一致，不能重新随机、归零或消失。
- 保留结果应包含可解释数值的完整信息：骰型、每颗骰子的点数，以及 `d100` 的组成读数；不能只留下总和。
- 同时保留骰池的骰型和数量，保证返回后仍可使用原骰池再次投掷。
- 允许清空动画轨迹、骰盘中的 3D 骰子、视角及动画进度。动画被清空不应影响结果区展示。
- 返回页面不自动投掷、不自动重播上一次动画或声音。
- 数据保留针对页面切换；用户主动再次投掷、修改骰池或清空骰池仍按明确的操作语义处理，不等同于永久锁定旧结果。
- 本需求不要求新增多轮投掷历史记录。

## 5. 已确认行为与实施默认值

用户确认仅页面切换保留、独立音效开关且跳过时静音、离页结算本轮；其余默认值随更新计划获授权实施。

| 事项 | 确认行为 |
|---|---|
| 开关初始状态 | 「跳过动画」默认关闭，保留现有动画体验 |
| 设置保留 | 应用内切换页面后保留开关选择；浏览器刷新后恢复默认值 |
| 跳过动画时的声音 | 同时跳过投掷音效，立即显示结果 |
| 音效控制 | 增加独立音效开关，动画模式默认开启音效；用户可静音 |
| 投掷过程中切换动画开关 | 当前轮进行中禁用该开关，下一轮再调整 |
| 投掷过程中离开页面 | 若本轮已生成数值，保留并结算该轮结果，停止动画和声音；返回直接查看该轮数值，不重新掷骰 |
| 浏览器刷新、关闭后重开 | 刷新或重开后不恢复骰池、结果与设置 |
| 修改骰池后的旧结果 | 沿用现有行为：增减或清空骰池使当前结果失效；仅切换页面不得使结果失效 |

## 6. 验收标准

### 核心需求验收

1. 开启「跳过动画」，投掷混合骰池：不出现投掷动画，也不等待物理预演完成，直接显示逐颗点数和正确总和。
2. 关闭「跳过动画」后再次投掷：恢复动画，并可听到与投掷过程匹配的声音。
3. 一次投掷完成后，记录骰型、逐颗点数和总和；切换到其他页面再返回，多次往返后结果仍完全相同。
4. 包含 `d100` 的结果在返回后仍能展示组成读数和换算值，总和不重复计算两颗十面骰。
5. 即使返回后骰盘为空，文字结果仍完整可读，且不自动重新投掷或重播声音。
6. 离开骰娘页面后投掷声音停止；模拟音效不可用时仍可正常获得结果。
7. 改变动画开关不改变已经生成的数值；两种模式均遵循现有骰型范围和合计规则。

### 已确认补充验收

- 返回页面后，骰池配置与动画、音效设置保持原值。
- 动画尚未结束时离开，返回仍可看到本轮已生成的结果，不停留在无法恢复的「投掷中」。
- 旧 Worker 响应或动画回调不能覆盖返回后已展示的结果或新一轮结果。
- 关闭音效或开启跳过动画后投掷，不播放声音。

## 7. 后续实施边界
