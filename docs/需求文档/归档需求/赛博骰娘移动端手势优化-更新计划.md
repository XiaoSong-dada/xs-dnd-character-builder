# 赛博骰娘移动端手势优化更新计划

## 1. 目标

治理 `/dice` 页移动端浏览器原生手势与 3D 骰盘手势的冲突，解决真机反馈的四个问题：双击触发页面缩放、手指左右移动不友好/无法移动、双指平移不跟手、增减骰子时误触发页面缩放。

方案核心：

- 页面级禁用双击缩放（页面主体与全部可点击控件 `touch-action: manipulation`），**保留双指捏合缩放**（可访问性不损）；
- 骰盘 canvas 按交互状态切换 `touch-action`：交互禁用期 `manipulation`（页面可滚动、禁双击缩放），交互启用期 `none`（双指手势全部交给 3D 控件）；
- 手势语义保持 v1.1：双指捏合缩放 + 双指拖动平移，单指不控制相机；
- 结果公布进入交互启用态时，在骰盘内展示双指操作提示，自动消失、不阻断操作。

兼容底线：**最低支持 `iOS 15+` 与对应 Android Chrome，不兼容 iOS 15 以下旧版本**。

## 3. 实施步骤

1. **页面级防误缩放样式**：骰娘页主体与全部可点击控件声明 `touch-action: manipulation`，覆盖骰型卡片、骰池增减、投掷/再次投掷/清空、视图控制按钮；评估是否沉淀为通用可点击元素样式约定（不得影响其他页面现有行为）。
2. **`dice-renderer.ts` 手势状态机**：在 `setInteractionEnabled` 中按交互状态切换 canvas 的 `touch-action`（禁用期 `manipulation` / 启用期 `none`）；保持 `touches.ONE = null`、`touches.TWO = DOLLY_PAN` 语义不变；启用期确保 OrbitControls 独占手势、无浏览器竞争。
3. **`DiceTray.vue` 提示浮层**：新增双指操作提示（文案"双指拖动移动视图 · 双指捏合缩放"或实际体验后的最终文案）；进入 `complete` 且有展示结果时展示，3—5 秒自动消失，新一轮结果重新展示；`role="status"` 柔和播报、不抢焦点；`prefers-reduced-motion` 下不播动画；不遮挡结果区与视图控制按钮。
4. **`DiceTypeSelector.vue` / `DicePoolPanel.vue`**：按钮防误缩放声明（步骤 1 的落地）。
5. **测试**：交互状态到 `touch-action` 的映射若沉淀为纯逻辑则补单元测试；提示展示/自动消失/新一轮重新展示逻辑单元测试；现有 R10 相机测试（缩放平移只改摄像机）保持通过。
6. **文档同步**：`docs/frontend-architecture.md`（如依赖拓扑或公共样式变化）、`赛博骰娘需求.md`（R10 关联说明）、README（如适用）。
7. **全量验证**：TypeScript 类型检查、全量测试、生产构建、浏览器控制台无错误。
8. **真机验收矩阵**：iPhone（Safari）、iPad（Safari）、Android（Chrome）各至少一台，覆盖双指捏合、双指平移、双击、按钮连点、提示展示五类场景。

## 4. 验收标准

### 4.1 自动化

- 手势状态映射与提示逻辑测试通过（如引入）。
- 现有 R10 相关测试通过：缩放和平移只改变摄像机状态，不改变物理轨迹、随机结果或总和。
- TypeScript 类型检查、全量测试和生产构建通过。

### 4.2 人工（真机矩阵，iOS 15+ / Android Chrome）

1. 结果公布后双击骰盘与任意按钮：页面不缩放，每次点击都生效。
2. 双指平移跟手、双指捏合缩放正常且页面本身不缩放。
3. 连点 `+` 十次：数量正确增加，无点击丢失、无页面缩放。
4. 交互启用期之外单指滚动页面正常；结束后滚动恢复。
5. 结果公布后双指提示出现并自动消失；新一轮结果公布后重新出现；提示存在期间操作不受阻断。
6. 投掷/清空后视图复位、滚动恢复、提示正确隐藏。
7. 切换页面再返回：无手势监听或 `touch-action` 残留，无控制台错误。
8. 桌面端回归：滚轮缩放、拖动平移、按钮操作正常。

## 5. 风险与注意

- **iOS Safari 手势行为**：`touch-action: manipulation` 禁双击缩放、保留捏合缩放；`none` 在交互启用期独占手势。iOS 15+ 支持完整，需在真机确认无残余竞争。
- **不要全局禁用缩放**：不使用 `user-scalable=no` / `maximum-scale=1`，保留页面捏合缩放以满足可访问性（WCAG 1.4.4）。
- **提示克制**：浮层自动消失、不阻断操作、不抢焦点，避免干扰玩家查看骰子结果。
- **最小改动**：不修改物理、随机、总和、超时降级逻辑；不改变骰盘布局与视图控制按钮样式。
