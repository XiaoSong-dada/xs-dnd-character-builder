# 法术伤害成长标注完善需求

## 1. 背景与目标

用户反馈：法表详情（法术列表的效果摘要）需要确认是否完善，重点关注**随等级/环位提升伤害**的法术信息，即：

- **戏法随角色等级成长**：5 级、11 级、17 级时伤害骰增加（如火焰箭 1d10 → 2d10 → 3d10 → 4d10）；
- **高环施放（upcasting）成长**：用更高环位施放时伤害/数值增加（如燃烧之手每高 1 环 +1d6）。

现状根因（已核验）：`spells-2014.ts` 的摘要表 `spellDescriptions` 已为全部 489 条法术登记原创中文摘要，但**"等级/环位成长"信息的登记不完整、口径不一致**：基础书部分法术（如 `cure-wounds`、`fireball`、`magic-missile`、`scorching-ray`、`armor-of-agathys`、`aid`、`animate-dead`、`elemental-weapon`、`magic-weapon`、`healing-spirit`、`crown-of-stars` 等）已按"每高 1 环 +X"或"5/11/17 级 +X"风格标注，但仍有大量有成长条款的法术漏标，且存在个别戏法成长标注完全缺失。

目标产物：补齐全部与等级/环位相关的伤害成长标注，统一表述口径，并建立防止再次漏标的回归测试。

**缺口 D：个别扩展书法术摘要缺基础伤害骰（顺带修复）**

### 2.2 测试层：无成长标注完整性回归测试（核心缺口）

`test/rules/spell-descriptions-2014.test.ts` 仅校验"摘要非空 + 个别法术抽查含伤害骰"（`fire-bolt` 含 1d10、`fireball` 含 8d6、`toll-the-dead` 含 1d12 等），**不校验**：

- 全部伤害性戏法均含"5/11/17"成长标注；
- 全部有高环施放条款的法术均含"每高 1 环"标注。

这是本次缺口 A/B 未被发现的直接原因，必须补测试。

### 2.3 结论

- 摘要体系与展开交互已完备，**无需改动类型、UI 组件或选择逻辑**；
- 缺口集中在 `spellDescriptions` 数据表的成长标注：1 条戏法缺标（雷鸣掌）、约 99 条 upcasting 缺标、一批扩展书戏法口径不一致；
- 测试缺成长标注完整性校验。

## 3. 需求项

### R1 数据层：补齐戏法等级成长标注（核心）

1. 雷鸣掌 Thunderclap 摘要补成长标注，风格与基础书戏法一致：`1 动作，自身；1.5 米内所有目标体质豁免失败受 1d8 雷鸣伤害；5/11/17 级伤害 +1 骰。`
2. XGtE/TCoE 戏法统一口径：将"5/11/17 级提升"统一为"5/11/17 级伤害 +1 骰"（燃火术、冻伤术、虫群侵袭、原始野蛮、亡者丧钟、光辉之语、闪电牵引、心灵利刺、剑刃爆发；原始野蛮 1d10、亡者丧钟 1d8、其余 1d6 基础骰）。
3. 雷鸣刃 / 绿焰刃补具体数值：`5/11/17 级伤害提升` → 按 TCoE 原书转述（如绿焰刃：5 级武器命中额外 1d8 火焰、11 级 2d8、17 级 3d8，溅射伤害同步提升；雷鸣刃含移动触发伤害同步提升）。
4. 摘要仍为只读展示文本，**不进入自动计算**；不改 `SpellRule` 类型、`CharacterDraft` / `SpellSelections`，导入导出完全兼容。

### R2 数据层：补齐高环施放（upcasting）成长标注（核心）

1. 按第 2.1 节缺口 B 清单，为每条法术摘要追加"每高 1 环 +X"标注（与既有条目风格一致，如 `cure-wounds`：`每高 1 环 +1d8`；`magic-missile`：`每高 1 环 +1 枚`；`armor-of-agathys`：`每高 1 环 +5`）。
2. 多条成长规则（如梅尔夫强酸箭初始与后续骰均成长）须完整转述，不得只写一条。
3. 清单内法术若摘要本身缺基础伤害骰（缺口 D：龙卷风、痛苦真言、幻影龙、疯狂黑暗），先补基础骰再补成长标注。
4. 实现时以 `5e.tools` 2014 数据逐条核对清单数值；核对后发现清单与实际不符的，以规则来源为准修正，并在交付说明中记录差异。

### R3 测试：成长标注完整性回归测试（核心）

在 `test/rules/spell-descriptions-2014.test.ts` 增加：

1. **戏法成长完整性**：维护"应有 5/11/17 成长标注的戏法 ID 清单"（23 条伤害性戏法，含雷鸣掌），断言清单内每条摘要均含 `5/11/17`；断言摘要不含 `5/11/17` 的戏法不在清单中（双向防漏）。
2. **upcasting 完整性**：维护"应有每高 1 环标注的法术 ID 清单"（约 99 条），断言清单内每条摘要均含 `每高 1 环`；清单外法术摘要不得包含 `每高 1 环` 字样（防误标与防漏标）。
3. 新增或修改的摘要继续满足既有断言（非空、无占位文本、summary 职责分离）。

> 采用 ID 清单快照而非正则自动判定，避免把"无伤害/无成长"法术误判为漏标。

## 4. 非目标与边界

- **不按角色等级动态计算/展示伤害**：如"5 级法师的火焰箭显示 2d10"需要把戏法成长规则接入规则计算层并派生展示，涉及"未经核验的具体效果不得进入自动计算"边界与较大改动，**另行立项**；本次摘要为静态说明文本，不改变"效果以规则来源为准"的定位。
- **不改展示交互**：`ExpandableOptionCard` 展开区已承载摘要，选择/候选/上限逻辑均不动。
- **不扩展现有导出**：PDF/XLSX 模板无法术效果字段，本次不涉及导出内容变更。
- **不强制补非伤害类 upcasting**（目标数、持续时间成长）：可顺带统一，不计入验收。
- **不重写全部摘要**：缺口 D 仅修与等级成长相关的 4 条，其余法术的效果摘要完整性问题不在本次范围。
- **不复制原书正文**：继续遵守版权约定，全部成长数值以原创转述方式追加。
