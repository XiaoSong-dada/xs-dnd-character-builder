# 赛博骰娘布面音效与开关视觉优化—更新计划

## 1. 已确认目标与实施结果

- 采用合成方案并交付可试听样本；没有引入外部音频、依赖或版本变更。
- 音效改为柔和落地、细碎滚动、轻微停稳三层序列。低频主体 120—220Hz，滤波噪声截止频率 350—1100Hz，起音约 4ms，衰减在动画截止前结束。
- 根据实际动画时长安排前 10% 投出、其后滚动、最后 10% 停稳；最多 16 次触碰。物理骰数量影响密度，d100 按两颗计数。
- 设置开关改为 72×44px、8px 内边距、22px 圆角，滑块 28px、位移 28px；两者禁止 flex 收缩，增加轻微阴影和 160ms 过渡，减少动态效果时禁用过渡。
- 保持既有设置语义、动画与总等待上限、结果展示位置和跨页面结果保留。

## 2. 实现与接口

- `DiceAudio.play(durationMs, physicalDiceCount)` 接收页面已有的物理数量。
- `services/dice-audio/synthesis.ts` 在 CPU 上离线生成 PCM，实时播放与 WAV 试听使用同一份合成逻辑。每轮用独立确定性序列改变触碰音色，绝不读取或改变点数随机源。
- 三层信号合成进一个缓冲后播放，避免为每颗骰子维护独立音轨。缓存短噪声缓冲，声音节点数量保持为一个。
- 按重叠包络上界统一缩放，再经无延迟软压缩限制输出。使用同一 PCM 软压缩替代实时专用压缩节点，使试听与实际输出一致且没有压缩器前视延迟或尾音。
- 声源自然结束时断开连接；stop/dispose 清除回调、停止并断开连接，dispose 同时释放缓存与 AudioContext。异步 resume 完成不会调度播放。
- 合成仅在客户端真正播放时执行，预渲染不创建 AudioContext。
