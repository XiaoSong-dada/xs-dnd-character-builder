## 1. 范围与设计

- `reconcileSessionLimits` 扩展第 6 个可选参数 `resources: readonly { id; max }[]`：
  - 已用资源（含免费施法，两者共用 `resourceUsage`）按新上限钳制到 `[0, max]`；
  - 已不存在的条目（降级失去特性、换职业、改规则集）直接移除；
  - 休息快照中的 `resourceUsage` 同步做同样处理，保证撤回休息后不越界；
  - 省略该参数时保持既有行为（兼容旧调用）。
- `character-drafts` Store 的 `replaceDraft` 统一传入新草稿的资源上限：每次草稿写入（升级／降级、换职业、改装备背景导致的资源变化、金币与物品写回）都会重算 `listSessionResources` 并协调局内状态；生命骰总数继续按 2024 等级传入。
- 两版并存与刷新恢复：局内状态按草稿 id 隔离存储（`session-state-storage`），切换角色重新挂载面板时按 id 读取；2014 草稿没有资源登记，协调结果保持为空，休息行为不变。
- 不包含：物品充能字段（Q-B10-5）；跨会话导出（B11）。
