# 种族与装备效果展开展示需求

## 1. 背景与目标

用户反馈：法术列表已支持可展开的效果详情，但**种族与装备**仍只有一行简介，车卡时无法了解完整信息：

- 种族卡片只显示一行 `summary`（如"坚韧、耐久，拥有黑暗视觉。"），看不到体型、速度、感官、语言与种族特性细节；
- 装备只有简短 `description`（如"轻甲，AC 11 + 敏捷调整值。"），**武器完全没有伤害数据**——玩家无法得知"这把武器加多少伤害、什么伤害类型"。

目标产物：

- **种族**与**装备**条目升级为可展开卡片，展开样式**与法术展开完全一致**（复用 `ExpandableOptionCard`，见 `docs/需求文档/法术效果展开展示需求.md` R2 视觉基线）。
- 数据层补齐：种族新增详细介绍字段；装备新增武器伤害字段并完善全部类目（武器/护甲/盾牌/工具/用品）详情。
- 覆盖范围（已确认）：起始装备步骤（`EquipmentStep`）与角色卡物品页签（`CharacterSheetStep`）均接入；装备全部类目都展开。

## 2. 现状调查（已核验）

### 2.1 种族：只有一行摘要

| 模块 | 现状 |
|---|---|
| `app/src/types/rules.ts` `RaceRule`（146–164 行） | 字段：`id / name / englishName / summary / parentRaceId / subraceIds / fixedAbilityBonuses / speed / flexibleBonus* / recommendedClassIds / status / sourceIds`；**无详细介绍字段** |
| `app/src/rules/data/origins-2014.ts` | 9 个基础种族 + 子种族 + 变体人类共约 20 条；`summary` 为一行概括（如矮人"坚韧、耐久，拥有黑暗视觉。"） |
| `OriginStep.vue`（62–88 行） | 种族/子种族用 `OptionCard` 平铺：`title=name`、`description=summary + 推荐理由`，无展开能力 |
| 资料现状 | `docs/dnd-species.md` 与 `docs/species/5e-2014/*` 已登记种族资料（体型、速度、感官、语言、特性），可作原创转述依据 |

### 2.2 装备：有简介但武器无伤害数据（核心缺口）

| 模块 | 现状 |
|---|---|
| `app/src/types/rules.ts` `EquipmentRule`（183–197 行） | 字段：`id / name / description / classIds / equippable / weaponKind / contents / armorBase / addsDexterityToArmor / armorDexterityCap / armorClassBonus / category / sourceIds`；**无武器伤害字段**（无 `damageDice` / `damageType`） |
| `app/src/rules/data/equipment-2014.ts` | 共 144 条；`description` 简短（如"轻甲，AC 11 + 敏捷调整值。""装备时AC +2。"）；武器条目只登记 `weaponKind`（如 `simple-melee`），**无伤害骰与伤害类型** |
| `EquipmentStep.vue` | 起始装备：分组选项用 `OptionCard`（`description` 显示"还需选择 N 件具体物品"）；pick 行具体装备为 `<span>名称</span> + 数量按钮`，无详情展示 |
| `CharacterSheetStep.vue` 物品页签 | `已装备`/`物品栏`为纯文字列表（`join('、')`），无条目级详情 |

### 2.3 结论

- 种族需要**新增详细介绍字段**并登记（约 20 条）；装备需要**新增武器伤害字段**并完善全部 144 条详情。
- 展开能力直接复用 `ExpandableOptionCard`（法术展开样式），组件无需改动；三处界面（`OriginStep` / `EquipmentStep` / `CharacterSheetStep` 物品页签）接入。
- 版权约束与法术一致：详细介绍为**原创中文转述**（基于 `docs/species/*` 资料与 SRD 公共数据），不复制原书正文。

## 3. 需求项

### R1 数据层：种族详细介绍

1. `RaceRule` 新增 `readonly description: string` 字段（与 `summary` 并存；`summary` 保留一行概括，`description` 为展开区详细介绍）。
2. 内容为**原创中文转述**，覆盖：体型、速度、感官（如黑暗视觉）、语言、种族特性要点（如矮人耐久、精灵对魅惑豁免优势等），以及子种族差异要点；风格与法术摘要一致（简洁要点式，不复制原文）。
3. **登记范围**：9 个基础种族 + 全部子种族 + 变体人类（约 20 条）全部登记。
4. 摘要为只读展示数据，不进入自动计算；不新增 `CharacterDraft` 字段。

### R2 数据层：装备详情与武器伤害

1. `EquipmentRule` 新增武器伤害字段：`damageDice?: string`（如 `'1d6'`）、`damageType?: string`（如 `'穿刺'`）；仅武器条目使用，其余类目不填。
2. 完善 `description`（或新增 `detail` 展示字段，二选一由实现定，推荐直接扩展 `description` 语义为"展开区详情"）：按类目覆盖——
   - **武器**：伤害骰 + 伤害类型 + 关键特性（灵巧/轻/重/双手/投掷/弹药/触及/两用等）；
   - **护甲**：AC 计算、力量需求（如有）、隐蔽劣势（重甲）；
   - **盾牌**：AC 加值；
   - **工具/施法用品**：用途一句话；
   - **冒险用品/装备包**：内容物或用途说明。
3. **登记范围**：全部 144 条装备（武器约 30+、护甲 12、盾牌、工具、用品、装备包）一次性补齐。
4. 版权合规：武器伤害骰与类型属 SRD 公共表数据，可登记；特性与描述为原创转述。

### R3 界面接入（复用法术展开样式）

三处界面接入 `ExpandableOptionCard`（视觉/交互与法术展开完全一致：右侧 `›` 箭头展开、双击展开、单击选择、键盘可达）：

1. **`OriginStep.vue`**：种族与子种族卡片由 `OptionCard` 换为 `ExpandableOptionCard`，`expandedLabel="种族介绍"`，展开区注入 `race.description`；推荐徽标保留在操作位；选择行为不变。
2. **`EquipmentStep.vue`**：
   - 分组选项卡片 → `ExpandableOptionCard`，展开区列出该选项实际包含的装备（名称 × 数量 + 每件装备详情）；选项仍可展开查看但选择行为不变；
   - pick 行具体装备条目 → `ExpandableOptionCard`（或同视觉的展开条目），展开显示该装备详情（武器伤害/护甲 AC/用途）；数量 `−/＋` 按钮保留在操作位。
3. **`CharacterSheetStep.vue` 物品页签**：已装备/物品栏条目升级为可展开条目，展开显示装备详情；当前纯文字列表改为条目化展示。
4. 展开状态为局部 UI 状态，不持久化；展开与选择/数量调整互不影响。

## 4. 非目标与边界

- **背景不展开**（本需求只覆盖种族与装备；背景的详细介绍展开如需要另行立项）。
- 不复制原书正文：种族/装备介绍均为原创中文转述，武器伤害数据为 SRD 公共表登记。
- 不新增 `CharacterDraft` / 草稿字段；装备伤害字段只作展示，**不进入自动计算**（攻击命中加值派生维持现状；伤害骰参与攻击派生属后续批次）。
- 不修改 `ExpandableOptionCard` 组件本身（复用现成能力）。
- 不做装备搜索、筛选、对比等列表增强。

## 5. 涉及模块与依赖方向

```text
app/src/types/rules.ts
  RaceRule 新增 description；EquipmentRule 新增 damageDice / damageType

app/src/rules/data/origins-2014.ts
  登记约 20 条种族/子种族原创详细介绍

app/src/rules/data/equipment-2014.ts
  补齐武器伤害字段与全部 144 条装备详情

views/character-builder/components/OriginStep.vue
  -> ExpandableOptionCard（种族/子种族卡片接入展开，expandedLabel="种族介绍"）

views/character-builder/components/EquipmentStep.vue
  -> ExpandableOptionCard（分组选项与 pick 行装备接入展开）

views/character-builder/components/CharacterSheetStep.vue
  -> ExpandableOptionCard（物品页签条目化并接入展开）
  -> rules/repository（getEquipment 读取详情，不变）

components/ui/ExpandableOptionCard.vue（复用，不修改）
```

依赖方向不变：`views → components/ui + rules → types`，rules 保持框架无关；新增数据字段与登记不改变模块拓扑，交付说明写明"已复核前端依赖拓扑，无需更新"。
