# 赛博骰娘动画开关音效与数据保留—更新计划

## 1. 目标与确认结论

- 产品范围：`app` 的 `/dice` 页面，不修改原型项目。
- 仅应用内页面切换保留骰池、逐颗结果（含 d100 组成读数）和设置；刷新或关闭重开不恢复，不增加投掷历史。
- 跳过动画默认关闭，音效默认开启；独立音效开关允许静音，跳过动画时静音并保留原音效偏好。
- 投掷中离页结算并保留本轮已生成结果，清理视觉与音频资源；返回不自动投掷或重播。

## 2. 实施步骤与结果

1. 已补充页面卸载/重建、准备中与播放中离页、旧回调隔离的回归测试。
2. 已新增骰娘 Pinia Store，集中管理投掷开始、待公布结果、结果公布与失效；总和和分组仍从原始结果派生。
3. 已接入跳过动画分支：复用原随机规则，立即公布结果，不启动 Worker；跳过时不挂载骰盘。
4. 已新增页面私有 Reka UI 设置区域，投掷中禁用动画开关；音效可在播放中关闭，立即停止。
5. 已新增 Web Audio 服务，封装 unlock / play / stop / dispose，合成短促碰撞与衰减滚动声；不引入素材、依赖或自动播放。
6. 骰盘开始播放事件携带投掷标识和时长，触发一次音效；系统减少动态效果直接显示最终帧时不触发。
7. 完成、降级、静音、离页均释放对应播放资源；浏览器音频能力缺失、resume 被拒或播放失败不影响计算。
8. 已同步需求确认结论、规则与前端依赖拓扑，归档需求增加后续引用并保留历史正文。

## 3. 接口与资源边界

- Store 保存 pool、results、pendingResults、activeRollId、skipAnimation、soundEnabled，提供 begin / prepare / publish / invalidate；投掷标识在同一 Store 生命周期内不重复。
- 页面 hook 管理 Worker、计时器、轨迹、音效实例和媒体查询监听；没有 localStorage 或其他持久化。
- 页面入口只绑定 hook 和组装组件；骰子结果类型与 Worker 协议不变。
- 离页先公布本轮结果、使标识失效，再取消任务、终止 Worker、释放音频。返回恢复可操作状态，旧响应不得影响新一轮。
- 增减或清空骰池仍使已有结果失效；调整设置不会清空数值。
