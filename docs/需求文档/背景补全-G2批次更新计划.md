## 3. 每批实施步骤（统一模板）

1. **读原文**：用 `.chm_output/DND.26.09.13/markdown/<书名>_<章节>_<标题>.md` 逐条读取，**特性名与英文名必须取自原文**（G 批次曾因虚构特性名返工 15 处）。
2. **补数据**：按批次落点补 `BackgroundRule`（含 `summary`／`description` 原创中文转述）与对应 `BackgroundFeature`。
3. **补来源**：同批注册所需来源（第三方 `contentKind: 'third-party'` + `defaultEnabled: false`；试玩内容 `status: 'dm-only'`）。
4. **补装备**：2024 写法条目按 `选择A或B` 补 `backgroundEquipmentA2024` 行；无法映射到既有装备 ID 的条目留空并在文本说明（沿用胧忆岛／白石城惯例）。
5. **跑测试**：`pnpm test -- --run <相关测试文件>`；断言一律用**覆盖度／下界**写法。
6. **更新计划文档**：在本文件第 2 节标记「已完成」并记录提交号。

## 5. 风险与注意

1. **CHM 重复渲染段**：`6874`—`6965` 段标题为「魔邓肯的众敌卷册（旧版）」，内容实为《范·里希腾的鸦阁魔域指南》的副本（与 `6580`—`6873` 对应）。**凡遇疑似新书段落，必须回到「含 Credits 的书锚点页」核对书名与创作人员，不得按相邻 ID 或目录标题推断来源。**
2. **来源归属**：斯坦哈德与「探秘艾伯伦」在 CHM 中同段混排，登记时以各自书锚点为准：`4902` 探秘艾伯伦、`4954` 斯坦哈德。
3. **同名不同版**：ERftLW／奇械锻炉、寻路者指南／ERftLW 两组同名条目必须用**不同 ID**（`…-erftlw`／`…-efa`／`…-wgte`），否则仓库会互相覆盖。
4. **专长依赖**：2014 背景的「获得某专长」类特性（巨人养子 → 巨人打击、符文雕刻者 → 符文塑形者）与 2024 背景的 `originFeatId`，若指向未登记的专长则**留空并在描述中注明「本项不接入自动专长授予」**，不得编造 ID（沿用索兰尼亚骑士／高等术法会大法师的既有处理）。
5. **家族工具熟练**：寻路者指南「家族工具熟练表」含载具／修补工具，项目有 `tool-land-vehicles`／`tool-water-vehicles` 但无「修补工具」→ 按惯例留空 + 文本说明。
6. **CHM 缺页**：`5528 背景`（寻路者指南）在 markdown 转换中缺失，只能用 index 摘要 + 同书其他章节交叉核对。
