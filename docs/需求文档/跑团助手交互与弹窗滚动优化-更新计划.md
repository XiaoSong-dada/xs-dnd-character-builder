# 跑团助手交互与弹窗滚动优化 · 更新计划

> 依据《docs/需求文档/跑团助手交互与弹窗滚动优化需求.md》制定。本文件为实施计划存档，执行时按阶段推进。
> **执行状态：已完成**（v0.6.4，2026-08）。

## 目标与范围

- **HP 钳制**：`useSessionPanel.changeHp` 改为双向钳制（加血超上限 → 满血；减血低于 0 → 归零），移除 HP 越界错误提示。
- **双击放大抽象**：`src/styles` 新增 `.touch-manipulation` 工具类；跑团助手页面应用；赛博骰娘两处静态 `touch-action: manipulation` 改为复用（动态 `resolveTrayTouchAction` 保留）。
- **弹窗封装**：新增 `src/components/ui/UiScrollModal.vue`（标题/页脚固定、仅内容区滚动）；仅应用于抄录法术书弹窗与新增物品弹窗；移除两者内部 `ListShell` 的 `max-height`（消除嵌套滚动）。
- **明确不做**：`UiModal` 本体及其余 6 个使用方行为变更；骰娘动态触摸策略（`'none'`）改动；其他页面应用双击放大抽象。

**`app/test/components/SessionAssistantPage.test.ts`**（测试先行，红）：

| 用例 | 断言 |
|---|---|

| 减血低于 0 自动归零（新增） | 当前 HP 扣到较低值，输入超大值「−」→ 显示 `0 / maxHp`，不含「生命值不能低于 0」 |

- 完成检查：新断言运行失败（现状报错拒绝），确认测试覆盖缺口。

**`app/src/views/session-assistant/hooks/useSessionPanel.ts`**：

```ts
function changeHp(delta: number): void {
  const state = ensureState()
  // 双向钳制：加血超上限自动满血，减血低于 0 自动归零，均不报错
  const next = Math.min(maxHp.value, Math.max(0, state.currentHp + delta))
  operationError.value = ''
  persist(applyHpChange(state, next - state.currentHp, maxHp.value))
}
```

- 完成检查：`pnpm exec vitest run test/components/SessionAssistantPage.test.ts` 全绿；`vue-tsc -b` 通过。

## 阶段 3：UiScrollModal 封装与两个弹窗接入

**新建 `app/src/components/ui/UiScrollModal.vue`**：

- 接口与 `UiModal` 一致：`props { open: boolean; title: string }`、`emit close`、`Teleport to body`、默认插槽 + `footer` 插槽、遮罩点击关闭、`aria-label`、关闭按钮；
- 结构：外层遮罩同 `UiModal`；`section` 改 **flex column**：

```scss
section {
  width: min(100%, 30rem);
  max-height: min(80dvh, 42rem);
  display: flex;
  flex-direction: column;
  overflow: hidden;      // 外层不滚动
}
header, footer { flex-shrink: 0; }   // 标题与页脚固定
&__body { flex: 1; min-height: 0; overflow-y: auto; }   // 仅内容滚动
```

- 样式（圆角、阴影、标题、关闭按钮、页脚分隔线）与 `UiModal` 保持一致。

**`app/src/features/spellbook-transcription/components/SpellbookTranscriptionModal.vue`**：

- 抄录候选 `ListShell` 移除 `max-height="12rem"`（内容统一由弹窗内容区滚动）。

**`app/src/components/AddItemModal.vue`**：

## 已确认决策（用户确认）

1. 弹窗滚动封装**仅**应用于抄录法术书与新增物品两个弹窗；`UiModal` 本体及其他使用方不动。
2. HP **双向钳制**：加血超上限自动满血，减血低于 0 自动归零，均不弹错误。
3. `touch-action: manipulation` **抽象为可复用能力**，跑团助手与赛博骰娘两页复用（骰娘动态 `'none'` 保留）。
4. 移除两个弹窗内部 `ListShell` 的 `max-height`，消除嵌套滚动。
