- 每条以“所属页面公共字段＋该行＋链接专项资料”组成记录：规则版本、核验日期、实现状态、TODO可在页首统一写明；条目名称、来源、获得条件、输入输出、资源、依赖与状态按行或链接填写。
- 未核对字段必须写待核验，不用空白、默认0或“无”掩盖未知。首批条目现已完成研究核验；后续目录条目仍不得继承该状态。
- 核验状态：本地整理→本地不全书正文已核对→逐项字段与依赖闭合；外部补充不抬升也不降低本地核验状态。只有本地字段、依赖和勘误影响均处理后才使用最终“已核验”。“已核对”只适用于写明的机制范围，不能传递给其候选依赖。
- 实现状态：未接入／待实现／已实现待验收／已验收。本批不推进实现状态。历史资料标签不继承为本批核验结果。
- 最终证据应定位本地不全书章节和对应标题；如有外部补充或勘误，再记录其链接与差异。仅外部目录 URL 不能替代本地正文，也不能证明条目已经完成字段核验。
