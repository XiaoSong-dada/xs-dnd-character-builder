- 项目内《DND 五版不全书 v2025.11.8》及其解包索引是本项目的直接权威；矩阵条文、数值、候选池和实现验收以其中正文为准。

- 官方页面、授权页面和官方勘误是可选外部补充，用于提供出处、发现差异和登记勘误，不是本地条目通过或 M0 的必要门槛。若外部口径与项目不全书不同，先记录差异，不在本批临时混用；本项目实现继续遵循已采用的不全书口径。
- 研究摘要与公开发布许可分开核验：商业内容只保留必要元数据、原创摘要、来源，不因能访问本地资料就获得转载完整正文的许可。
