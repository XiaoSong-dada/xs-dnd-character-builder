# 跑团助手 · 更新计划

> 依据《docs/需求文档/跑团助手需求.md》制定（2026-08 需求基线已完整，§7 确认表 9 项全部拍板）。本文件为实施计划存档，执行时按阶段推进。

## 目标与范围

- **命名与路由**：底部导航第 2 项「职业介绍」→「跑团助手」；`/classes` → `/assistant`（原占位页无功能，直接改路径）。
- **局内面板**（参考角色卡页布局）：上方基础信息区（角色基本信息、HP、金币、短休/长休/撤回、状态 tag）+ 下方 4 Tab（总览 / 战斗 / 物品 / 状态）。
- **局内状态**：`SessionState`（当前 HP、已用法术位、力竭层数 0–6、普通 debuff、休息快照），独立存储，不写草稿、不触发车卡校验。
- **休息**：短休 = 回半损失血（向上取整）+ 邪术师契约位清零；长休 = 全恢复 + 清 debuff + 力竭归零（确认后）；均支持**撤回**（快照，仅最近一次）。
- **物品**：`AddItemModal` / `AdjustItemModal` 抽象至 **`src/components`**，跑团助手与角色卡页共用；MVP 不做自动金币结算。
- **角色来源**：本地草稿列表 + JSON 导入（复用 `store.importDraft`），导入后直接进入局内面板。
- **金币**：写回 `adventureGold`（与角色卡页共享事实源）。
- **状态**：13 项普通 debuff 点击挂/摘 + 顶部 tag 联动（tag 可点击查看详情）；力竭独立字段叠层（−/+ 控件，tag「力竭 ×N」）。

## 阶段 3：规则纯函数（测试先行）

`app/src/rules/session-state.ts`（框架无关）：

| 函数 | 行为 |
|---|---|
| `createInitialSessionState(draftId, maxHp)` | HP = maxHp、法术位全 0、力竭 0、debuffs 空、无快照 |
| `applyHpChange(state, delta, maxHp)` | 钳制 [0, maxHp] |
| `applySpellSlotChange(state, level, delta, maxForLevel)` | 钳制 [0, maxForLevel]；非法环级原样 |
| `applyExhaustionChange(state, delta)` | 力竭层数增减，钳制 [0, 6] |
| `toggleDebuff(state, debuffId)` | 挂/摘幂等（力竭不在 debuffs 列表） |
| `applyShortRest(state, pactSlotLevel)` | 快照 → 回半损失血（向上取整）+ 契约位已用归零 |
| `applyLongRest(state, slotMaxByLevel)` | 快照 → 满血 + 全环归零 + debuffs 清空 + 力竭归零 |
| `restoreLastRest(state)` | 无快照原样返回；有快照恢复 HP/法术位/力竭/debuffs 并清快照 |
| `clampCurrentHp(state, maxHp)` | 读取时按新最大 HP 钳制（升级场景） |

单元测试 `app/test/rules/session-state.test.ts`：

- 初始状态（HP=最大、全 0、无快照）；
- HP/法术位/力竭增减与钳制（0、上限、输入 0）；
- debuff 挂摘幂等；
- 短休（半血回升奇数值向上取整、契约位清零、普通环不动、满血不变、存快照）；
- 长休（全恢复 + debuff 清空 + 力竭归零 + 存快照）；
- 撤回（复原 + 快照清除；再次休息覆盖快照；无快照时原样返回）；
- clamp（最大 HP 变小后读取钳制）。

- 完成检查：`pnpm test:run` 该文件全绿。

## 已确认决策（用户 2026-08 拍板，详见需求文档 §1 与 §7）

1. 命名「跑团助手」；路由 `/assistant`；
2. 短休 = 半损失血（向上取整）+ 契约位清零；长休 = 全恢复 + 清 debuff + 力竭归零（确认）；
3. 休息撤回（快照，仅最近一次）；撤回入口常驻显示；
4. 局内状态独立存储（不入草稿/导出/校验）；
5. 金币写回 `adventureGold`；HP/金币/力竭均用按钮 + 输入框（空输入按 1）；
6. 角色 = 本地草稿 + JSON 导入（导入后直接进入）；
7. 物品弹窗抽象至 `src/components`；MVP 不做自动金币结算；
8. 布局 = 上方基础信息区 + 下方 4 Tab（总览/战斗/物品/状态）；
9. 状态：13 项普通 debuff 点击挂/摘 + 顶部 tag 联动（tag 可点看详情）；力竭独立字段叠层 0–6（tag「力竭 ×N」）。
