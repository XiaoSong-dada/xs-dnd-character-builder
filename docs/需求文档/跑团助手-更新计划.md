## v0.6.1 批次：法术/能力页签、交互反转与状态保持

### 目标与范围

- **页签扩容**：总览 / **能力** / 战斗 / **法术** / 物品 / 状态（能力排在总览后，用户确认）；`UiTabs` 增加 wrap 模式（固定宽度 + 超宽换行），角色卡页不受影响。
- **法术位语义反转**：显示「可用 / 总量」；「−」= 施法使用（可用 −1）、「＋」= 恢复（可用 +1）；数据模型内部仍存「已用」，休息/撤回逻辑不变。
- **法术页签（新）**：已准备法术按环分组（参考角色卡法术页签展示）；戏法只读；每环环位行可手动 ±；点击「施法」弹 `UiModal` 环位选择（**支持升环**，选后可用 −1）。
- **能力页签（新）**：豁免/技能 `StatTile` 网格 + 职业特性/子职特性（仅当前等级已解锁）+ 专长与属性提升，复用角色卡同套组件与规则函数。
- **状态保持**：选中角色 id + 当前页签 → 新 pinia store + localStorage 持久化；切页/刷新均恢复；角色删除回退列表。
- **返回按钮样式**：与辅助车卡 `StepHeader` 一致（无边框透明文本按钮 `← 返回列表`）。

### 阶段 1：状态保持 store（独立提交）

1. 新增 `app/src/stores/session-assistant.ts`：
   - 状态：`selectedDraftId?: string`、`activeTab: string`（默认 'overview'）；
   - 持久化：localStorage（独立 key，如 `dnd-session-assistant:view:v1`），初始化时读取、变更时保存；
   - 方法：`selectDraft(id)`、`clearSelectedDraft()`、`setActiveTab(tab)`；
   - 防御：读取时若 `selectedDraftId` 对应草稿不存在，置空回退列表。
2. `useSessionAssistantPage` / `useSessionPanel` / `SessionPanel` 改用 store 状态（替换本地 ref）：
   - 列表选择/返回、面板 `activeTab`（`v-model` 绑定 store）；
   - 页签顺序：总览 / 能力 / 战斗 / 法术 / 物品 / 状态。
3. **返回按钮样式**：`session-panel__back` 改为 StepHeader 风格（无边框透明、`←` + 文案、primary 色、focus-visible 描边）。
4. 单元/组件测试：
   - store：选择/清空/页签持久化（localStorage mock）；草稿不存在回退；
   - 组件：卸载重挂载（`wrapper.unmount()` 后重新 mount）自动回到原角色原页签；返回按钮存在且文案「← 返回列表」。

### 阶段 2：UiTabs wrap 模式（独立提交）

1. `app/src/components/ui/UiTabs.vue`：新增 `wrap?: boolean` prop（默认 false）：
   - `wrap` 时：tab 固定最小宽度（如 `min-width: 5.5rem`）、容器 `flex-wrap: wrap`、无横向滚动；
   - 默认（角色卡页）保持现状（横向滚动）。
2. 跑团助手 `SessionPanel` 传 `wrap`；页签 items 更新为 6 个（顺序：overview/features/combat/spells/items/status）。
3. 组件测试：6 个页签渲染与切换正常；角色卡页测试无回归。

### 阶段 3：法术位语义反转（展示层）

1. `useSessionPanel` 增加派生：
   - `availableSlot(level)` = 总量 − 已用（`spellSlots` 总量与 `sessionState.usedSpellSlots`）；
   - 按钮语义：`−` 调 `changeSpellSlot(level, +1)`（内部已用 +1 = 可用 −1）、`＋` 调 `changeSpellSlot(level, -1)`（恢复）；
   - 越界提示文案更新：如「{n}环法术位已用尽」「{n}环法术位已全部恢复」。
2. 战斗页签环位行与法术页签环位行统一为「可用 / 总量 + −使用/＋恢复」。
3. 组件测试更新：
   - 显示「可用 / 总量」；点「−」可用 −1；点「＋」可用 +1；用尽/恢复满时提示。

### 阶段 4：能力页签（R5B）

1. `SessionPanel` 新增 features tab 内容（全部复用公共组件与规则函数）：
   - 豁免：`StatTile` 网格（`derived.savingThrows`，标签 `ABILITY_LABELS`，note = sources 标签拼接）；
   - 技能：`StatTile` 网格（`derived.skills`，标签 `rulesRepository.getOption(id)?.name`，note = sources detail）；
   - 职业特性：`ListShell` + `ExpandableOptionCard`（`getClassFeatures2014(classId)` 过滤 `level <= targetLevel`；`{level}级 · {englishName}`；展开 = description；`requiresChoice` 显示选择徽标）；
   - 子职特性：同上（`getSubclassFeatures2014(subclassId)`；未选子职展示提示）；
   - 专长与属性提升：`buildTimeline` 解析 ASI/专长条目（参照角色卡 `featAndAsiEntries` 逻辑）。
2. 组件测试：豁免/技能网格渲染数值与标签；特性列表条目与展开；专长条目出现。

### 阶段 5：法术页签（R5A）

1. 规则层（`app/src/rules/session-state.ts`）新增纯函数（测试先行）：
   - `getAvailableSlotLevels(state, spellLevel, slotLevels: readonly {level, count}[]): readonly number[]`
     —— 返回可施法环位（≥ spellLevel 且 可用 > 0；pact 契约位并入对应环级）；戏法（spellLevel = 0）返回空数组。
2. `SessionPanel` 新增 spells tab 内容：
   - 已准备法术：`getSelectedSpellIds` / 法术库按环分组（戏法单独区块只读）；
   - 每环区块头部环位行：`{n}环 可用 x / y` + 「−」「＋」；
   - 每个法术行 `ExpandableOptionCard`（标题/`{n}环 · 英文名`/展开效果）+ suffix「施法」按钮；
   - 施法：`UiModal` 环位选择（`getAvailableSlotLevels` 结果；无可用环位时按钮置灰/提示）→ 选择后 `changeSpellSlot(level, +1)`（可用 −1）→ 轻提示「已使用 X 环法术位」；
   - 契约法术位（邪术师）同样参与施法消耗。
3. 组件测试：
   - 已准备法术按环分组渲染；戏法区块只读无施法按钮；
   - 施法弹层列出可选环位（含升环：3 环法术可消耗 4 环位）；
   - 选择后该环可用 −1 且环位行联动；无可用环位时置灰。
