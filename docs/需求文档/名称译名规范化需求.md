# 名称译名规范化需求

## 1. 背景与目标

用户反馈：项目中物品、职业、专长、法术等名称疑似机翻、不够优雅，希望对照**官方简体中文翻译**与**中文社区通行译名**进行规范。

经全量考察（已核验），结论与用户直觉部分相符、部分不同：

- **大部分数据并非机翻**：职业、子职、专长、种族、背景、护甲、武器、普通魔法物品、职业特性、子职特性的中文名**全面采用官方简体中文译名（2016 年威世智授权简体中文版体系）或社区通行译名**，质量较高；
- **真实缺陷集中在法术名**：约 12 处法术名与官方简体中文术语不一致（其中 1 处与邻法术撞名、2 处同名冲突），以及少量扩展书法术名与 5e.tools 中文/果园主流译名有差异——这些正是"机翻感/不优雅"的主要来源。

目标产物：将法术名（及少量其他类别）对齐官方简体中文术语与社区主流译名；修复同名冲突；补充防回归测试与文档说明。**名称修改仅改 `name` 展示字段，`id`（基于英文名）不变，草稿存档完全兼容。**

### 2.4 核验方式与置信度说明

本项目环境无法联网，本次核验基于知识库中的四类中文译名来源，逐条对照：

1. **官方简体中文书版**（2016 年威世智授权《玩家手册》《地下城主指南》体系）——R1 清单 1—12 条的依据；
2. **博德之门 3 官方简体中文**（拉瑞安，大众玩家接触面最广）——「电爪」「死云术」「圣焰击」等依据；
3. **5e.tools 中文镜像**——扩展书法术（XGtE/TCoE）社区主流译名依据；
4. **纯美苹果园（果园）**——社区通行译名佐证。

置信度标注：清单 1—12 条为高置信（书版与多个来源一致）；13—14 条为用户指定（「电爪」「繁彩球」）；R2 按用户确认的「社区分歧倾向果园通行译名」规则定稿（见 2.3 定稿列）。**定稿结论已登记于本文件，实施按定稿清单执行。**

### 2.5 兼容性与影响面（已核验）

- `id` 基于英文名生成（`spellId(englishName)`），**改名不改变 id**；草稿仅持久化 id 与选择，存档完全兼容；
- 测试与组件按 id 引用，未锁定上述中文名（已 grep 核验），改名后需全量回归；
- 展示层（车卡步骤、角色卡、导出 PDF/XLSX）均从 `rules` 读取 `name`，改名自动跟随；导出文案与角色卡打印同步生效。

## 4. 非目标与边界

- **不重翻 description/摘要文本**：仅规范名称；效果文本的措辞优化另行立项。
- **2024 规则数据不在范围**：`docs/species/5e-2024`、`magic-items-2024.ts` 为未来独立规则集（当前只读隔离），待官方简体中文术语明确后另行处理。
- **不更改 `id` 与持久化格式**：草稿导入导出完全兼容。
- **不复制规则书正文**：采用短名称（术语），属事实性短文本；官方简体中文译名为社区广泛引用的通用术语，本项目仅登记名称并标注来源，不摘录正文。
- **特性/背景等已与官方一致，无需改动**；如实施中发现个别条目差异，以 5e.tools 中文核验后纳入（记录在交付说明）。
