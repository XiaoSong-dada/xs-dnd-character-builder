# 添加物品弹窗高度调整 · 更新计划

> 依据《docs/需求文档/添加物品弹窗高度调整需求.md》制定。本计划为实施存档：改动范围小（一个通用组件加属性 + 一个调用方传值），完成条件明确，无需分批次。
>
> 实施状态（2026-08-26）：已完成，随 v0.9.2 发布。

## 目标与范围

- 调高“添加物品”弹窗高度：移动端接近占满屏幕（约 `96dvh`），桌面端约 `60rem`，组合值 `min(96dvh, 60rem)`。
- `UiScrollModal` 支持 `maxHeight` 可配置属性，默认值保持 `min(80dvh, 42rem)`，保证抄录法术书等未传属性的调用方零变化。

## 已核验现状

- `UiScrollModal.vue:35`：`section { max-height: min(80dvh, 42rem) }`，目前无高度可配置入口。
- 调用方：
  - `AddItemModal.vue:238`：`<UiScrollModal :open="open" title="添加物品" :body-scroll="false" ...>`（v0.9.1 已固定布局：body 为 flex 容器，仅 `__result-area` 滚动）。
  - `SpellbookTranscriptionModal.vue:30`：未传 `body-scroll`，使用默认滚动行为。
- 弹窗内布局（搜索/筛选/底部固定、结果区滚动）由 v0.9.1 的 flex 方案保证，高度调整只影响容器 `max-height`，不触碰内部布局。

## 实施细节

1. **`UiScrollModal.vue`**：
   - props 增加 `maxHeight?: string`，`withDefaults` 默认值 `'min(80dvh, 42rem)'`。
   - `section` 改为 `:style="{ maxHeight }"`（替换 SCSS 中的固定 `max-height`）。
2. **`AddItemModal.vue`**：
   - `<UiScrollModal ... max-height="min(96dvh, 60rem)">`。
   - 若视觉验收需要全屏，仅改该值为 `100dvh`，无结构变化。
3. **不修改**：`SpellbookTranscriptionModal.vue`、弹窗内部布局与交互逻辑。
