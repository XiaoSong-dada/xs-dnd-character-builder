## 5. 关键设计（实施时不再决策）

**排序规则与比较器**（与 `groupSpellsByLevel` 同源）：

```text
比较顺序：spell.level 升序
        → 规则表登记下标（getSpellOrderIndex）升序
        → 未登记法术（下标未命中）统一排到末尾，并保持输入相对顺序
```

| 输入情形 | 期望结果 |
| --- | --- |
| 乱序层级（3→0→1→2） | 0→1→2→3（戏法最先） |
| 同环内逆序 | 纠正为登记顺序 |
| 核心列表 + 扩表块拼接 | 扩表法术按自身环级插入对应位置，不再成块追加 |
| 含未登记法术 | 排在末尾、保持相对顺序 |
| 空输入 | 空数组；不修改入参 |

**默认页签**：任务切换 watch 中 `levelFilter` 恒置 `'all'`；搜索与来源／学派／仪式／专注四个下拉仍按现状重置；不新增记忆逻辑。

**边界与失败模式**：

- 「已选择 N」页签继承候选排序（只做已选过滤，不再重排）。
- `spellbook-extra` 任务的候选（`getSpellbookExtraCandidates`，含已在书中项）同样排序，不影响「已在书中」徽标判定。
- 排序不得影响 `activeCount`／`activeRequiredCount` 与任何校验：计数仍基于草稿数组顺序，与展示顺序无关。
- 环级页签集合由 `taskCandidates` 的环级集合派生（排序不改变集合），因此页签不变。
