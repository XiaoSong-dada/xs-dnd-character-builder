# B09-09 专长属性提升子选项标签与显示统一 · 更新任务

- 对应问题：2024 角色在时间线选中「敏锐心灵」后，子检查点「敏锐心灵 · 属性提升」的选项显示原始 ID `feat-bonus-int-1`，应显示「智力 +1」。
- 实现日期：2026-09-15。
- 状态：已完成并提交。

## 1. 根因

- 专长自带的属性提升子选项使用统一编码 `feat-bonus-<ability>-<1|2>`（`feats-2024.ts` 的 `abilityChoice()` 生成；`timeline.ts:180-215` 据此建立 `feat-child:` 子检查点，标题为「专长名 · 属性提升」）。
- **2014 注册了中文标签**：`feats-2014.ts:173-175` 导出 `featChoiceOptions2014`（`name: '智力 +1'`）并在 `repository.ts:49` 并入 2014 仓库。
- **2024 未注册**：`repositories.ts` 的 2024 options 只含 `asi-2024-*`、专长本体、法术／物种／技能／子职等，没有任何 `feat-bonus-*`（grep 两处仓库文件均为空）。
- 显示层 `TimelineStep.vue:222` 使用 `getOption(id)?.name ?? featureOptionLabel(...) ?? id` → 2024 三处都未命中 → 回退显示原始 ID。
- 连带影响：角色卡「专长与属性提升」与导出特性列表会**静默漏掉**该 +1（属性数值本身由 `derive.ts` 的正则正确应用，因此只是可读性／展示缺陷）。

## 2. 修复

| 文件 | 改动 |

| `src/views/character-builder/components/CharacterSheetStep.vue` | 「专长与属性提升」识别 `feat-bonus-*` → 显示「专长名 · 智力 +1」；四处 `buildTimeline` 补传 `selections`／`enabledSourceIds`（此前子检查点未被构建） |
