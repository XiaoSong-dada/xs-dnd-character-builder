# 添加物品筛选与物品库补全-前置物品清单

## 1. 清单用途

本文是《添加物品筛选与物品库补全需求》的实施前清单，用于回答：

- 当前运行时已经有什么物品。
- 项目文档候选池覆盖哪些 DMG 2014 物品。
- 哪些来源仍没有运行时物品数据。
- 实现筛选前必须补齐哪些字段。
- 哪些中文译名需要进入人工审校队列。

本文不是新的规则正文仓库。DMG 2014 每件物品的中英文名、稀有度、类型和原创摘要已经按字母保存在 `docs/equipment/5e-2014/magic-items/`，本清单只维护批次、数量、状态和对照入口，避免复制 247 行资料并造成双重事实源。

## 2. 统计口径

- 统计日期：2026-08-26。
- 当前规则集：`5e-2014`。
- 运行时基线：`rulesRepository.equipment`。
- DMG 候选基线：`docs/equipment/5e-2014/magic-items/*.md`。
- 网站参考：5e 不全书旧版《城主指南2014》分类页；当前首页速查中的 `DMG24` 条目不计入本清单。
- “候选”表示已经有名称与摘要资料，不等于已经进入运行时。
- “现有”必须以代码仓库实际装配结果为准，不能直接相信旧文档中的 `pending` 标签。

### 4.2 状态漂移说明

字母资料中的条目目前统一写为 `pending`，但运行时已经存在 101 条 DMG 物品。因此实施前必须执行一次对照，更新为以下状态之一：

- `implemented`：已进入运行时且机械字段已接入。
- `selectable`：已进入运行时，可保存和导出，复杂效果由桌面裁定。
- `index-only`：元数据完整，可浏览但不参与派生。
- `pending`：尚未进入运行时或身份尚未核验。
- `dm-only`：神器、诅咒或需要 DM 明确许可。

不能简单用“247 - 101 = 146”作为缺失数量，因为：

- 文档存在 `+1/+2/+3` 汇总条目，运行时可能拆成一个或多个 ID。
- 治疗药水、巨人力量药水、抗力药水等存在系列型号。
- 运行时存在 XGtE/TCoE 重印或同名条目。
- 少量英文名、裸 ID 和规范 ID 的格式不同。

完成英文名/ID 对照后，才能得到最终的逐条缺失清单。
