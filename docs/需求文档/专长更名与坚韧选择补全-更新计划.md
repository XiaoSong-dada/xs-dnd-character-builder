# 专长更名与坚韧选择补全 · 更新计划

> 依据《docs/需求文档/专长资料补全与译名核验需求.md》制定，并叠加用户 2026-08-27 的两项决策：**全部译名按 5e 不全书（CHM v2025.11.8）更名**、**更名作为用户指定例外登记**。本文件为实施计划存档，执行时按阶段推进。
>
> 实施状态（2026-08-27）：**全部完成，v1.1.3 已发布**——阶段 0 定稿核对（46 项映射与 CHM 一致、内部唯一、跨类重名 1 处「运动员/背景」按 CHM 命名登记）；阶段 1 坚韧子选择机制（`grantSavingThrowProficiency` + 派生来源）；阶段 2 更名 46 项；阶段 3 测试（新增 3 组断言，全量 631 通过，含 PDF 字体子集重建与黄金样例断言更新）；阶段 4 文档与双公告同步；阶段 5 验收（test:run / vue-tsc / vite-ssg build 全部通过）。

## 目标与范围

- **根因 1**：`feat-resilient`（坚韧）未配置 `choices`，选择后没有「属性 +1 + 豁免熟练」的后续子检查点；且规则层完全没有「专长授予豁免熟练」的派生来源。
- **根因 2**：72 项 2014 专长中 44 项、`docs/dnd-feats.md` 2024 索引约 47 项译名与 5e 不全书不一致。
- **已确认方案**：
  1. 专长译名全部按 5e 不全书更名（只改 `name` 展示字段；`id`、`englishName` 不动 → 草稿存档、导入导出完全兼容；展示层与导出自动跟随）。
  2. 坚韧补「选择属性」子检查点：所选属性 +1（复用 `feat-bonus-*` 现有机制）**且**获得该属性豁免熟练（新增机制）。
  3. 更名作为**用户指定例外**登记到《名称译名规范化需求.md》（先例：法术「电爪」）。
- **不改动范围**：description/detail 文本（除必须随更名核对专长名交叉引用外）、职业/子职/法术/装备等其他类别名称、2024 规则数据、稳定 ID。

## 关键实施细节（已核验）

1. **兼容性**：`feat()` 工厂的 `name` 是唯一展示字段，ID 基于英文名（`feat-resilient` 等）→ 改名不破坏草稿。`app/test/rules/feats-2014.test.ts` 按 ID 断言且未锁定中文名（已 grep 核验）。
2. **更名位置**：`app/src/rules/data/feats-2014.ts` 中 `feat()`/`supplementFeat()` 调用的第二个参数（中文名）。
3. **2014/2024 同名专长译名不同，禁止全局字符串替换**：Alert（警觉/警戒）、Athlete（运动员/运动精英）、Tavern Brawler（斗殴高手/酒馆斗殴者）、Mounted Combatant（骑乘战斗/骑乘斗士）、Elemental Adept（元素导师/元素掌控）——按规则集分别处理。
4. **坚韧子选择机制（方案 B）**：
   - `FeatChoiceSpec` 与 `ChoiceCheckpoint` 扩展一个字段（如 `grantSavingThrowProficiency?: boolean`）；
   - `feats-2014.ts` 给 `feat-resilient` 配置 1 个「选择属性」choice（`abilityChoice('resilient', ABILITY_KEYS)` + 新字段）；
   - `timeline.ts` `buildFeatChoiceCheckpoints` 透传新字段；并复核 `optionIds` 兜底逻辑（当前空 optionIds 会兜底为 `SKILL_IDS`，属性选择自带 `feat-bonus-*` 不受影响，但需确认）；
   - `derive.ts` `savingThrows` 计算处新增来源：解析 `feat-child:` 选择中授予豁免熟练的属性，加入熟练加值并显示来源（如「强健身心」），与职业豁免并列；
   - 属性 +1 与豁免熟练天然联动（同一选项），无需二次校验；`applyAbilityImprovements` 已处理上限 20。
5. **译名定稿清单**：以《专长资料补全与译名核验需求.md》第 5.1—5.4 节为基线，用户已确认全部按 CHM 更名；实施时以 2.1—2.4 对照表逐条执行。
6. **名称唯一性**：更名后 72 项 2014 专长内部已人工核对无重名；与特性/法术/装备跨类重名需临时脚本核对（如专长「幸运」与半身人种族特性「幸运」为既有情况，不属于本次引入，仅登记）。
