## 2. 修订与去重规则（E05-01）

1. **单一有效版本**：奥术 II 覆盖的 6 项只录入 II 期数据；一期同概念数据不生成选项，只在盘点文档保留差异记录。
2. **跨来源去重**：咒剑宗主只登记一次，采用奥术一期版本；可怖版标记为旧版（盘点已登记）。
3. **译名**：纹身武者取二期「纹身武者」，ID 用 `tattoo-warrior`；恩护结社以 CHM 目录为准（文件作疗愈结社）；其余按 CHM 目录。
4. **数据隔离**：所有条目 `subclass-2024-ua-*`＋对应 UA 来源；不与 2014 同名条目共享任何数据。

## 3. 设计

### 3.1 文件与 ID

- 新文件：
  - `app/src/rules/data/ua-horror-2024.ts`
  - `app/src/rules/data/ua-arcane-subclasses-2024.ts`（含 II 期修订后的唯一版本）
  - `app/src/rules/data/ua-cataclysm-2024.ts`
- ID：`subclass-2024-ua-<class>-<slug>`（见 [子职矩阵](2024扩展内容引入-盘点/子职矩阵.md)）；特性 `ua-<article>-2024-<slug>`；选项 `ua-<article>-2024-<slug>-option-*`。
- 来源：可怖 `source-2024-ua-horror`、奥术／II `source-2024-ua-arcane`、浩劫 `source-2024-ua-cataclysm`；全部 `selectable`＋游玩测试标记。
- 装配：`subclasses-2024.ts` 与 `repositories.ts`。

### 3.2 特性、选择与资源

| 组 | 主要选择 | 资源／特别处理 |
| --- | --- | --- |
| 可怖 | 精魂学院故事表、幽邃戍卫猎物、苏生师造物 | 鬼魅魂灵、幽影术法幽暗之瞳、死灵宗主战栗形态；奇械师子职（苏生师）依赖 E02 奇械师职业；召唤物保持提示级 |
| 奥术 | 咒法师王车易位、惑控师直觉魅惑、变化师变化师之石、纹身武者文身选择、魔射手奥术射击选项 | 魔射手射击次数、纹身武者文身种类、先祖术法威仪；法师四学派需要法术书／准备协同（按 CHM） |
| 浩劫 | 角斗士武斗演出、恩护之地地形、亵渎强化选项、巫王诏令 | 亵渎术法术法点沿用职业；恩护结社地形法术始终准备；巫王宗主契约施法沿用职业 |

- 子职法术一律走 `alwaysPreparedSpellIdsByLevel` 或 `grantedSpells`，与 E07-03 法术数据协同。
- 需要玩家选择且跨等级不可重复的选项用 `uniqueGroup`；多选特性用 `minSelections`／`maxSelections`。
- 情境效果（召唤、形态、光环、状态）以原创摘要＋资源计数表示，不伪造自动计算。

### 3.3 校验与隔离

- 未启用对应来源时条目不可选；关闭来源保留选择并失效。
- 每个修订子职都建立与 2014 条目的隔离断言（ID、来源、特性数量、候选池）。
- 奥术 II 修订项建立「旧期次不存在」断言。
