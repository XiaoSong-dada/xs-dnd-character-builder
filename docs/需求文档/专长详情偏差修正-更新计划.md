# 专长详情偏差修正 · 更新计划

> 依据 2026-08-27 专长详情排查报告（v1.1.3 之后）制定。排查结论：`feats-2014.ts` 的 `detail`/`description` 展示文本存在 4 类 9 处翻译错误（法术名 5、工具名 1、技能名 1、错别字 2）、6 处此前已登记的规则表述偏差，以及若干可选优化项。本计划为实施存档，**只改展示文本，不动 ID、机制、派生与校验**。
>
> 实施状态（2026-08-27）：**全部完成，v1.1.4 已发布**——A—F 组 16 处 detail 修正 + 1 处背景术语统一；字体子集重建；新增防回归测试（全量 632 通过）；双公告与需求文档同步；vue-tsc / vite-ssg build 通过。

## 目标与范围

- **根因**：专长详情摘要撰写时未与项目术语体系（`spells-2014.ts` 法术名、`equipment-2014.ts` 工具名、技能正式名）和 2014 规则原文对齐，且含 2 处错别字。
- **已确认方案**：按下方定稿文案逐条修正 `detail`（及必要的 `description`）；发布版本 **v1.1.4**；CHANGELOG 与 `app/src/constants/update-notices.ts` 双公告同步；重建 PDF 字体子集覆盖新字。
- **不改动范围**：稳定 ID、`englishName`、前置条件与选择机制（choices）、派生逻辑、校验逻辑；2024 资料与文档（`docs/feats/` 待后续批次统一核验）。
