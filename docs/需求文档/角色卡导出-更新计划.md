# 角色卡导出（PDF / XLSX / JSON）· 更新计划

> 依据《docs/需求文档/角色卡导出需求.md》制定，路线决策已确认（2026-08-20）。本文件为实施计划存档，执行时按阶段推进。

## 目标与范围

- **三种导出**：PDF（自绘中文 print CSS + `window.print()`）、XLSX（exceljs 自生成 `.xlsx`）、JSON（已有，改入口形态）。
- **入口**：角色卡页（`CharacterSheetStep.vue`）现有「导出角色 JSON」按钮区（583 行附近）改为「导出」入口，含 PDF / XLSX / JSON 三项；个人中心不做。
- **新增依赖**：exceljs（`pnpm add`，**动态 `import()` 按需加载**，规避 vite-ssg 预渲染执行 Node 不兼容代码）；不引入 pdf-lib。
- **数值一致性**：三种导出一律复用 `rules` 派生函数；PDF/XLSX 以角色卡页已有的 `draft + derived` 为数据源，不重新计算、不复制规则逻辑。
- **模板**：`docs/export-templates/` 归档模板仅作版面参考，不进入运行时。

## 现状锚点（已核验）

- 角色卡已具备中文版面与全部派生数值（`overview/combat/features/spells/items` 五页签、`spellSlotsLabel`、技能列表、物品与金币），是打印版面的事实数据源。

## 阶段 1：PDF 打印版面（R2，自绘中文）

**新增页面私有组件 `app/src/views/character-builder/components/CharacterPrintSheet.vue`**（`draft + derived` 双 props，与 `CharacterSheetStep` 同源）：

1. 中文版面区块：基础信息（角色名、职业等级、种族/出身、玩家名、阵营、经验值）、六项属性与调整值、熟练加值/被动感知、HP/AC/先攻/速度、技能熟练与专精、攻击与法术攻击/法术豁免 DC/法术位摘要、已选法术（按环级分组，复用 `getSelectedSpellIds`）、背包与金币、特性速览。
2. `@media print` 样式：打印时仅显示打印视图（隐藏页面其余内容）、A4、`break-inside: avoid` 防区块断裂、黑白友好（不依赖背景色传达信息）、触控不可见（`display: none` 屏幕态处理，用 `.print-only` 类控制）。
3. 打印交互：点击「导出 PDF」→ 打开全屏打印视图（复用 `UiModal` 或独立容器）→ `window.print()` → `afterprint` 事件自动关闭；打印失败/取消不改变草稿。

**完成检查**：手机宽度打印预览 A4 完整、中文无乱码、各区块数值与角色卡页面一致。

## 阶段 2：XLSX 导出服务（R3）

**新增 `app/src/services/export-xlsx.ts`**（services 边界，不反向依赖 views；动态 import 由此文件发起）：

1. `buildExportWorkbook(draft, derived)`：返回 exceljs `Workbook`——中文工作表与列名：总览（身份/属性/熟练加值/HP/AC/先攻/速度）、技能、攻击与法术、法术位、法术列表、物品与金币；列宽、冻结表头、值旁附来源文字（如「熟练+2 · 属性调整+3」），版面字段组织参考 DRA6N MIT 模板（`docs/export-templates/`）。
2. `downloadXlsx(draft, workbook)`：浏览器 Blob 下载，文件名 `角色名-dnd5e.xlsx`。
3. 数值全部来自 `derived` / `rules` 派生函数，不写死。

**新增测试 `app/test/services/export-xlsx.test.ts`**（参照 `character-json.test.ts` 先例）：

- 中文表头无乱码（读回单元格文本断言）；
- 文件名含角色名与 `dnd5e` 标记。

## 已确认决策（2026-08-20，见需求文档第 7 节）

1. 角色卡必须中文；PDF 走自绘中文 print CSS（官方英文 PDF 仅版面参考，不进入运行时）。
2. XLSX 用 exceljs 自生成中文工作表（DRA6N xlsm 仅字段组织参考）。
3. 仅中文导出；免费个人工具；导出入口仅角色卡页内，个人中心暂不开发。

## 待执行时确认点

1. **导出入口形态**：弹层菜单（三项，省空间）vs 并排三按钮（更直接）；倾向弹层菜单，触控 ≥ 44px。
2. **打印视图形态**：全屏遮罩打印视图（`afterprint` 自动关闭，推荐）vs 就地切换打印模式；如浏览器 `afterprint` 支持不佳，用 `onbeforeprint` 快照 + 手动关闭兜底。
3. **exceljs 打包体积**：动态 import 后评估产物体积；若过大（>200KB gzip）评估裁剪引入（`exceljs/dist/es5` 子路径）或仅导出值不写公式。
4. **打印分页**：手机浏览器打印对话框默认缩放行为各异，A4 每页完整性需真机抽查（列入验收）。
