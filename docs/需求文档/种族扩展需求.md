# 2014 种族扩展需求

## 1. 背景与目标

用户反馈：当前项目的 2014 种族偏少。要求：

1. **扩展更多 2014 版种族**，尤其补充**地精类人种族**（哥布林、大地精、熊地精）与**类似侏儒一样的大种族**（带多个子种族的种族，如兽化人四亚种、天裔三形态、吉斯双亚种）。
2. **补充子种族层级**：例如龙裔之下分**色龙裔 / 宝石龙裔 / 金属龙裔**，色龙裔之下再分黑、蓝、绿、红、白等龙；高精灵之下分**日精灵与月精灵**。
3. 本轮目标：**考察种族并整理到规则文档中，并更新需求文档**，为下一步程序实现（数据登记）做铺垫，**不写代码**。

目标产物：

- `docs/dnd-species.md` 总索引更新（新增种族/子种族条目、来源、状态）。
- `docs/species/5e-2014/<race>/` 新增 42 个种族/分支资料文件（沿用现有格式：基础资料 + 快速索引 + 特性详解 + 兼容边界）。
- 本需求文档，记录范围决策、核验结论与后续实现铺垫。

### 2.3 考察核验结论（2026-08-11，dnd5e.wikidot.com + 5e.tools 交叉核验）

**来源勘误（重要）**：

- **天裔（Aasimar）三形态官方来源是 VGM（p.104–105），不是 SCAG**；SCAG 无天裔条目。
- **5e 2014 无官方“灰精灵”亚种**（灰精灵为 3.x/4e 时代亚种）；PHB 高精灵文本中的“灰精灵/月精灵”仅是被遗忘国度叙事别称，由高精灵 heritage 表覆盖。地底矮人（Duergar）常被误称为灰矮人，注意区分。
- **地底侏儒（Deep Gnome）首发 EEPC，由 MToF 重印**；XGtE 只含同名专长 Svirfneblin Magic（专长层，不并入种族）。
- **ERftLW 重印的哥布林、兽人数值与 VGM 完全相同**（不存在属性不同的新版）。
- **Fizban 龙裔三大类均无黑暗视觉**；吐息为“攻击动作中替换一次攻击”，次数 = 熟练加值。
- 2014 原版与 Monsters of the Multiverse 重制版差异巨大（海精灵无寒冷抗性、地底矮人保留日光敏感、伊拉德林妖精步短休恢复、蛇人毒素免疫、狗头人保留日光敏感等），资料一律以 2014 原版为准。

## 4. 非目标与边界

- **不写程序代码**（本轮为考察 + 文档铺垫）。
- 不复制商业规则书正文：所有新种族资料只记录稳定 ID、属性提升、原创玩法摘要、选择提示、兼容边界与官方链接。
- 灰精灵不新增资料（5e 2014 无官方规则），以高精灵日/月精灵 heritage 表覆盖叙事分支。
- 不把 Monsters of the Multiverse 重制版数值混入 2014 资料。
- 不引入 2024 物种数据；两套规则保持独立。
