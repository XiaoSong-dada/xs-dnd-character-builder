# 角色卡头部按钮布局优化 · 更新计划

> 目标版本：**v1.1.0**（随 v1.1.0 后续提交发布）
> 实施状态：**已完成**（阶段 A—E 全部通过：59 个组件用例 + 全量测试、类型检查与生产构建通过）。

## 背景与问题

开启「编辑角色卡」后，角色卡头部操作区最多同时出现 5 个元素：

`待补全` 徽标 + `调整等级` + `完成编辑` + `编辑角色形象` + `恢复系统默认`

当前 `header-actions` 为单行 flex 且按钮文字未禁止换行，导致：

1. 按钮宽度被压缩，文字在**按钮内部**换行；
2. 按钮高度被内容撑高（`min-height: 2.25rem` 只是下限），整行按钮一起变高；
3. 有头像/立绘时可用宽度进一步收窄（立绘时 `header-content` 限 `max-width: 72%`），375px 手机宽度下 5 个按钮一行必然放不下，页面观感拥挤。

## 目标

- 编辑模式下头部按钮行保持整齐：按钮文字永不换行、行高恒定；
- 放不下时**整组换行**而不是压缩变形（兜底）；
- 编辑模式头部按钮收敛为最多 3 个：`待补全` 徽标 + `调整等级` + `完成编辑` + `更多 ▾`；次要操作（编辑角色形象、恢复系统默认）收进「更多」展开面板。

## 方案 A：基础修复（CSS，必做）

1. `&__header-actions` 增加 `flex-wrap: wrap`：放不下时按钮整组换行；
2. `&__level-button` 增加 `white-space: nowrap`：按钮文字永不在按钮内换行，行高恒为 2.25rem；
3. 收紧间距减少换行概率：`header-actions` gap `0.5rem → 0.35rem`；`level-button` padding `0 0.9rem → 0 0.7rem`。

## 方案 B：编辑模式收纳「更多」面板（叠加）

1. **模板收敛**：`header-actions` 只保留「待补全」徽标、`调整等级`、`编辑角色卡 / 完成编辑`、`更多 ▾`（仅编辑模式显示，`aria-expanded`/`aria-controls` 标注）。
2. **「更多」展开面板**（页面私有结构，不引入新组件/依赖）：
   - 状态 `showMoreActions = ref(false)`；
   - 面板内容：`编辑角色形象`（打开媒体编辑器弹窗）、`恢复系统默认`（危险样式，仅 `editing.hasEdits` 时显示）；点击面板项后自动收起；
   - **flow 内联展开**：面板作为按钮行容器内的子元素（`flex-wrap` 后自然排到下一行），不使用绝对定位——`header` 有 `overflow: hidden`（立绘圆角裁剪），绝对定位面板会被裁剪；
   - 面板样式：卡片风格（surface 背景、border、radius），操作项触控高度与 `level-button` 一致（≥2.25rem），危险项沿用 `--danger` 样式；
   - 关闭逻辑：`更多` 按钮切换展开；点击面板外关闭（`document` pointerdown 监听，卸载时移除）；Esc 关闭。
3. **行为不变**：面板项点击后仍触发原有逻辑（`showMediaEditor = true` / `editing.showResetConfirm.value = true`），徽标与主按钮逻辑不动。

## 实施步骤

1. **阶段 A（CSS）**：`header-actions` flex-wrap + 间距收紧；`level-button` nowrap + padding 收紧；
2. **阶段 B（模板与交互）**：头部按钮收敛 + `更多` 按钮 + 展开面板（含外部点击/Esc 关闭）；
3. **阶段 C（测试）**：
   - 现有测试零改动（无对收纳按钮的存在性断言；「调整等级」仍为第一个 level-button）；
   - 新增：编辑模式开启后头部按钮数量与文案（调整等级/完成编辑/更多）；「更多」展开显示两项、无人工编辑时不显示「恢复系统默认」；点击「编辑角色形象」打开媒体编辑器弹窗；点击「恢复系统默认」打开恢复确认弹窗；面板外点击与 Esc 关闭；
4. **阶段 D（文档与版本）**：本计划登记实施状态；`CHANGELOG.md` v1.1.0 条目追加按钮布局优化说明（v1.1.0 尚未发布，直接并入该条目）；README 与架构文档不涉及新模块，无需更新；
5. **阶段 E（验收）**：`pnpm test:run` 全量通过；`vue-tsc` 类型检查通过；`pnpm build` 通过；375px 宽度下非编辑模式单行、编辑模式 ≤3 按钮且按钮文字不换行、高度恒定；无浏览器控制台错误。

## 验收标准

- 开启编辑模式后头部无按钮文字换行，所有按钮行高一致（2.25rem）；
- 按钮放不下时整组换行到第二行，而不是压缩变形；
- 编辑模式下头部只显示：`待补全`（如有）+ `调整等级` + `完成编辑` + `更多 ▾`；
- 「更多」展开面板可开合，面板外点击/Esc 关闭；面板项触达原有功能（媒体编辑器、恢复确认弹窗）；
- 有媒体（头像/立绘）时头部展示不受影响，`overflow: hidden` 裁剪无回归；
- 全量测试、类型检查、生产构建通过。
