## 后续来源批次准入条件

每一本 ERftLW、EGtW 或其他扩展来源只有同时满足以下条件才能标记完成：

1. 中英文名、稳定 ID、稀有度、九类目录类别、同调和来源已经核验。
2. 重印内容合并到原实体的 `sourceIds`，不创建同义重复条目。
3. 效果说明是项目原创摘要，不复制商业正文或第三方内容。
4. 数据完整性测试、筛选测试、全量测试和生产构建均通过。
