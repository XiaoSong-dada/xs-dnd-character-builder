### 3.3 法术与校验

- 子职法术表统一走 `SubclassRule.alwaysPreparedSpellIdsByLevel`（若 CHM 写明「始终准备」）或 `SubclassFeature.grantedSpells`；新增法术 ID 与 [E07-03](2024扩展内容引入-E07更新计划.md) 协同，先行引用 E02／E06 已落地的法术，未落地者登记依赖。
- 子职特性选择由 `requiresChoice` ＋ `optionIds`／`candidateKind` 派生检查点；跨等级不可重复的选项使用 `uniqueGroup`。
- 校验：候选池按来源、等级、职业与前置过滤；来源关闭保留选择并失效。

### 3.4 隔离与替换

- 隔离测试：知识领域、紫龙骑士、剑咏者与 2014 同名条目在 ID、数据、来源、候选池四个维度完全独立；开启 2014 来源不出现 2024 条目，反之亦然。
- 替换接口：来源字段记录 `source-2024-ua-fr-subclasses`；正式书到达后新增 `source-2024-fr-heroes` 并把同概念条目的 `sourceIds`／`adoptedSourceId` 切到正式版，ID 不变（D-04）。
