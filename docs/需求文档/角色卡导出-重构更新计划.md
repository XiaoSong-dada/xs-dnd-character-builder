## 1. 目标与完成定义

本次重构把 PDF 与 XLSX 从两套松散字段组装收束为唯一 `CharacterExportModel`，补齐武器、钱币、特性和施法导出规则，并为模板容量、字段缺失、公式缓存与内容截断提供统一诊断。JSON schema、导入导出逻辑及 5e-2014 单职业范围不变。

只有统一模型、规则、XLSX、PDF、页面交互和自动测试共同通过后，才登记实现完成；中间阶段不作为独立可交付版本。根据 2026-08-20 的最新要求，本轮跳过全部视觉校验，视觉结果不作为本轮交付结论；WPS/LibreOffice 兼容性仍需在具备对应软件的环境补验。

## 3. 关键实现约束

- `features/character-export/build-export-data.ts` 只暴露统一模型构建；页面 hook 不再组装 PDF/XLSX 字段。
- `services/export-pdf.ts` 与 `services/export-xlsx.ts` 只处理模板加载、适配、校验与下载。
- 阻断诊断禁止下载；警告诊断允许下载并显示受影响类别，不展示路径或堆栈。
- XLSX 模板版本固定为 4；`formula-cache` 保留公式并写缓存结果，工作簿设置打开时完整重算。
- PDF 映射项集中在 `PDF_REGION_MAP_V4`，包含页面、矩形、对齐、字号范围、颜色、最大行数和溢出策略。
- 特性按专长/关键资源、子职、职业、种族/子种族、背景排序；第一页溢出后续写人物资料页。
- spellbook 输出全部法术书法术并标记准备集合；known/pact 输出已知法术；prepared 输出准备法术；戏法始终全部输出。
