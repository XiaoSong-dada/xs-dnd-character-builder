# 角色形象（头像与立绘）更新计划

> 目标版本：**v1.1.0**
> 实施状态：**已完成**（613 测试通过、类型检查与生产构建通过）。

## 目标与范围

为角色增加**可选**头像与立绘：

- 身份步骤与角色卡编辑模式均可上传、替换、删除头像/立绘，并支持焦点（裁切/显示位置）调整和「从立绘生成头像」；
- 头像与立绘展示在车卡首页草稿列表、角色卡头部、跑团助手列表与详情头部；图片缺失或加载失败时自动隐藏，不显示占位图；
- 图片仅保存在当前浏览器或完整角色包中，不参与完成度、规则校验与派生计算；
- 草稿升级为 schema v7：只保存媒体引用与焦点元数据，Blob 存入 IndexedDB；
- 新增 ZIP 完整角色包（角色数据 + 头像/立绘）导出与导入，支持跨设备迁移；普通 JSON 导出明确移除媒体引用；PDF/XLSX 不写入图片。

## 实施步骤

1. **类型与存储**：`CharacterDraft` 升级为 schema v7，新增 `media?: CharacterMedia`（`CharacterMediaRef` / `CharacterPortraitRef`，含焦点元数据）；`draft-storage` 新增 v7 key 与 `migrateDraftToV7`，v2—v6 统一迁移，media 归一化（v7 之前迁移结果媒体为空）。
2. **图片处理服务** `services/character-image.ts`：JPEG/PNG/WebP 校验（≤10 MB、非空）、WebP 压缩（0.86）、头像 512×512 cover 裁切、立绘最长边缩放至 1600、焦点值 0—1 钳制。
3. **媒体存储服务** `services/character-media-storage.ts`：IndexedDB Blob 存取（save/load/remove/removeMany），草稿不直接保存图片二进制。
4. **完整角色包服务** `services/character-package.ts`：ZIP 内含 `character.json` + 可选 `media/avatar.webp`、`media/portrait.webp`；25 MB 上限（压缩前后均校验）；导入校验文件清单与媒体元数据一致性，重建角色 ID 与媒体 ID，失败回滚已保存图片。
5. **Store 与 JSON 边界**：`character-drafts` 新增 `importPackage`，删除草稿时清理关联媒体；`character-json` 导出移除 `media`、导入支持 `preserveMedia`（仅角色包使用）。
6. **共享特性** `features/character-media`：`CharacterMediaEditor`（上传/预览/焦点调整/从立绘生成头像/删除）、`CharacterMediaImage`（IndexedDB → 对象 URL，加载失败隐藏与释放）、hooks `useCharacterMediaEditing` / `useCharacterMediaUrl`。
7. **UI 集成**：身份步骤、角色卡（头部头像+立绘、编辑模式「编辑角色形象」弹窗、导出菜单新增「导出完整角色包」）、车卡首页（草稿列表头像、导入 JSON 或 ZIP）、跑团助手（列表头像、详情头部头像+立绘、导入 JSON 或 ZIP）。
8. **测试**：新增 `character-media.test.ts`（IndexedDB 往返、校验、焦点钳制）、`character-package.test.ts`（ZIP 往返、ID 重建、损坏包）；更新角色卡导出菜单、身份步骤、首页草稿条、跑团助手列表与 JSON 导入/迁移测试。
9. **文档与版本**：`docs/rules.md`（数据保存与导出能力、身份步骤、媒体展示约定）、`docs/frontend-architecture.md`（`features/character-media` 拓扑、三个新 service、v7 schema 说明）、`docs/quick-build-implementation.md`（v7 与角色包切片）、`CHANGELOG.md` / `README.md` / `app/README.md` / `app/package.json` 同步至 v1.1.0。

## 验收重点

- v2—v6 草稿与旧 JSON 导入自动迁移到 v7，媒体为空；本地 v7 草稿保存/恢复正常。
- 头像与立绘可上传（JPEG/PNG/WebP）、替换、删除；焦点拖动与滑块调整生效；从立绘生成头像与立绘焦点一致。
- 车卡首页、角色卡、跑团助手的头像/立绘展示符合「有且加载成功才显示，否则隐藏且无占位」约定。
- 普通 JSON 导出不含 `media`；ZIP 完整角色包可导出并在导入后重建角色与媒体 ID，图片可正常展示；损坏包、缺文件、超限均有中文错误提示。
- 删除草稿后 IndexedDB 中的关联图片被清理。
- `pnpm test:run` 全量通过（613 用例）、`vue-tsc` 类型检查与 `pnpm build`（vite-ssg）通过。
