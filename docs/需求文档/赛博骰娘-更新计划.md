# 赛博骰娘更新计划

## 1. 目标

将 `/dice` 从占位页升级为移动端优先的 D&D 3D 骰子工具。页面、底部导航和浏览器标题统一使用“赛博骰娘”，但视觉继续沿用项目现有羊皮纸暖色、酒红主色和金色点缀，不使用赛博朋克风格。

## 2. 首版范围

- 支持 `d4、d6、d8、d10、d12、d20、d100`。
- 支持同类多骰与混合骰池，逐颗展示结果并计算总和。
- 单次最多 20 个物理骰体；`d100` 由十位和个位两颗 d10 构成，占两个额度。
- 使用可靠随机源预定公平结果，使用 Three.js 与 cannon-es 呈现真实滚动、碰撞和停稳。
- WebGL、Worker 或物理预演失败时降级为公平文字结果。
- 首版不做声音、震动、修正值、优势劣势、历史、预设和角色卡联动。

## 3. 实施步骤

1. 新增骰子共享类型，以及骰池表达式、物理骰数量、d100 换算、逐颗结果和总和纯函数。
2. 封装 Web Crypto 拒绝采样，结果随机与物理动画随机相互独立。
3. 用统一顶点与面数据建立六种凸多面体；d100 展开为两颗 d10。
4. 在 Worker 中以固定时间步长运行 cannon-es，检测休眠、歪骰与超时，并传回可转移的轨迹数组。
5. 使用 Three.js 绘制暖色骰盘、象牙白骰子、酒红数字与金色边线；按最终落面应用合法对称旋转，使画面与预定结果一致。
6. 建立骰型选择、骰池控制、骰盘、结果区和投掷操作，处理忙碌锁定、清空、再次投掷、减少动态效果与文字降级。
7. 同步导航、路由标题、README、规则文档和前端依赖拓扑。
8. 执行纯逻辑、物理、页面状态测试、生产构建与手机宽度人工验收。

## 4. 验收标准

- 七种骰型范围、d100 边界、混合总和和 20 个物理骰限制正确。
- 固定种子的物理轨迹可复现，骰面旋转映射覆盖每种骰子的全部结果和落面。
- 投掷期间控件锁定，修改骰池后旧结果失效；物理失败时仍返回同一批公平文字结果。
- 375px 与 430px 下可完成选择、投掷、查看结果、再次投掷和清空流程。
- 离开页面后停止动画、终止 Worker 并释放 WebGL 资源。
- TypeScript、全量测试与生产构建通过，无浏览器控制台错误。

## 5. 实施状态

- 需求、规则、随机、物理、3D 渲染、页面交互、导航命名与文档同步：已完成。
- 自动化验收：51 个测试文件、359 项测试全部通过，TypeScript 与生产构建通过。
- 浏览器验收：已在 375px 验证混合骰池与 3D 投掷，在 430px 验证 10d100 满载投掷、数量上限、结果展示与路由离开清理；控制台无警告或错误。

## 6. v1.1 动态骰盘与移动视图

- 动态骰盘：按物理骰体数量使用 `clamp(sqrt(数量 / 6), 1, 1.85)` 扩大地面、碰撞墙、投放网格和摄像机范围；骰子尺寸与 20 个物理骰限制不变。
- 物理投放：骰子在二维网格内居中分散出生，水平初速度采用独立随机方向，降低满载骰池集中碰撞和卡墙概率。
- 视图控制：自动全景适配动态骰盘，成功停稳后开放最大 3 倍缩放、受限平移和复位；手机使用双指操作并保留单指页面滚动。
- 超时降级：单次投掷设置 20 秒端到端截止时间，超时终止 Worker 或动画并公布预生成的公平文字结果，迟到事件不得覆盖当前状态。
- 实施状态：代码、测试、规则文档和前端拓扑已更新；最终全量测试、生产构建和手机端人工验收结果以本次交付记录为准。
