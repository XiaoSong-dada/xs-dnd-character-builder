- 若后续 S00-03 决定第三方默认关闭，届时再评估字段，本批不受影响。

### 3.2 法术条目（S01-02）

- 落在 `spells-2014.ts` 的 `spellSeeds`；seed 行格式保持 `[englishName, name, level, classIds, sourceIds]`。
- 稳定 ID 规则 `spell-2014-<英文名小写连字符>`（既有 `spellId()` 生成，不手工写 ID）。
- `classIds` 映射到 `class-2014-*`：吟游诗人／牧师／德鲁伊／圣武士／游侠／术士／法师／邪术师／奇械师，按第 2 节表逐条对照；`思想编码` 为 `[]`。
- `ritual` 按 CHM 行填布尔（本批 20 条全部为 `false`，其中 `灾厄之刃` 不录入）。
- `sourceIds` 与第 3.1 节 ID 一一对应；`冰风谷` 两条为 `['idrotf-2020-index']`。
- 中文名以 CHM 为准；英文名以 CHM 为准但保留项目既有写法：`Enlarge/Reduce`、`Meld into Stone`、`Summon Lesser Demons`（本批无涉及）。

### 3.3 可选字段（S01-04）

- 在 seed 结构支持下（`SpellRule` 已声明可选字段），按 CHM 有明确值的条目填写：`school`、`castingTime`、`range`、`components`、`duration`、`concentration`。
- 施法时间/射程/成分/持续时间从各书详述页读取；无明确值留空，不做推断。
- 不建议在 S01 为此改动 `spellSeeds` 的元组结构；如实现时选择扩展元组，需同步更新既有 seed 解析逻辑（属实现细节，不改变交付结果）。

### 3.4 `思想编码` 呈现（S01-05，R1a）

- 已确认口径（S00-01）：`classIds: []`、`status: 'implemented'`、详情写明“无职业归属；由 DM／背景授予，可在手动添加法术中加入”。
- 验证：普通职业候选池（2014 任意职业）不出现该法术；手动添加候选包含该法术。
- 已放弃的备选：「随 GGR 公会法术授予」需要背景特性结构化与授予逻辑，不在本批（也不在本次计划）范围。

### 3.5 摘要口径（S01-03）

- 每条撰写原创中文摘要，含施法时间／射程／持续时间／效果要点；不复制 CHM 正文。
- 戏法成长（5/11/17）与高环施放条款按既有测试口径标注；本批无伤害性戏法成长条目。
- 摘要不得包含“元数据条目”“效果以规则来源为准”等占位文本（既有测试会拦截）。

### 3.6 明确不做

- 不修改 2024 目录、不修改来源模型字段、不新增 UI 组件、不做自动比对校验、不调整既有 489 条的字段与摘要。
