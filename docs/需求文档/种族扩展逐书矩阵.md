- 「定位」只证明玩家正文路径存在，不证明数值已核验或模型已支持。
- 「正文核验」表示已阅读机械正文；开放前仍需类型、必选任务、派生、来源、保存和导出测试。
- 「身份核验」只证明正式/合作/UA 分类，不代替效果核验。
- 除明确标记「已接入」的条目外，建议 ID 尚未登记，实施时检查全仓库碰撞。已有旧版本不覆盖；同一重印机械数据一致时才合并来源。
