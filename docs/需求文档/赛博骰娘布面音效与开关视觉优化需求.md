## 2. 用户需求

1. 优化骰娘投掷声音，使其更像多面骰落在布面骰盘上的声音；先调研常见跑团骰子声音。
2. 优化「跳过动画」「投掷音效」开关的视觉样式。现有开关偏窄，希望评估拉宽后的效果。

成功标准：声音听起来柔和、有投掷和停稳层次，不像白噪声或骰子砸在硬桌面上；开关在手机上容易辨认开/关状态，比例舒展，同时保持至少 44px 的触控高度和键盘可达性。

## 3. 调研结论：常见跑团骰盘的声音方向

### 3.1 常见实体骰盘材质

跑团骰盘常使用毛毡、天鹅绒或微纤维绒面作为落骰层。多个骰盘产品都把「降低滚动噪声」「让骰子柔和落下」作为核心特点：

- SkullSplitter 的跑团骰盘使用带软垫的毛毡底，并明确以更安静的滚动为卖点：[Tabletop Dice Trays](https://www.skullsplitterdice.com/pages/tabletop-dice-trays)。
- Fire Road 的木框骰盘使用再生毛毡底，说明该材质会柔化每次投掷的声音：[Classic Dice Tray](https://www.fireroad.us/products/classic-dice-tray)。
- Soar Forge 的骰盘使用软质天鹅绒内衬，将目标描述为类似赌场桌面的安静、受控滚动：[DND Dice Tray](https://shop.soarforge.com/products/dnd-dice-tray-blue-wolf-world-tree)。

因此，本项目目标应定义为「树脂/塑料多面骰落在有软质内衬、带硬边框的骰盘」：主体为短促、偏低频的闷响，滚动时有少量被吸收的细碎触碰，偶尔保留较清楚的弹跳或碰壁声。纯木桌面上尖锐、明亮、连续的啪嗒声不符合本次目标。

### 3.2 可参考的声音样本

- Pixabay 的骰子音效目录包含普通骰、桌游骰和 D20/多面骰录音，可用于比较投出、连续滚动、减速和停稳的节奏：[Dice sound effects](https://pixabay.com/sound-effects/search/dice/)、[D20 sound effects](https://pixabay.com/sound-effects/search/d20/)。
- 商业音效清单中已有明确的 `Dice Roll On Felt Board` 分类，说明「骰子落在毛毡板」是独立且成熟的拟音场景：[Casual UI sound list](https://www.asoundeffect.com/wp-content/uploads/2024/04/00_Casual_UI_CK_Metadata.pdf)。

本次只核验了在线目录与材质说明，尚未选定或实际试听真实录音；不能把这些链接当作已完成的听感对照。后续若改用音频文件，必须逐条核对素材页面、作者、授权类型、署名义务和再分发条件，不能仅凭「免费下载」直接纳入仓库。

## 4. 现状核验

### 4.1 优化前音效

当前 `app/src/services/dice-audio.ts` 使用 Web Audio 即时合成：

- 生成约 90ms 的单层宽频噪声；
- 用 1800Hz 低通滤波；
- 在动画期间重复播放，间隔逐渐拉长；
- 每次触发的声源和音色几乎相同，仅响度随时间衰减。

主要问题：

- 单层噪声缺少骰子实体的低频冲击，容易听成沙沙声或电子点击；
- 1800Hz 仍保留较多明亮高频，不够像布面吸收后的闷响；
- 每次触碰音色相同，缺少多颗多面骰的自然差异；
- 没有区分首次落地、滚动小碰撞、碰壁与最终停稳，声音缺少层次；
- 当前旧版接口没有接收骰子数量，各种骰池播放相同的序列；本次才新增数量适配，不能将旧版问题描述为数量造成堆叠。

### 4.2 优化前开关

当前 `DiceSettings.vue` 使用 Reka UI 的 `SwitchRoot`/`SwitchThumb`，语义、键盘操作和禁用逻辑正确。视觉参数为：

- 外框 `54 × 44px`，宽高比约 `1.23:1`；
- 内边距 `8px`，滑块 `24px`；
- 开启时只横移 `14px`。

44px 高度满足触控目标，但外框接近方形，轨道显得厚而短，滑块移动距离小，开/关状态的方向感不够明显。用户关于「偏窄」的判断成立。

## 5. 建议解决方案

### 5.1 音效：继续使用 Web Audio，重做为三层布面拟音

已确认继续合成，不引入外部音频文件。这能避免素材授权、下载体积和不同文件裁切长度问题，也方便声音严格跟随 1.5 秒动画。

每次投掷由三类声音组成：

| 层次 | 作用 | 建议声音 |
|---|---|---|
| 首次落地 | 表达骰子落到软垫上的重量 | 120—220Hz 的短低频主体，加少量 500—900Hz 滤波噪声；快速起音，约 45—80ms 衰减 |
| 滚动碰撞 | 表达棱角在布面上滚动 | 350—1100Hz 的带通/低通噪声脉冲；每次 25—55ms，间隔逐渐拉长，音量逐渐降低 |
| 停稳 | 给动画明确句点 | 一个更轻、更低的短闷响，避免清脆提示音或胜负音效 |

调音约束：

- 使用确定性伪随机数为每次碰撞微调频率、响度、声像与间隔，使同一轮内部自然变化，同时便于测试。
- 骰子数量只影响密度和有限的响度增长。总体增益采用对数或平方根压缩并设置上限，20 个物理骰不得接近削波。
- 使用重叠包络归一化和共享 PCM 软压缩保护输出；默认响度应适合手机扬声器，不盖过语音聊天。
- 动画实际播放多长，声音就调度多长；完成、超时、离页、静音和跳过动画继续立即停止所有节点。
- `AudioContext` 继续只在用户点击投掷后解锁。初始化、恢复或节点创建失败时静默降级，不能影响点数。
- 不实现逐帧物理碰撞音频，也不按每颗骰子创建完整独立声轨；当前轨迹协议没有碰撞事件，首批采用与视觉节奏匹配的拟音序列。

备选方案是录制或引入一段真实的树脂多面骰落在毛毡骰盘上的干声，并按 1.5 秒裁切。只有合成调音经真机试听仍无法达到目标时再启用此方案；素材应优先自产或使用明确允许项目再分发的 CC0/兼容许可，并在仓库记录来源和许可。

### 5.2 开关：改为更宽的标准胶囊比例

建议尺寸：

- 外框由 `54 × 44px` 调整为 `72 × 44px`，宽高比约 `1.64:1`；
- 滑块由 `24px` 调整为 `28px`；
- 左右内边距保持 `8px`，开启位移改为 `28px`；
- 圆角保持胶囊形，增加 `background-color` 和滑块位移的 150—180ms 缓动；
- 关闭态使用比正文弱、比边框深的中性色，开启态沿用主色；禁用态保留状态颜色并降低整体透明度。

选择 `72 × 44px` 的理由：保持项目要求的 44px 触控高度，横向增加 18px 后比例更舒展，滑块移动距离翻倍，状态更容易一眼分辨；在当前最大 48rem 的页面和「标签在左、开关在右」的行布局中不会挤压文字。无需把整个设置区域改成卡片网格或新增图标。

移动端窄屏仍保持每个设置项一行。标签可点击范围继续由 `<label for>` 关联，`aria-checked`、焦点轮廓、忙碌禁用、跳过动画时禁用音效等既有行为不变。

## 6. 实施前置条件

1. 准备三个固定试听场景：`1d20`、混合骰池 `1d20 + 2d6 + 1d100`、最大 `20d6`。
2. 试听设备至少包括手机扬声器和普通耳机；布面声的低频在手机上可能丢失，必须确认中低频噪声仍能表达触碰。
3. 提供旧音效与新合成音效试听对比；真实布面录音未选定，不作为本批前置门槛。重点判断「像布面」「不刺耳」「有落地和停稳」「多骰不吵」。
4. 若使用外部音频素材，先完成许可证与归档检查，再进入实现；使用推荐的 Web Audio 合成方案则无此依赖。
5. 开关只需在 320px、375px 和桌面宽度检查布局；本次不需要修改其他通用按钮或 Reka UI 封装。

## 7. 验收标准

### 音效

- 盲听时，新音效相较当前版本更常被判断为骰子落在毛毡/布面骰盘，而非硬木、玻璃或电子噪声。
- 1.5 秒动画内能听到首次落地、逐渐减速的小碰撞和轻微停稳，结果公布后无尾音。
- `1d20` 不显单薄，`20d6` 不爆音、不刺耳；音效失败不影响结果。
- 静音、跳过动画、减少动态效果、超时和离页行为保持正确。

### 开关

- 两个开关显示为宽胶囊形，开/关滑块位置差异明显，用户不需要依赖颜色判断状态。
- 320px 宽度下标签不与开关重叠，设置区不横向溢出。
- 鼠标、触摸、键盘、焦点、禁用和屏幕阅读器语义保持可用。
- 视觉改动仅影响骰娘设置开关，不扩散到其他组件。
