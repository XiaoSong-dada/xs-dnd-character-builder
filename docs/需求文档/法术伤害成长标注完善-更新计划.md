# 法术伤害成长标注完善 · 更新计划

> 依据《docs/需求文档/法术伤害成长标注完善需求.md》制定。本文件为实施计划存档，执行时按阶段推进。

## 目标与范围

- **根因**：`spells-2014.ts` 摘要表 `spellDescriptions` 的"等级/环位成长"标注登记不完整、口径不一致——雷鸣掌漏标 5/11/17 级戏法成长；约 99 条有高环施放（upcasting）伤害条款的法术漏标"每高 1 环 +X"；扩展书戏法成长表述简略（无骰数）。
- **已确认方案**：纯数据层修改 + 测试加固 + 文档同步。**不涉及**类型、UI 组件、stores、services、导出链路与选择逻辑；`SpellRule.description` 仍是只读展示文本，不进入自动计算。
- **不改动范围**：按角色等级动态计算/展示伤害（另行立项）；非伤害类 upcasting（目标数、持续时间）不强制补；除缺口 D 的 4 条外不重写既有摘要。

## 关键实施细节（已核验）

1. **摘要表现状**：`spellDescriptions` 共 489 条键值，风格示例——`cure-wounds`："…；每高 1 环 +1d8"；`magic-missile`："…；每高 1 环 +1 枚"；`armor-of-agathys`："…；每高 1 环 +5"；基础书戏法："…；5/11/17 级伤害 +1 骰"。
2. **既有"每高 1 环"标注共 27 条**（已核验）：`armor-of-agathys / cure-wounds / magic-missile / aid / scorching-ray / animate-dead / fireball / lightning-bolt / revivify / disintegrate / catapult / cause-fear / aganazzar-s-scorcher / borrowed-knowledge / healing-spirit / rime-s-binding-ice / snilloc-s-snowball-swarm / ashardalon-s-stride / erupting-earth / intellect-fortress / charm-monster / vitriolic-sphere / dawn / synaptic-static / bones-of-the-earth / crown-of-stars / abi-dalzim-s-horrid-wilting`。测试清单 B 必须包含这 27 条（否则反向断言失败）。
3. **戏法现状**：44 个戏法中 22 条含"5/11/17"标注（含扩展书简略版"5/11/17 级提升"），雷鸣掌缺失；补雷鸣掌后清单 A 共 23 条（伤害性且原书有成长的戏法）。
4. **缺口 D 前置**：龙卷风、痛苦真言、幻影龙、疯狂黑暗摘要缺基础伤害骰，须先补基础骰（如龙卷风 2d6、疯狂黑暗 8d8），再补"每高 1 环 +X"。
5. **测试设计（关键）**：采用 **ID 清单快照 + 双向断言**，不用正则自动判定（避免把无伤害/无成长法术误判为漏标）：
   - 清单 A（应有 5/11/17 标注的戏法，23 条）：断言全部含 `5/11/17`；**反向断言**——摘要含 `5/11/17` 的戏法必须全部在清单 A 内；
   - 清单 B（应有"每高 1 环"标注的法术，27 条既有 + 约 99 条新增 ≈ 126 条）：断言全部含 `每高 1 环`；**反向断言**——摘要含 `每高 1 环` 的法术必须全部在清单 B 内。
6. **数据核对基准**：全部成长数值以 `5e.tools` 2014 数据（项目现有来源）逐条核对后原创转述；需求文档 2.1 节缺口 B 清单为审核基准，核对后发现差异以规则来源为准修正并在交付说明记录。
