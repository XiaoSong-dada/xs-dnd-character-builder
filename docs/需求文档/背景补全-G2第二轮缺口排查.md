## 1. 为什么上一轮会漏（根因）

G 批次的缺口清单来自「背景页特征」过滤，判据是「同时含 `技能熟练`、`工具/[语言]`、`装备/金币`」。该判据有五个盲区：

| 盲区 | 后果 | 例证 |
| --- | --- | --- |
| 只认 `工具熟练`，不认 `工具熟练项` | 万象无常书与鬼魅幽谷整本漏掉 | 受宠者／受难者写的是「工具熟练项：一套你自选的赌具」 |
| 只扫「合作内容」以外的官方区 | **合作内容区（ID ≥ 4730）里的官方书全漏** | 费伦英雄、费伦冒险、艾伯伦：奇械锻炉、启封奥秘 |
| 只按「2014 写法」判定 | **2024 写法条目（`属性值：` + `专长：`）整类漏掉** | 艾伯伦：奇械锻炉 16 条、启封奥秘 10 条、费伦英雄 3 条 |
| 只搜中文名 | 家族后裔类条目按「XX家族后裔」命名，未被识别 | 艾伯伦 12 个龙纹家族后裔 |
| 未按「书目页（Credits）」分组核对 | 无法发现整本书是否有背景节 | 本轮改为按书分组后一次性暴露 |

## 2. 本轮排查方法（可复现）

1. **以 markdown 章节文件为单位全库扫描**（`.chm_output/DND.26.09.13/markdown/`，7028 个文件，文件名格式 `书名_章节_标题.md`，因此来源归属可按文件名前缀直接判定）。
2. 判定为背景需满足 ≥2 个字段特征：`技能熟练项：` / `工具熟练项：` / `语言：` / `装备：` / `属性值：` / `专长：`；排除含 `护甲等级`、`挑战等级` 的怪物数据块。
3. 另做一次「低阈值补充扫描」（仅命中 1 个字段），用于捞回写法更短的条目（如盐沼怪谈、黯潮之书的短字段背景）。
4. 与运行期仓库 `backgrounds2014`（83 条：基础 78 + 变体 5）＋ `backgrounds2024`（58 条）逐条按**中文名 + 英文名**比对，得到缺失清单。
5. 仍无法在 CHM 中定位独立背景节的第三方书，单列「无背景节」白名单（见 §6），避免下一轮重复排查。

6. **PDF 字体子集**：新增条目会引入新汉字，G2 完成后需重跑 `python tools-subset/make-subset.py` 并验证 `pdf-font.test.ts`（G 批次曾因缺字形失败 3 次）。
