- [ ] **UI-A01：徽章只显示数字、职业名改为 tag**

  - 要点：
    - 徽章文本 = `checkpoint.classLevel ?? checkpoint.level`（纯数字）；
    - tag 仅在 `checkpoint.classId` 存在时渲染，用 `UiBadge tone="primary"`，`flex: none`、不换行；
    - 标题块保持 `min-width: 0`，标题过长时优先收缩标题而不是撑破 tag；
    - 徽章补 `title` 与 `aria-label`（「职业 第 N 级」／无归属职业时「第 N 级」）。
  - 完成标准：长职业名（构造 6 字以上职业名或使用既有最长职业名）下头部不错位；无归属职业的检查点无 tag。
  - 验证：`test/components/TimelineStep.test.ts` 与 `multiclass-timeline-equipment.test.ts` 扩展/改写。
- [ ] **UI-A02：改写锁定旧标签的既有断言**
  - 交付：`multiclass-timeline-equipment.test.ts` 中原先读取 `.timeline-step__header span` 文本并断言「战士 1 级」「游荡者 1 级」的用例，改为分别断言**徽章数字**与**职业 tag**。
  - 已知受影响断言（取证）：该文件 `:54` 的 `levelLabels()` 辅助函数、`:81`「战士 1 级」、`:82`「战士 3 级」、`:84` 游荡者 1 级计 2 条、`:85` 不含「游荡者 3 级」。

  - 完成标准：改写后的用例仍能捕获「徽章取了总等级而不是职业等级」这类回归。

### UI-B：说明区截断与明细弹窗（D23—D27）

- [ ] **UI-B01：新增共享说明组件**
  - 交付：`src/components/ui/StatNote.vue`：入参 `{ details?: readonly string[]; fallback?: string; label: string; value: string | number; interactive: boolean }`；
    - 内部把明细拼成单行说明（` · ` 连接）并做 2 行截断显示；
    - 溢出检测：挂载后与 `ResizeObserver` 变化时比较 `scrollHeight > clientHeight`，得到 `truncated`；
    - `interactive && truncated` 时才可交互（`role="button"` / `tabindex="0"` / `aria-label`）；
    - 交互方式：`@dblclick`、触屏双击（沿用 250ms 判定窗口，与 `EditableStatTile.handlePointer` 一致）、`Enter` / `Space`；
    - 明细弹窗：`UiModal`，标题为「`label`（当前 `value`）」，正文按明细逐条 `<li>`；无明细时显示 `fallback` 原文。
  - 约束：样式放在组件 scoped SCSS，遵循 `&__el` / `&--mod` 嵌套约定；不引入新依赖（`ResizeObserver` 为原生）。
  - 完成标准：见 UI-B03 的验证清单。
  - 影响：**新增模块** → 实施后必须同步 `docs/frontend-architecture.md` 的 `src/components/ui` 清单与 `src/rules` 之外的依赖说明。
- [ ] **UI-B02：两个 tile 接入并迁移调用点**
  - 交付：`EditableStatTile.vue` 与 `StatTile.vue` 的说明入参由 `note?: string` 改为 `details?: readonly string[]`（保留 `note` 作为兼容兜底或一次性迁移，实施时二选一并在记录中写明）；`CharacterSheetStep.vue`（16 处）与 `SessionPanel.vue`（7 处）改传明细数组。
  - 要点：
    - `CharacterSheetStep.sourceNote()` 改为 `sourceDetails(sources): string[]`，每条为「`label` `±value`」，并在有 `detail` 时把 `detail` 一并交给弹窗（弹窗负责拼接展示）；
    - `abilityNote(key)` 这类固定文案传单元素数组；
    - `EditableStatTile` 的**编辑态双击进入编辑**行为必须保持不变（说明组件的交互只在非编辑态生效）；
    - `CharacterDrawer.vue` 的 5 处未传说明，不应因改造而报错或改变外观。
  - 完成标准：说明区显示内容与改造前**同源**（拼接口径一致）；弹窗明细包含 `detail`。
- [ ] **UI-B03：说明组件的针对性测试**
  - 交付：新增 `test/components/StatNote.test.ts`：
    - 明细拼接与 2 行截断的样式类；
