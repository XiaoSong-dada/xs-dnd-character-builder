# 法术译名对齐 5e 不全书需求

> 本需求文档由用户口头需求整理而成，**本次交付仅为需求理解、前置条件核验与全量对照分析，未修改任何代码**。

## 1. 背景与目标

用户需求：将项目当前全部法术中文翻译与 **5e 不全书（《DND 五版不全书》CHM v2025.11.8）** 逐条对照，判断差异，**最终以 5e 不全书中的翻译为准**。

先例：2026-08-27 已完成 2014 专长 46 项全部按同一 CHM 译名更名（用户指定例外，登记于《名称译名规范化需求.md》第 6a 节"用户指定例外"）。本次法术更名与专长同性质，同样按**用户指定例外**登记：法术中文名全部以 5e 不全书译名为准。

目标产物：

- 全量法术（489 条）与 5e 不全书的可审计对照关系与差异清单（本文件第 5 节）。
- 明确修改边界：仅改 `spells-2014.ts` 的 `name` 展示字段，稳定 ID 与 `englishName` 不动，草稿存档完全兼容。
- 为后续实施（数据层更名、防回归测试、文档与发布同步）提供定稿输入。

## 4. 对照结论

### 4.1 总体结论

- **差异规模大**（55.8%）：273 条法术名与 5e 不全书不一致，主要集中在 PHB 基础书（173 条）与 XGtE（71 条）。此前《名称译名规范化需求.md》以"官方简体中文书版（2016 授权版）术语 + 社区主流"为准的定稿与 CHM（果园系译名）存在系统性差异，属两套译名体系，并非错误，而是标准切换。
- **一致项 216 条**：含既有规范化中与 CHM 相同的条目（电爪、繁彩球、死云术、火焰风暴、再生术、灵体卫士、散射术、亡者丧钟、银光锐语、剑刃爆发、吸收元素、魔法飞弹、火球术、魔能爆、迷踪步、解除魔法、大步奔行、行动无踪、传讯术（Message）、活力灵光、生命灵光等），无需改动。
- **同名冲突**：273 条按 CHM 更名后，全量 489 条 `name` **无重复**（脚本已核验）；Message（传讯术）/Sending（短讯术）不再同名。无需额外人工改名。
