## 4. 第二阶段：录音接入（前置条件满足后）

### 资源与接口

- 确认成品作为本地构建资源引入，运行时不请求Freesound。
- 音频服务保留 `unlock()`、`stop()`、`dispose()`；新增 `prepare(): Promise<void>` 提前加载字节；播放改为 `play(durationMs)`，同步页面调用及测试。
- 页面挂载和用户后续开启有效音效时预加载，条件为音效开启、未跳过动画、未启用减少动态效果；加载去重。音频上下文仍仅在用户点击投掷时创建或恢复。
- 不同骰池统一播放一次录音，不按数量叠加、循环或改变音高。

### 播放与释放

- 实际动画开始事件是唯一播放入口，同轮重复事件不重播。
- 原速播放；录音短于动画则自然结束，动画短于录音则结束前最多20ms淡出并按动画时长截止。
- 加载、解码或音频恢复未完成时本轮静音；不延迟动画和结果，不在异步完成后补播。
- 加载失败静默降级，下次有效投掷允许重试。
- 完成、静音、超时、失败和离页停止并释放声源；离页使异步任务失效，迟到响应不得重新创建声源或播放。
- 保持1.5秒动画上限、3秒总等待、跳过动画、减少动态效果及跨页结果保留。
- 正式替换后移除不再使用的合成器及专属测试，试听工具改为使用正式录音；旧方案保留在历史文档。
