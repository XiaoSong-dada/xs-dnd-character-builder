# D&D 5e 2014 快速车卡规则约定

## 当前支持范围

- 唯一规则集：`5e-2014`
- 等级：1—20
- 角色结构：单职业
- 属性生成：标准数组、27 点购点、自定义录入
- 可选规则：专长、变体人类默认开放并显式标记
- 来源规则：Basic Rules 与 PHB 始终开放；其他已登记 2014 玩家来源由每份草稿的 `enabledSourceIds` 独立控制
- 数据保存：浏览器本地草稿与 JSON 导入、导出；可选头像/立绘二进制独立保存在 IndexedDB
- 导出能力：PDF 角色卡（约 1.25MiB 的国内 5E 术语版三页 AcroForm 运行时模板，静态中文字体已按实际用字子集化；pdf-lib 填充时嵌入 Noto Sans SC Regular 中文字体子集并扁平化，页序为基础角色卡、人物资料、法术表）、XLSX 自动计算卡（用户自制中文模板 + 「字段映射」表填充，公式自动计算）、不含图片的 JSON 数据文件、包含角色数据与图片的 ZIP 完整角色包；导出入口仅角色卡页
- 暂不包含：2024 规则、多职业、DM 房规编辑器、云同步

旧 2024 草稿只读隔离并允许导出。任何 2014/2024 同名内容都必须使用不同稳定 ID 和独立规则数据。

## 车卡顺序

1. 设置目标等级和属性生成方式。
2. 选择本次使用的 2014 扩展书；核心规则始终启用，不要求至少选一本扩展书。
3. 选择职业；列表使用稳定配置顺序，不再进行玩法偏好评分。
4. 自由选择种族、子种族、背景和正式背景变体。
5. 分配基础属性并应用种族、子种族加值。
6. 按 1—20 级时间线完成职业技能、子职、专长或属性提升及职业专属选择。
7. 选择并装备初始物品。
8. 配置施法（若职业具备）。
9. 填写身份资料，完成校验并生成角色卡。

修改职业、等级、种族、子种族或背景时，系统必须先报告受影响选择；旧选择保留并标记失效，不静默删除。

来源关闭使用同样的非破坏语义：职业、子职、种族、背景、专长、法术与物品的原始 ID 与子选择仍保留，但不再进入候选池、派生或导出；重新开启来源后自动恢复。

角色创建完成后仍可随时调整等级（1—20 任意跳级，升级或降级）或重新编辑全部原始选择：升级新增的检查点需在时间线补全（未完成时校验报错），升级后若施法配置（已知/准备/法术书法术或戏法数量）随新等级增加，将引导进入法术步骤补全；降级时超出新等级范围的选择保留并标记失效，系统按新等级提示数量减少的资源（熟练加值、属性提升/专长次数、战技、已知法术上限、子职特性、生命值）供玩家复查。

## 2014 起源

种族及子种族提供固定或自选属性加值、体型、速度、感官、语言与种族能力。背景不提供属性加值，而提供技能、工具、语言、背景特性及装备。

- 种族、子种族、背景和正式变体可在官方 2014 资料目录内自由组合。
- 变体只替换或调整对应基础条目的收益，不能重复叠加。
- 变体人类用两项不同属性各 `+1` 替换普通人类六项 `+1`，并在 1 级选择一项专长。
- 半精灵的两项自选属性不能再次选择魅力。
- 来自两个来源的同类熟练不能重复累计；应选择另一项同类熟练并记录替换来源。

属性页必须展示基础值、种族加值、子种族加值和最终值的来源链。

种族/子种族条目登记**原创中文详细介绍**（`RaceRule.description`，覆盖体型、速度、感官、语言与特性要点，72 条全部登记）；装备条目登记**完整详情与武器伤害**（`EquipmentRule.description` 覆盖护甲 AC/力量需求、工具用品用途等，`damageDice`/`damageType` 仅武器条目填写，37 条武器全部登记）。两者均为只读展示数据，供展开区展示，不进入自动计算。

种族熟练项已接入技能派生：`RaceRule` 登记固定技能熟练（`skillProficiencies`，如精灵察觉、半兽人威吓、歌利亚运动等 11 处）、自选技能规格（`skillProficiencyChoices`，如半精灵 2 项全技能、兽人 7 选 2 等 13 处，选项缺省为全部 18 项）、工具熟练规格（`toolProficiencyChoices`，矮人/战俑/维达肯/吉斯洋基）与武器/护甲熟练（`weaponArmorProficiencies`，展示级）。子种族沿 `parentRaceId` 链继承父种族熟练（如精灵系继承察觉）。技能熟练由 `derive` 合并背景、职业、种族三来源，来源标注"来自种族"；2014 规则无重复替换机制，同技能多来源只加一次熟练。工具/武器熟练为展示数据不参与派生（工具检定模型属后续批次 TODO）；吉斯洋基的腐化精通为技能/工具二选一。

## 属性生成

```text
属性调整值 = floor((属性值 - 10) / 2)
```

- 标准数组必须恰好使用 `15、14、13、12、10、8` 各一次。
- 本项目采用 27 点自由购点团规：六项基础属性从 8 开始，每提高 1 点消耗 1 点，总花费不得超过 27。27 点预算只计算第 5 步保存的基础值，不计入种族、子种族及后续等级属性提升；所有加成应用后的最终值仍不得超过 20。
- 自定义录入允许 3—20，并提示由玩家与 DM 确认来源。
- 属性提升通常把一项提高 2，或两项各提高 1；最终值不超过 20，除非规则明确例外。
- 开放专长时，专长与同等级属性提升互斥。

## 属性提升与专长

- 每个“属性提升或专长”检查点提供完整的自由属性提升：六项属性中的任意一项 `+2`，或任意两项不同属性各 `+1`，合计正好分配 2 点。
- 属性提升应用前必须以该检查点之外的当前属性为基准校验；任何会使最终属性超过 20 的组合不可选择，修改已有分配时不得重复累计。
- 专长目录收录 PHB 42 项、XGtE 15 项与 TCoE 15 项专长。扩展专长的种族/亚种前置、施法前置和半专长属性加值使用结构化父子检查点保存。
- 专长卡片展示原创摘要、来源与前置条件。不满足前置条件的条目保留在目录中并明确显示不可选原因。
- 完成度使用 `index-only → selectable → implemented`：只有索引数据的条目不可选；必选数据完整但存在战斗情境效果的条目可选并以原创摘要提示。

## 工匠与灌注

- 工匠从 1 级开始以智力准备施法，准备数量为“智力调整值 + 向上取整的职业等级一半”（最少 1），使用独立半施法位表。
- 2/6/10/14/18 级时的灌注已知数量通过唯一选项组校验；同时生效数量依次为 2/3/4/5/6。
- 灌注必须绑定物品栏中的合法条目。同一物品不得重复灌注；降级、删除物品、更换职业或关闭来源时保留绑定记录，但停止应用其派生加值。
- Alchemist、Armorer、Artillerist 与 Battle Smith 的始终准备法术不占准备上限；仆从、炮台与随机灵药以资源上限和摘要表示，不扩建战斗回合模拟器。

## 等级与核心计算

```text
熟练加值 = 2 + floor((等级 - 1) / 4)
技能加值 = 属性调整值 + 熟练加值（若熟练）+ 其他修正
豁免加值 = 属性调整值 + 熟练加值（若熟练）+ 其他修正
攻击加值 = 相关属性调整值 + 熟练加值（若熟练）+ 其他修正
法术攻击 = 施法属性调整值 + 熟练加值 + 其他修正
法术豁免 DC = 8 + 施法属性调整值 + 熟练加值 + 其他修正
先攻 = 敏捷调整值 + 其他修正
```

1 级最大生命值为职业生命骰最大值加体质调整值；后续等级按所选固定值或掷骰结果增加。护甲、天生护甲与无甲防御是不同基础公式，选择一个适用公式后再叠加盾牌等明确允许的修正。

所有派生数值都由草稿原始选择重新计算，并返回可显示的来源说明。

### 角色卡人工编辑

角色卡人工编辑使用独立差值，不覆盖职业、种族、装备、法术选择等规则事实。统一计算顺序为：系统基线 → 最终属性与熟练加值的人工调整 → 依赖重算 → 各派生字段自身的人工调整。再次编辑某字段时，以未叠加该字段人工差值的最新基线重新求差，避免重复累计。

- 上游人工调整：六项最终属性、熟练加值；
- 下游人工调整：AC、最大生命值、先攻、速度、武器命中与伤害、六项豁免、18 项技能、被动察觉、法术攻击、法术 DC；
- 法术资源：1—9 环法术位使用“职业系统数量 + 人工差值”；人工添加法术保存稳定 spell ID、加入目标和准备状态；
- 人工法术候选来自完整 5e-2014 系统法术库，不受职业列表、来源开关或正常已知/准备数量限制；展示时与后来通过规则正常获得的同 ID 法术去重，但双方来源均保留；
- 一键恢复仅清空人工差值和人工添加法术，不修改正常法术、抄录、装备、金币或跑团状态。

跑团状态跟随有效最大生命值与有效法术位协调。最大生命值变化时保持已损失生命值；当前生命和休息快照按新旧上限换算并钳制。法术位变化时保留已消耗数量，超过新上限的部分钳制到新上限。

## 2014 职业关键等级

- 牧师、术士、邪术师在 1 级选择子职。
- 德鲁伊、法师在 2 级选择子职。
- 野蛮人、吟游诗人、战士、工匠、武僧、圣武士、游侠、游荡者在 3 级选择子职。
- 当前 2014 子职目录共登记 118 项：116 项进入普通玩家时间线；死亡领域和破誓者作为 DM 专用索引登记，不进入普通玩家选择。
- 扩展资料子职按模型内自动化纵向切片接入：全部玩家子职登记等级特性、必选项、互斥、资源与可表达派生；情境效果使用 `selectable` 与原创摘要，不阻断保存和导出。
- 子职特性选择：`requiresChoice` 且带选项的特性由 `buildTimeline` 按所选子职追加 `subclass-feature` 检查点，玩家在时间线完成选择，未完成时校验报 error；换子职时旧特性选择自动作废。多选特性（如战斗大师战技：3/7/10/15 级各选 3/2/2/2 项，与 PHB 2014 一致）由特性的 `minSelections`/`maxSelections` 规格生成多选检查点，战技跨等级不可重复（校验按 `maneuver-` 前缀选项查重）。子职特性校验按检查点粒度与 `minSelections`/`maxSelections` 判定（不足提示、超选报错，单选特性仍报“选项互斥”），未解锁等级的特性不校验。首批可核验派生（龙族血脉：未着甲 AC 13 + 敏捷调整值、每级 +1 生命值）已接入 `derive`，数值来源可在角色卡查看。
- 世界树道途、舞蹈学院和海洋结社属于 2024 内容，不进入 2014 子职目录。
- 其他核心职业通常在 3 级选择子职。
- 圣武士与游侠从 2 级开始施法。
- 邪术师在 3 级选择魔契恩泽，契约法术位与其他施法模式分开处理。
- 时间线只展开当前检查点；自动获得的能力只展示，不要求玩家重复确认。
- 职业级选择特性（`requiresChoice`）必须由职业 checkpoints 提供选择入口：术士超魔法（3 级选 2 项、10/17 级各 +1 项，10 项选项登记在 `app/src/rules/data/metamagic-2014.ts`，`metamagic-` 前缀跨等级不可重复）、吟游诗人专精强化（10 级）与魔法奥秘（10/14/18 级各选 2 个任意职业法术，候选为全法术池且环级不高于当前最高环，所选法术计入角色卡法术展示与导出，但不占用已知法术上限）、法师法术精通（18 级选法术书中 1 环与 2 环法术各 1 个）与招牌法术（20 级选法术书中 3 环法术 2 个）。法术级选择使用动态候选池（`ChoiceCheckpoint.candidateKind`，由 `rules/spellcasting` 的 `getCheckpointCandidates` 按草稿解析）。
- 选择类选项详情数据：子职选择选项（战斗大师战技等 83 项）登记原创中文摘要与英文名于 `app/src/rules/data/subclass-choice-options-2014.ts` 与 `fighter.ts`（战技），角色卡能力页签"已选选项详情"区块与 PDF/XLSX 导出共用该数据。
- 职业基础等级特性登记在 `app/src/rules/data/class-features-2014.ts`（13 职业，包含工匠），`ClassRule.features` 经 `repository` 挂载；角色卡“能力”页签展示职业特性区块，时间线在首个职业检查点展示自动获得特性（只读）。
- 职业特性与子职特性均登记原创中文详细效果（`description`，571 条子职特性全量、146 条职业特性全量），角色卡“能力”页签与时间线特性条目均可展开查看；角色卡“能力”页签同时展示已选专长（可展开 `detail`）与属性提升（如“属性提升（智力+2）”），数据来自草稿 `selections`，只读展示。

2014 战士不包含武器精通。战斗大师新增战技不能与较低等级已掌握战技重复。

## 扩展来源与起源提示

- 第 2 步选择本角色使用的扩展书；Basic Rules 与 PHB 永久启用，扩展书允许全选、全不选和多选。
- 新草稿只在创建时默认启用当前全部可选 2014 来源；旧草稿迁移时仅推导实际引用来源，以后登记新来源不会改写既有草稿。
- 来源关闭不删除原选择；候选池、时间线、法术、物品、派生和最终校验共用同一来源判断，重新启用后恢复。
- 职业页按稳定配置顺序展示，不再计算玩法偏好、评分或推荐徽章。
- 第 3 步职业成长速览由规则数据推导（生命骰、施法起始等级、子职选择等级、时间线检查点），不硬编码任何职业文案。
- 第 4 步种族/背景推荐理由从数据推导：种族取 `fixedAbilityBonuses` 与职业主要属性交集，背景取背景技能与职业技能检查点选项交集；无交集时使用中性表述。

## 内容状态

- `implemented`：数据足以参与计算与合法性校验。
- `selectable`：结构化选择已完整，可保存与导出；情境效果以摘要提示并由桌面裁定。
- `index-only`：仅可浏览，缺少必选数据时不可选择。
- `dm-only`：2014 可选规则或需 DM 明确允许。
- `unavailable`：当前不可选择。

商业资料只记录稳定 ID、必要选择数量、原创摘要、来源与实现状态，不复制完整规则正文。

## 数据与界面原则

- 当前规则条目全部显式标记 `ruleset: '5e-2014'`。
- 法术规则以结构化 `ritual` 字段标记是否可仪式施法；全部法术列表的副标题保持英文名，并对仪式法术显示为“环位 · 英文名 · 仪式”。
- ID 包含版本，例如 `class-2014-fighter`、`race-2014-elf`。
- 导出数值必须由 `buildCharacterExportModel(draft, derived)` 统一生成并与页面派生结果一致。XLSX v4 按「字段映射」写入 `input`，为 `formula-cache` 保留公式并写缓存结果，设置打开时完整重算；PDF v6 按 AcroForm 字段名填充国内 5E 术语版三页模板，以 Noto Sans SC Regular 的实际字宽完成中文换行并显式控制字号，在下载前扁平化并重排页面。特性按完整条目先填第一页、再续排至人物资料页；物品清单写入人物资料页“宝物”，按完整物品条目横向排列并以两个普通空格分隔，当前行放不下时整项换行，只有单项超过整行宽度时才在条目内部换行；第一页装备框仅保留索引提示，钱币仍写入第一页对应币种框。武器逐件按近战力量、远程敏捷、灵巧取较高值计算，只有熟练时叠加熟练加值；无法可靠计算的情境加值不猜测并产生诊断。阻断诊断禁止下载，容量截断等警告允许下载并在下载后列出省略数量或原因；导出结果不保存为草稿字段。
- 身份步骤提供伦理轴“守序、中立、混乱”与道德轴“善良、中立、邪恶”组成的全部九种阵营；两个中立轴的交叉项显示为“绝对中立”。身份资料还可独立上传头像和立绘，两者均为可选，不参与完成度、规则校验或派生计算；支持调整人物焦点及从立绘生成独立头像。
- 头像与立绘仅保存在当前浏览器或 ZIP 完整角色包中：草稿 schema v7 只保存媒体引用与焦点元数据，Blob 存入 IndexedDB。普通 JSON 明确移除媒体引用；PDF/XLSX 不写入图片。旧 v2—v6 草稿迁移到 v7 时媒体为空。
- 车卡首页和跑团助手角色列表仅在头像存在且加载成功时显示头像。角色卡与跑团助手详情头部可显示头像和立绘；只有一种图片时仅显示该图片，两者都没有或加载失败时隐藏媒体区域，不显示默认占位图。
- `CharacterDraft` 只保存原始选择；派生值不作为唯一事实源持久化。
- UI 渲染注册表数据，不硬编码“战士只能选择人类与士兵”等限制。
- 错误必须给出中文原因和返回步骤；选中、错误和禁用状态不能只依赖颜色。
- 所有主要点击目标至少 44 px。

## 赛博骰娘

- `/dice` 支持 `d4、d6、d8、d10、d12、d20、d100`，可以组合相同或不同骰型一次投掷。
- 普通骰结果为 `1—N` 的整数；`d100` 使用十位 d10 与个位 d10，`00 + 0` 解释为 `100`。
- 一次最多投掷 20 个物理骰体；普通骰占一个额度，`d100` 占两个额度。
- 每颗逻辑骰独立生成公平随机结果；动画随机只决定运动轨迹，不决定点数。
- 总和等于全部逻辑骰结果之和；`d100` 只以换算后的结果计入一次。
- 物理动画或 WebGL 不可用时仍展示相同规则生成的文字结果，不使用 `Math.random` 替代可靠随机源。
- 物理骰盘按物理骰体数量动态扩大：`1—6` 个保持基础尺寸，更多骰子按 `clamp(sqrt(数量 / 6), 1, 1.85)` 同步扩大地面、边界、投放区域与摄像机范围。
- 成功停稳并公布结果后可缩放和平移 3D 视图；视图操作只改变摄像机，不改变骰子轨迹与结果，新一轮投掷恢复自动全景。
- 从触发投掷起最多等待 20 秒，覆盖物理准备与动画播放；超时立即停止视觉流程并公布投掷开始时已生成的同一批公平文字结果。
- 首版不保存骰池或投掷历史，不包含固定修正、优势、劣势、声音、震动或角色卡联动。

## 法术数据范围

- 法术条目收录范围：2014《玩家手册》（PHB）、XGtE、EGtW、TCoE、FTD、SCC；SCAG 新增法术已并入 TCoE 重印条目，不单独登记。
- 每个法术保存：稳定 ID、中英文名、环级、8 个主施法职业归属、来源索引与**原创中文效果摘要**（`description`：施法时间/射程/持续时间/效果要点，全部 489 条已登记，版权合规转述，不复制原书正文）；摘要含戏法 5/11/17 级伤害成长与高环施放（upcasting）伤害/数值成长标注，成长信息登记完成度 100%；效果以规则来源为准。法术中文名以 5e 不全书（CHM v2025.11.8）译名为准（用户指定例外，2026-08-31 全量 273 条对齐，稳定 ID 与英文名不变，草稿兼容）；`id` 基于英文名生成，改名不影响草稿兼容。
- 全量法术表位于 `app/src/rules/data/spells-2014.ts`，各职业 `classSpellIds` 均由该表按职业过滤派生，跨职业共享法术只登记一次并合并职业归属。
- EGW 的 dunamancy（时间魔法/引力魔法）法术属于法师子职专属，不在 8 个主职业标准法术列表中，未收录。
- VRGR 与 BGG 法术因公开数据源不可达暂未收录，待后续批次补充。
- 新增来源登记：`scc-2021-index`（斯翠海文：混沌课程索引）；各书法术来源见 `app/src/rules/repository.ts` 的 `sources`。
- 法术位按职业等级表派生展示、不持久化：全施法者（吟游诗人、牧师、德鲁伊、术士、法师）共用全施法者法术位表，半施法者（圣武士、游侠，2 级起）使用半施法者法术位表，邪术师使用契约法术位表（法术位数量 1—4 个、环级随等级升至 5 环，短休恢复），奥法骑士与诡术师（子职级施法）共用三分之一施法者表（3 级起，1—2 级无环位，最高 4 环）。四张表登记在 `app/src/rules/data/spell-slots-2014.ts`（来源 Basic Rules / SRD 5.1 / PHB 2014），由 `rules/spellcasting` 的 `getSpellSlots` 按职业等级返回，施法配置步骤与角色卡法术页签展示，调整等级后即时重算。
- 准备施法职业（牧师、德鲁伊、圣武士、游侠）在 2014 规则下直接知晓整个职业法术列表（无“法术书”机制）：角色卡法术页签按三块展示（已准备 / 未准备法术 / 全部职业法术只读参考，含已学戏法），准备与取消准备实时联动；导出 PDF/XLSX 时法术表输出全部可达环级职业法术并标记已准备，且按“已准备优先”排序（组内按环级与名称），保证已准备法术优先可见。戏法数量按 2014 PHB 表登记并从法术步骤选择：牧师 1—3 级 3 个、4—9 级 4 个、10 级起 5 个；德鲁伊 1—3 级 2 个、4—9 级 3 个、10 级起 4 个；未选满时校验报错（`cantrip-count`）并在升级引导中提示缺口。圣武士、游侠 2014 规则无戏法。法师（法术书）维持“法术书 + 准备标记”的既有展示与导出。
- **法师抄录法术书**：法师可在角色卡「法术」页签与跑团助手「法术」页签抄录额外法术（两处共用同一草稿的 `spellSelections` 与 `adventureGold`）。抄录费用 = 环级 × 50 GP（每环级另需 2 小时，仅提示不记录），从冒险净增金币（`adventureGold`）扣除，持有总额不得为负；抄录不可撤销（不提供移出/退款，车卡法术步骤中抄录法术同样不可移除）。抄录候选 = 法师职业法术池中环级 ≥ 1、≤ 当前最高可施放环且尚未写入法术书的法术（不含戏法）；抄录后法术写入 `spellbookSpellIds` 并记录于 `transcribedSpellIds`（升级自动获得的法术不在此列）。**抄录法术不计入升级名额**：法术书校验与界面计数（角色卡、车卡法术步骤）均按“非抄录法术数”对比升级自动名额（至少达到），抄录法术以「抄录」标记单独展示、不顶替免费名额，法术书总数可超过名额。抄录法术与升级法术同等地位：可被准备、可被选为法术精通/招牌法术、自动进入 PDF/XLSX/JSON 导出。规则层实现为 `app/src/rules/spellbook.ts` 纯函数（候选池、费用、金币校验、应用），共享界面在 `app/src/features/spellbook-transcription/`；`schemaVersion` 4 起新增 `transcribedSpellIds`，v3 及更早草稿导入/迁移自动补空数组。
- 子职级施法：奥法骑士（战士）、诡术师（游荡者）3 级起以智力施法（已知法术制，无法师法术书），配置挂在 `SubclassRule.spellcasting`，由 `rulesRepository.getSpellcastingConfig` 统一解析（子职配置优先、否则回退职业配置）；已知法术 3 级 3 个、共 11 个，戏法 3 级 2 个、10 级 3 个，法术池为法师法术列表。2014 规则学派限制（奥法骑士限防护/塑能、诡术师限幻术/惑控，8/14/20 级自由）当前未在候选池过滤，界面提示 DM 确认，学派数据登记属后续批次。

## 装备数据范围

- 装备条目收录范围：2014《玩家手册》（PHB）装备章节全部普通装备（护甲 12 + 盾牌 1、武器 37、冒险装备、17 种工匠工具、6 种专用工具包、4 种游戏套具、10 种乐器、4 种法器、7 个标准套组、坐骑与车辆）与《地下城主指南》（DMG 2014）第 7 章魔法物品全量（按英文名 A–Z 分文件收录，含药水、卷轴、法杖、魔杖、戒指、奇物与诅咒物品）及神器 8 件。
- 全量装备资料索引位于 `docs/dnd-equipment.md`，分文档位于 `docs/equipment/5e-2014/`；每个条目记录稳定 ID、中英文名、分类、官方价格与重量（普通装备；魔法物品按稀有度给参考区间并由 DM 定价）、是否可装备、**原创中文介绍**与登记状态，版权合规转述，不复制原书正文。
- 代码现状：`EquipmentRule` 已显式登记 `ruleset`、中英文名、内容状态与三态同调；魔法物品另有九类目录索引、`varies` 稀有度和特殊同调条件。旧 `requiresAttunement` 字段已原子移除。
- 魔法物品无固定价格，价格按稀有度参考区间（常见 50–100 gp、非普通 101–500 gp、稀有 501–5,000 gp、非常稀有 5,001–50,000 gp、传说 50,001+ gp）；扩展书补充魔法物品（XGtE 常见魔法物品、TCoE 刺青等）列为待补批次。
- DMG 2014 的 247 条 A–Z/神器候选与 ERftLW、EGtW 扩展目录由构建期脚本 `scripts/build-item-catalog.mjs` 从 `docs/equipment/5e-2014/` Markdown 生成类型化分块（`rules/data/generated/`），运行时不再解析 Markdown；主界面只装配最小运行时索引（展示/校验/派生所需字段，不含完整描述），完整描述在“添加物品”弹窗首次打开时按需加载并缓存，加载失败可重试。手工核验条目按稳定 ID/中英文名覆盖；聚合型号与神器保持 `index-only`，具体候选为 `selectable`，复杂效果不进入自动派生。
- “添加物品”弹窗支持中文名、英文名和稳定 ID 搜索；稀有度、类别、同调与来源组内取或、组间取且，空组返回空结果。普通装备只在稀有度全选时保留，避免与 `common` 魔法物品混淆。
- 物品栏数量调整边界：仅"冒险获得"（`sourceKind === 'adventure'`）条目可在角色卡物品页签调整数量（减少/增加/删除全部）；职业与背景起始装备条目由重新编辑流程管理、不直接调整。减少时装备数量同步收缩（恒满足 `equippedQuantity ≤ quantity`），扣减至 0 或删除整条需二次确认且不返还金币；增加只入物品栏、不改变装备数量。删除/减量/增量由 `app/src/rules/starting-equipment.ts` 的 `removeAdventureItem` / `decreaseAdventureItem` / `increaseAdventureItem` 纯函数处理，变更随草稿持久化。
