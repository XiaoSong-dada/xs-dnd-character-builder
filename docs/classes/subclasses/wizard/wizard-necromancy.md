# 死灵学派 School of Necromancy

## 基本信息

- 子职 ID：`wizard-necromancy`
- 所属职业：[`wizard` 法师](wizard.md)
- 规则集：`5e-2014`
- 原版2级选择；用于2024法师时首批特性在3级取得
- 来源与边界：2014 Player's Handbook；商业规则，仅记录特性结构与原创摘要
- 官方详情：[2014 Player's Handbook](https://www.dndbeyond.com/sources/dnd/phb-2014)
- 最后核验：2026-07-27

## 玩法定位

从死亡魔法中汲取生命，强化自己创造的不死仆从，并在高等级尝试控制其他不死生物。

## 特性详解

### 3级（原版2级）：死灵学者 Necromancy Savant

- 特性 ID：`wizard-necromancy-necromancy-savant`
- 动作或触发：抄录死灵法术时
- 资源与恢复：无次数限制

降低抄录死灵系法师法术所需时间与金币。

实现与校验：

- 只影响法术书抄录；校验死灵学派和法术来源。

### 3级（原版2级）：惧怖收割 Grim Harvest

- 特性 ID：`wizard-necromancy-grim-harvest`
- 动作或触发：用带法术位的法术令生物生命归零时
- 资源与恢复：每回合一次

从死亡中恢复生命；恢复量随法术环级增长，使用死灵法术时效果更高，但对构装体和不死生物无效。

实现与校验：

- 校验击杀归属、每回合限制、目标类型和法术位环级；不能超过最大生命值。

### 6级：不死奴仆 Undead Thralls

- 特性 ID：`wizard-necromancy-undead-thralls`
- 动作或触发：学习并施放操纵死尸时
- 资源与恢复：被动强化召唤物

自动取得核心造不死法术，并让一次施法影响更多尸体；自己创造的不死仆从获得额外生命和攻击伤害。

实现与校验：

- 绑定2014法术与怪物数据；保存控制期限、仆从数量、额外生命和攻击加值来源。

### 10级：不死适应 Inured to Undeath

- 特性 ID：`wizard-necromancy-inured-to-undeath`
- 动作或触发：被动
- 资源与恢复：无次数限制

获得黯蚀伤害抗性，且最大生命值不会被规则效果降低。

实现与校验：

- 抗性只对黯蚀伤害；最大生命保护不等于免疫普通伤害或生命上限的主动重算。

### 14级：命令不死生物 Command Undead

- 特性 ID：`wizard-necromancy-command-undead`
- 动作或触发：动作；选择可见不死生物
- 资源与恢复：同一时间受控目标有限；目标可重复豁免

尝试以魅力豁免控制一个不死生物；高智力目标更容易抵抗，并可能周期性重新豁免。

实现与校验：

- 校验生物类型、智力、豁免、持续与唯一受控目标；目标成功后按原版设置免疫或重试限制。

## 兼容与校验

- 战役必须允许该来源，法师达到子职选择等级，且子职选择位尚未占用。
- 角色数据保留 `5e-2014`；原版2级特性在2024法师框架下于3级取得，其余等级保持来源记录。
- 法术、召唤物、状态、休息和动作术语必须绑定明确规则版本。
- 新旧同名或替代能力不得叠加；规则数据与自动化测试尚未实现。
