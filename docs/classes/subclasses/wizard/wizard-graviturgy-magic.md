## 玩法定位

改变生物与物体的重量，以法术牵引目标位置、放大攻击或坠落伤害，并在高等级制造限制移动的重力视界。

## 特性详解

### 3级（原版2级）：调整密度 Adjust Density

- 特性 ID：`wizard-graviturgy-magic-adjust-density`
- 动作或触发：动作并保持专注
- 资源与恢复：同一时间一个目标；持续1分钟

改变附近合格生物或物体的重量：减轻会提高移动但削弱力量表现，加重会降低移动但强化力量表现；高等级可影响更大目标。

实现与校验：

- 保存目标、轻/重模式、专注和到期；体型与距离必须合格；移动修正不能把速度降到非法值。

### 6级：重力井 Gravity Well

- 特性 ID：`wizard-graviturgy-magic-gravity-well`
- 动作或触发：法术命中、目标豁免失败或目标自愿失败时
- 资源与恢复：每个合格法术目标一次

用自己的法术影响生物时，把目标向一个附近空位移动一小段距离。

实现与校验：

- 只在特性列出的三种触发之一发生；目标移动到合法空位；属于被迫移动，不按普通移动处理借机攻击。

### 10级：暴力吸引 Violent Attraction

- 特性 ID：`wizard-graviturgy-magic-violent-attraction`
- 动作或触发：反应；附近攻击命中或生物坠落时
- 资源与恢复：智力调整值次/长休，至少1次

瞬间强化重力，使一次武器攻击额外造成伤害，或提高一次坠落造成的伤害。

实现与校验：

- 触发分为攻击与坠落两类；保存次数；同一次伤害只能强化一次；目标必须在范围内。

### 14级：事件视界 Event Horizon

- 特性 ID：`wizard-graviturgy-magic-event-horizon`
- 动作或触发：动作并保持专注
- 资源与恢复：长休一次，或按来源消耗法术位恢复

形成持续的重力场，使敌人在进入或开始回合时进行力量豁免；失败会被压制到无法移动，成功也会显著减速。

实现与校验：

- 保存区域、专注、持续与每目标豁免；只影响敌对或自选目标；恢复所需法术位和动作按原版来源。
