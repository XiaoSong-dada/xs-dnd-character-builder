# 时间魔法 Chronurgy Magic

## 基本信息

- 子职 ID：`wizard-chronurgy-magic`
- 所属职业：[`wizard` 法师](wizard.md)
- 规则集：`5e-2014`
- 原版子职等级按来源；用于2024职业时首个子职特性在3级取得
- 来源与边界：Explorer's Guide to Wildemount；商业规则，不复制正文
- 官方详情：[Explorer's Guide to Wildemount](https://www.dndbeyond.com/sources/dnd/egtw)；最后核验：2026-07-27

## 玩法与特性

时间法师通过干预事件发生的先后与结果承担控场和支援职责：前期可以迫使关键检定重掷并提高先攻，中期能够短暂冻结目标、把法术保存后交给其他生物释放，后期可以强制一次检定走向成功或失败。

## 特性详解

### 3级（原版2级）：时间转移 Chronal Shift

- 特性 ID：`wizard-chronurgy-chronal-shift`
- 动作类型：反应
- 触发范围：30尺内一个可见生物进行攻击检定、属性检定或豁免检定
- 使用次数：2次
- 恢复方式：长休后恢复全部

在目标完成掷骰、但成功或失败尚未正式确定时，时间法师可以扭转这一瞬间，迫使目标重新掷骰。新结果必须取代原结果，不能从两次结果中选择较有利的一次。

实现与校验：

- 保存剩余次数、触发检定类型、原结果和重掷结果。
- 只能在结果正式结算前触发；结算完成后不能回溯使用。
- 新骰点必须覆盖原骰点。
- 如果该骰已经通过其他规则重掷，需要按通用重掷限制或DM团规则处理。

### 3级（原版2级）：现世感知 Temporal Awareness

- 特性 ID：`wizard-chronurgy-temporal-awareness`
- 动作类型：被动
- 使用次数：无限制

时间法师对即将发生的行动具有超常预感，在自己的先攻检定中加入智力调整值。

```text
先攻加值 = 敏捷调整值 + 智力调整值 + 其他先攻修正
```

实现与校验：

- 把智力调整值记录为独立的先攻修正来源，不能直接修改敏捷调整值；多个同名特性不得重复叠加。

### 6级：片刻停滞 Momentary Stasis

- 特性 ID：`wizard-chronurgy-momentary-stasis`
- 动作类型：动作
- 目标：60尺内一个体型不超过大型的生物
- 豁免：体质豁免，对抗法师的法术豁免 DC
- 使用次数：智力调整值次，至少1次
- 恢复方式：长休后恢复全部

时间法师尝试将目标冻结在一个短暂的时间泡中。目标豁免失败后获得失能状态且速度变为0，效果持续到时间法师下一回合结束；目标在持续期间受到任何伤害时，效果立即结束。豁免成功时目标不受影响，但本次使用仍会消耗。

实现与校验：

- 目标必须位于范围内，且体型不得超过大型。
- 保存目标 ID、豁免结果、效果结束回合和本次使用消耗。
- 受到伤害时立即同时移除失能与速度归零。
- 该效果不是麻痹、震慑或束缚，不能错误套用这些状态的额外规则。

### 10级：奥术中止 Arcane Abeyance

- 特性 ID：`wizard-chronurgy-arcane-abeyance`
- 触发方式：施放符合条件的法术时
- 法术限制：使用不高于4环的法术位
- 微粒持续时间：1小时
- 使用次数：1次
- 恢复方式：短休或长休后恢复

时间法师可以把正在施放的法术冻结成一枚临时存在的魔法微粒，而不立即结算法术。持有微粒的生物之后可以使用动作释放其中的法术；法术使用时间法师的法术攻击加值与法术豁免 DC，但释放微粒的生物在其他交互中视为该法术的施法者。微粒到期或被摧毁时，其中的法术失效。

建议保存的数据：

```text
storedSpellId
slotLevel
creatorCharacterId
creatorSpellAttackBonus
creatorSpellSaveDc
createdAt
expiresAt
holderCharacterId
released
destroyed
```

实现与校验：

- 保存法术时立即消耗对应法术位。
- 只有符合环级限制的法术可以被保存。
- 微粒释放、到期或被摧毁后必须清除，不能重复使用。
- 法术需要专注时，由释放微粒并被视为施法者的生物承担专注。
- 法术的目标、范围、放置位置和其他施放条件在释放时继续校验。
- 魔宠、召唤物或其他生物能否接收并释放微粒，以及高风险法术组合是否允许，由DM团规则决定。

### 14级：趋同未来 Convergent Future

- 特性 ID：`wizard-chronurgy-convergent-future`
- 动作类型：反应
- 触发范围：60尺内一个可见生物进行攻击检定、属性检定或豁免检定
- 普通次数限制：无
- 使用代价：每次使用获得1级力竭

当目标完成符合条件的掷骰、但结果尚未正式结算时，时间法师可以选择一条确定的时间线：把该次检定调整为刚好成功所需的最低结果，或者调整为比成功要求低一点的失败结果。它不是重掷，也不是普通数值加减。

实现与校验：

- 必须在成功或失败正式确定前触发。
- 保存时间法师选择“成功”还是“失败”，并记录调整后的最终结果。
- 使用后立即增加力竭，不能因为其他减免而忽略本特性的代价。
- 原规则对这种力竭的恢复有限制；实现时必须保留来源，不能当作普通临时减益直接清除。
- 2014与2024的力竭机制不同。混用2024法师框架时，角色或战役配置必须明确 `exhaustionRuleset`，禁止逐次选择更有利的版本。

## 兼容与校验

- 战役必须允许 Explorer's Guide to Wildemount/Critical Role 来源，且法师子职选择位尚未占用。
- 原版2级获得的时间转移与现世感知，在2024法师框架下统一于3级取得；6、10、14级特性保持原等级。
- 角色数据必须保留 `ruleset: 5e-2014`，并由DM明确动作术语、休息恢复、力竭和法术版本。
- 奥术中止涉及施法资格、法术位消耗、物品交接、专注归属与特殊行动经济，进入自动车卡前必须单独建立校验。
- 新旧同名或替代能力不得叠加；规则数据与测试尚未实现。
