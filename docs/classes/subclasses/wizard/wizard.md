# 法师 Wizard

## 基础资料

- 职业 ID：`wizard`；规则集：`5e-2024`
- 主要属性：智力；生命骰：`d6`；豁免：智力、感知；子职：3级
- 职业介绍：以研究掌握奥术的施法者：法术书持续积累法术、每日更换准备列表，奥术回想补充施法能量，子职决定学派专精方向。
- 技能：从奥秘、历史、洞悉、调查、医药、自然、宗教中选2项
- 训练：简易武器；无护甲。奥术法器或法术书可以作为法师法术的施法法器
- 起始装备：A 2匕首、长棍奥术法器、长袍、法术书、学者套组、5 GP；B 55 GP
- 多职业前置：智力13

## 1级车卡与公式

1. 选择2项技能、3个戏法，并在法术书写入6个1环法术；从书中准备4个。
2. 法术书与准备列表必须分开保存；仪式学家可从书中施放带仪式标签且未准备的法术。

```text
1级最大生命值 = 6 + 体质调整值
法术攻击加值 = 熟练加值 + 智力调整值
法术豁免 DC = 8 + 熟练加值 + 智力调整值
```

## 资源与校验

- 升级后向法术书加入2个当前法术位环级允许的法师法术。
- 将发现的一环以上法师法术抄入法术书，每法术环级耗时2小时并花费50 GP；从自己的法术书复制到备用书时，每法术环级耗时1小时并花费10 GP。法术书遗失后，只能先把当前准备的法师法术转录到新书，再另行找回其他法术。
- 准备法术长休可从法术书重选；戏法长休可替换1个。
- 奥术回想短休后恢复总环级不超过法师等级一半向上取整，且不能恢复6环以上槽，长休一次。
- 法术精通选择书中施法时间为动作的一环和二环法术各一道，始终准备并能以最低环免费施展；长休时可将其中一道换为同环合格法术。
- 招牌法术选择书中两道三环法术，始终准备并各有一次三环免费施展；两道法术的免费次数分别记录，短休或长休恢复。
