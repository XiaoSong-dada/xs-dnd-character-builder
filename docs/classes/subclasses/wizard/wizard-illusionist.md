- 子职 ID：`wizard-illusionist`

- 规则集：`5e-2024`

## 玩法定位

以更灵活的幻术制造声音、图像和虚假生物，能够用幻象避开攻击，并短暂让幻术造物成为现实。

## 特性详解

### 3级：幻术学者 Illusion Savant

- 特性 ID：`wizard-illusionist-illusion-savant`
- 动作或触发：被动
- 资源与恢复：无次数限制

免费扩充低环幻术法术，并在解锁新法术位环级时继续获得一个当前可用的幻术系法师法术。

实现与校验：

- 必须校验法师列表、幻术学派和环级；每个新环级只领取一次。

### 3级：精进幻术 Improved Illusions

- 特性 ID：`wizard-illusionist-improved-illusions`
- 动作或触发：施放基础幻术时
- 资源与恢复：无次数限制

强化次级幻影等基础幻术，使施放更迅速，并能在一次幻术中组合更丰富的声音与图像表现。

实现与校验：

- 只修改特性明确列出的幻术或戏法；奖励动作施放仍受同回合法术规则约束；保存声音与图像两个组成部分。

### 6级：幻影生物 Phantasmal Creatures

- 特性 ID：`wizard-illusionist-phantasmal-creatures`
- 动作或触发：施放子职指定的召唤/幻影法术
- 资源与恢复：含一次免费施放或法术位消耗

获得与幻影生物有关的常备法术，并能以幻术方式召来暂时的生物协助。

实现与校验：

- 召唤物必须绑定法术版本与数据块；保存免费施放状态、专注、持续和行动归属。

### 10级：幻象自我 Illusory Self

- 特性 ID：`wizard-illusionist-illusory-self`
- 动作或触发：反应；攻击命中自己时
- 资源与恢复：使用后按休息或资源恢复

在命中瞬间制造一个替身幻象，让该次攻击落空。

实现与校验：

- 必须在命中后伤害前触发；只让触发攻击失效，不影响同一敌人的其他攻击；记录反应与恢复状态。

### 14级：幻象成真 Illusory Reality

- 特性 ID：`wizard-illusionist-illusory-reality`
- 动作或触发：施放带法术位的幻术后使其中物体实体化
- 资源与恢复：受每次法术与持续限制

从幻术中选择一个非魔法、非生命物体，使它在短时间内成为真实存在；不能借此直接造成伤害或制造违禁效果。

实现与校验：

- 保存来源法术、实体对象和到期时间；对象必须符合尺寸与无害约束；法术结束或持续到期后清除实体。

## 兼容与校验

- 战役必须允许该来源，法师达到子职选择等级，且子职选择位尚未占用。
- 角色数据使用 `5e-2024`，不得引用2014同名子职的数值或触发方式。
- 法术、召唤物、状态、休息和动作术语必须绑定明确规则版本。
- 新旧同名或替代能力不得叠加；规则数据与自动化测试尚未实现。
