- 子职 ID：`wizard-conjuration`
- 所属职业：[`wizard` 法师](wizard.md)
- 规则集：`5e-2014`
- 原版2级选择；用于2024法师时首批特性在3级取得

## 玩法定位

专精召唤物体、生物与空间转移，能够临时创造小型物品、交换位置并提高召唤法术的稳定性。

## 特性详解

### 3级（原版2级）：咒法学者 Conjuration Savant

- 特性 ID：`wizard-conjuration-conjuration-savant`
- 动作或触发：抄录咒法法术时
- 资源与恢复：无次数限制

降低把咒法系法师法术抄入法术书所需的时间与金币。

实现与校验：

- 只影响抄录流程，不影响升级免费加入法术；必须标记法术学校和来源版本。

### 3级（原版2级）：次级咒法 Minor Conjuration

- 特性 ID：`wizard-conjuration-minor-conjuration`
- 动作或触发：动作
- 资源与恢复：同一时间一个造物

临时创造一个自己见过的非魔法小型物体；物体有体积和重量限制，并会在持续结束、再次使用特性或受到特定交互后消失。

实现与校验：

- 保存参照物、尺寸、重量、创建时间和消失条件；不能创造魔法物品、消耗品内部复杂内容或规则禁止物。

### 6级：良性传送 Benign Transposition

- 特性 ID：`wizard-conjuration-benign-transposition`
- 动作或触发：动作
- 资源与恢复：使用后长休恢复；施放咒法法术可按规则刷新

短距离传送到可见空位，或与一个合格且自愿的生物交换位置。

实现与校验：

- 校验距离、可见空位、目标体型与自愿状态；交换位置属于传送，不触发普通移动事件。

### 10级：专注咒法 Focused Conjuration

- 特性 ID：`wizard-conjuration-focused-conjuration`
- 动作或触发：被动
- 资源与恢复：无次数限制

因受到伤害而进行的专注检定不会打断自己的咒法系法术。

实现与校验：

- 只免除伤害引起的专注中断；失能、主动结束或其他规则仍能结束专注；法术必须属于咒法学派。

### 14级：耐久召唤 Durable Summons

- 特性 ID：`wizard-conjuration-durable-summons`
- 动作或触发：召唤或创造生物时
- 资源与恢复：每个合格生物一次

自己通过咒法法术召唤或创造的生物获得额外的生存能力。

实现与校验：

- 召唤物必须由自己的咒法法术产生；额外生命属于临时生命或指定增益时不能与同类数值叠加；法术结束后移除。

## 兼容与校验

- 战役必须允许该来源，法师达到子职选择等级，且子职选择位尚未占用。
- 角色数据保留 `5e-2014`；原版2级特性在2024法师框架下于3级取得，其余等级保持来源记录。
- 法术、召唤物、状态、休息和动作术语必须绑定明确规则版本。
- 新旧同名或替代能力不得叠加；规则数据与自动化测试尚未实现。
