# 2014 法师实现说明

- 稳定 ID：`class-2014-wizard`
- 规则集：`5e-2014`
- 实现状态：基础职业时间线、法术书、准备法术与派生数值已实现

## 施法数据

- 1级选择3个戏法，法术书写入6个1环法术。
- 每提升1个法师等级，法术书增加2个当前可施放环级的法师法术。
- 准备数量为“智力调整值 + 法师等级”，至少1个。
- 准备法术必须已经存在于法术书。
- 法术攻击与法术豁免 DC 分别使用智力调整值。

## 时间线

- 1级选择2项职业技能。
- 2级选择奥术传统。
- 4、8、12、16、19级选择属性提升或专长。

当前八个核心奥术传统保留稳定索引；尚未核验的子职效果为 `index-only`。
