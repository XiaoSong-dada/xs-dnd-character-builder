# 回音骑士 Echo Knight

## 基本信息

- 子职 ID：`fighter-echo-knight`
- 所属职业：[`fighter` 战士](fighter.md)

- 官方详情：[Explorer's Guide to Wildemount](https://www.dndbeyond.com/sources/dnd/egtw)

## 玩法定位

在战场生成可移动回音，从回音位置攻击、换位和借机，随后借回音侦察、护卫、吸收生命并维持双回音。

## 特性详解

### 3级：回音显现 Manifest Echo

- 特性 ID：`fighter-echo-knight-manifest-echo`
- 动作或触发：奖励动作；在附近空位生成或移动回音
- 资源与恢复：无固定次数；同一时间通常一个

创建有独立AC和1生命的回音；攻击可从自己或回音位置发出，并可与回音换位或借其发动借机攻击。

实现与校验：

- 保存回音位置、生命与距离；换位消耗奖励动作和移动；回音不是生物。

### 3级：化身突袭 Unleash Incarnation

- 特性 ID：`fighter-echo-knight-unleash-incarnation`
- 动作或触发：采取攻击动作时从回音位置追加近战攻击
- 资源与恢复：体质调整值次/长休，至少一次

从回音位置额外进行一次近战攻击。

实现与校验：

- 必须有回音且选择攻击动作；扣除次数；额外攻击位置读取回音。

### 7级：回音现身 Echo Avatar

- 特性 ID：`fighter-echo-knight-echo-avatar`
- 动作或触发：动作；把意识转入回音
- 资源与恢复：每次持续受距离和时间限制

通过回音感知并远程移动它，用于侦察；本体失去相应感知。

实现与校验：

- 记录意识状态、距离与持续；回音超限或被毁时结束；不能借此无限战斗。

### 10级：暗影殉身 Shadow Martyr

- 特性 ID：`fighter-echo-knight-shadow-martyr`
- 动作或触发：反应；附近生物被攻击指定
- 资源与恢复：短休或长休一次

把回音传送到目标身旁，使该次攻击改为以回音为目标。

实现与校验：

- 校验回音存在、目标距离和空位；使用原攻击结果；回音承受命中。

### 15级：回收潜能 Reclaim Potential

- 特性 ID：`fighter-echo-knight-reclaim-potential`
- 动作或触发：回音因受伤被摧毁时
- 资源与恢复：体质调整值次/长休，至少一次

获得与战士等级和体质相关的临时生命。

实现与校验：

- 只在回音由伤害摧毁时触发；临时生命不叠加；扣除次数。

### 18级：一人成军 Legion of One

- 特性 ID：`fighter-echo-knight-legion-of-one`
- 动作或触发：奖励动作回音显现时
- 资源与恢复：共享回音显现能力

可同时维持两个回音，并在掷先攻且无化身突袭次数时恢复一次。

实现与校验：

- 保存两个独立位置；攻击与换位仍受一次动作限制；恢复不超过上限。
