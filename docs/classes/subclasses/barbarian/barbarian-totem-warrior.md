## 子职定位

图腾武者通过动物灵性获得可切换的狂暴期增益：选择熊、鹰或狼图腾，在狂暴中获得对应的防御、机动或团队压制能力，并在高等级继续强化同一图腾路线。它是 2014 野蛮人的 PHB 核心道途之一，车卡时要求玩家完成图腾选择。

### 3级：图腾精魂 Totem Spirit

- 特性 ID：`barbarian-totem-warrior-totem-spirit`
- 获得条件：达到3级并选择本道途。
- 玩家选择：单选（熊、鹰、狼三选一）。
- 资源与恢复：不建立独立资源池；增益与狂暴状态绑定。

## 选择、资源与校验

- 3级必须从熊、鹰、狼中选择一种图腾，且只能选择一种。
- 6级与14级的图腾强化必须与3级选择保持一致，车卡与校验不得允许中途更换。
- 图腾增益与狂暴状态绑定，狂暴不生效时相应增益不适用。
- 子职不额外建立独立点数池；资源主要依赖狂暴次数、反应与仪式施法。
- 具体数值效果未经官方文本核验前保持 `index-only`，只登记选择所需的名称、来源与原创摘要。
