# 野蛮人（Barbarian）— 5e-2014

- 职业 ID：`class-2014-barbarian`
- 职业介绍：以狂暴为核心的前线战士：狂暴期间提升伤害、获得力量检定与豁免优势并减伤，配合 d12 生命骰成为最耐打的职业之一。玩法直接，适合新手与偏好正面强攻的玩家。
- 主要属性：力量（5e 不全书「快速建卡」：最高属性分配给力量，次高分配给体质）
- 子职选择：3级
- 属性提升/专长：4、8、12、16、19级
- 当前状态：1—20级选择时间线已实现

玩家在1级选择2项职业技能，3级选择原初道途。狂暴、鲁莽攻击、险境感知、额外攻击、不屈意志等自动能力不要求重复确认。

派生计算已支持 d12 生命骰、力量/体质豁免、无甲防御和5级快速移动。子职具体效果仍按资料状态分别处理。
