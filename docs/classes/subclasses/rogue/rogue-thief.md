# 盗贼 Thief

## 基本信息

- 子职 ID：`rogue-thief`
- 所属职业：[`rogue` 游荡者](rogue.md)
- 规则集：`5e-2024`
- 选择等级：3级
- 来源与边界：2024 Free Rules / SRD 5.2.1；开放规则
- 官方详情：[2024 Free Rules / SRD 5.2.1](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes)
- 最后核验：2026-07-27

## 玩法定位

以奖励动作操作物品与机关，强化攀爬、跳跃和隐匿，并在高等级突破魔法物品限制和首轮行动上限。

## 特性详解

### 3级：快手 Fast Hands

- 特性 ID：`rogue-thief-fast-hands`
- 动作或触发：奖励动作；作为狡诈动作选项
- 资源与恢复：每回合受奖励动作限制

可用奖励动作进行指定巧手操作或执行利用动作，更快开锁、解除陷阱或操作物件。

实现与校验：

- 动作必须属于特性允许列表；需要检定时使用正确工具或巧手；仍消耗奖励动作。

### 3级：二楼工作 Second-Story Work

- 特性 ID：`rogue-thief-second-story-work`
- 动作或触发：被动
- 资源与恢复：无次数限制

获得更可靠的攀爬速度，并用敏捷改善跳跃距离。

实现与校验：

- 派生攀爬和跳跃值；只使用规定属性；与其他速度来源按通用规则合并。

### 9级：极致隐匿 Supreme Sneak

- 特性 ID：`rogue-thief-supreme-sneak`
- 动作或触发：满足装备或移动限制时进行隐匿
- 资源与恢复：无固定次数

在适合潜行的条件下获得更稳定的隐匿检定，并强化从隐匿状态行动的能力。

实现与校验：

- 检定时校验护甲、移动或其他限制；优势不在条件失效后保留。

### 13级：使用魔法装置 Use Magic Device

- 特性 ID：`rogue-thief-use-magic-device`
- 动作或触发：协调或使用魔法物品、卷轴及充能物品时
- 资源与恢复：受协调栏位与物品充能限制

可协调更多魔法物品，忽略部分职业使用限制，并有机会不消耗充能；还可尝试施放高环卷轴。

实现与校验：

- 最多协调4件；充能节省按规定骰值；卷轴检定使用智力与指定DC；失败按规则处理。

### 17级：盗贼反射 Thief's Reflexes

- 特性 ID：`rogue-thief-thiefs-reflexes`
- 动作或触发：战斗第一轮
- 资源与恢复：每场战斗一次额外回合

在第一轮以较低先攻值获得第二个回合，大幅提高开场行动量。

实现与校验：

- 生成独立先攻条目；只在第一轮；第二回合遵守特性对动作或资源的额外限制。

## 兼容与校验

- 战役必须允许该来源，游荡者达到3级，且子职选择位尚未占用。
- 规则数据保留 `5e-2024`；不得隐式混用另一规则集的同名能力、偷袭或狡诈打击数值。
- 偷袭每回合频率、动作经济、反应、法术位与独立资源必须分开追踪。
- 新旧同名或替代能力不得叠加；规则数据与自动化测试尚未实现。
