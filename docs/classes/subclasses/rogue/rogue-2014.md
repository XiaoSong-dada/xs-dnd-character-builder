# 游荡者（Rogue）— 5e-2014

- 职业 ID：`class-2014-rogue`
- 职业介绍：以技能与精准打击见长的专家：只要取得优势或目标旁有队友，偷袭即可提供稳定额外伤害；专精与狡黠行动让隐匿、开锁、解除陷阱与撤退都非常可靠。
- 主要属性：敏捷（5e 不全书「快速建卡」：最高属性分配给敏捷）
- 子职选择：3级
- 属性提升/专长：4、8、10、12、16、19级
- 当前状态：1—20级选择时间线已实现

玩家在1级选择4项职业技能和2项专精，6级再选择2项未重复的专精。专精只能应用于已熟练技能或盗贼工具。

派生计算已支持 d8 生命骰、敏捷/智力豁免、敏捷攻击、皮甲和双倍熟练加值。偷袭、灵巧动作等自动能力不要求重复确认。
