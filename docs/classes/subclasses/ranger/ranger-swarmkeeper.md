## 特性详解

### 3级：集群牧者魔法 Swarmkeeper Magic

- 特性 ID：`ranger-swarmkeeper-swarmkeeper-magic`
- 动作或触发：被动；随等级解锁
- 资源与恢复：自动获得

获得法师之手及虫群、蛛网和自然控制主题额外法术。

实现与校验：

- 按等级解锁；额外法术不占普通准备数量；法师之手外观可主题化。

### 3级：聚集虫群 Gathered Swarm

- 特性 ID：`ranger-swarmkeeper-gathered-swarm`
- 动作或触发：每回合武器命中生物后
- 资源与恢复：每回合一次

选择让虫群追加伤害、推动目标，或把自己移动一小段距离。

实现与校验：

- 三选一；推动需目标豁免；自身移动不等同于传送且按规则处理借机攻击。

### 7级：蠕动浪潮 Writhing Tide

- 特性 ID：`ranger-swarmkeeper-writhing-tide`
- 动作或触发：奖励动作
- 资源与恢复：熟练加值次/长休

获得由虫群托举的短时飞行速度。

实现与校验：

- 扣除次数并记录持续；结束时移除飞行；失能等结束条件按来源处理。

### 11级：强力虫群 Mighty Swarm

- 特性 ID：`ranger-swarmkeeper-mighty-swarm`
- 动作或触发：聚集虫群触发时
- 资源与恢复：每回合一次并沿用原选择

强化三个虫群选项：提高伤害、使推动目标倒地，或为自身提供额外防护。

实现与校验：

- 先选择原选项再应用对应升级；额外状态需校验豁免结果。

### 15级：集群驱散 Swarming Dispersal

- 特性 ID：`ranger-swarmkeeper-swarming-dispersal`
- 动作或触发：反应；受到伤害时
- 资源与恢复：熟练加值次/长休

虫群分散身体，令该次伤害减半，并把自己传送到附近可见空位。

实现与校验：

- 在伤害结算时触发；减半与抗性按规则顺序；终点可见且未占用。
