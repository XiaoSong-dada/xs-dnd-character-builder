# 2014 游侠实现说明

- 稳定 ID：`class-2014-ranger`
- 规则集：`5e-2014`
- 来源：2014 Basic Rules；非开放子职效果只保留索引
- 实现状态：基础职业、时间线、装备与半施法已实现

## 车卡选择

- 1级：选择3项职业技能、1种宿敌与1种偏好地形。
- 2级：选择箭术、防御、决斗或双武器战斗风格。
- 3级：选择猎人或驯兽师范型；当前子职效果为 `index-only`。
- 6、14级：新增宿敌。
- 6、10级：新增偏好地形。
- 4、8、12、16、19级：属性提升或专长。

## 施法

- 从2级开始施法，施法属性为感知。
- 掌握法术数量严格使用2014游侠职业表：2级2个，10级6个，20级11个。
- 最高可用法术环级由2014游侠职业表驱动。
- 法术攻击为“熟练加值 + 感知调整值”。
- 法术豁免 DC 为“8 + 熟练加值 + 感知调整值”。

## 校验

- 已知法术数量必须与当前等级一致。
- 法术必须属于2014游侠列表，且不能高于当前可用环级。
- 重复法术与跨职业法术会阻止规则合法完成。
