# 2014 圣武士实现说明

- 稳定 ID：`class-2014-paladin`
- 规则集：`5e-2014`
- 来源：2014 Basic Rules；非开放子职效果只保留索引
- 实现状态：基础职业、时间线、装备与半施法已实现

## 车卡选择

- 1级：从运动、洞悉、威吓、医药、游说、宗教中选择2项技能。
- 2级：选择防御、决斗、巨武器战斗或保护战斗风格。
- 3级：选择神圣誓言；奉献、古贤、复仇当前为 `index-only`。
- 4、8、12、16、19级：属性提升或专长。

## 施法

- 从2级开始施法，施法属性为魅力。
- 准备数量为“魅力调整值 + 圣武士等级的一半（向下取整）”，至少1个。
- 最高可用法术环级由2014圣武士职业表驱动。
- 法术攻击为“熟练加值 + 魅力调整值”。
- 法术豁免 DC 为“8 + 熟练加值 + 魅力调整值”。
- 誓言法术不计入准备上限；本批先在界面明确提示，具体誓言法术表随子职数据批次接入。

## 校验

- 准备数量必须准确。
- 法术必须属于2014圣武士列表，且不能高于当前可用环级。
- 重复法术与跨职业法术会阻止规则合法完成。
