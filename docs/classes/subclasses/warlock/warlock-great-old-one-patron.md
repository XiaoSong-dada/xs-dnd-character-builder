## 特性详解

### 3级：旧日宗主法术 Great Old One Spells

- 特性 ID：`warlock-great-old-one-patron-great-old-one-spells`
- 动作或触发：被动常备
- 资源与恢复：不占普通准备数

按等级获得心灵、预言和异怪主题的常备邪术师法术。

实现与校验：

- 按等级解锁；绑定2024法术；不占普通准备数。

### 3级：心灵法术 Psychic Spells

- 特性 ID：`warlock-great-old-one-patron-psychic-spells`
- 动作或触发：施放合格附魔或幻术法术时
- 资源与恢复：无固定次数

让部分心灵法术更隐蔽，并能把特性允许的伤害转换为心灵伤害。

实现与校验：

- 校验法术学派、组件变化和原伤害类型；每次施法保存是否转换。

### 3级：觉醒心智 Awakened Mind

- 特性 ID：`warlock-great-old-one-patron-awakened-mind`
- 动作或触发：建立心灵连接
- 资源与恢复：同一时间受连接数量限制

与附近生物建立双向心灵通讯，即使没有共同语言也能传递可理解的思想。

实现与校验：

- 保存连接目标、距离和持续；目标必须满足语言/智力前置；连接结束后清除通讯权限。

### 6级：千里眼战斗者 Clairvoyant Combatant

- 特性 ID：`warlock-great-old-one-patron-clairvoyant-combatant`
- 动作或触发：奖励动作或心灵连接中的战斗触发
- 资源与恢复：目标与持续受限

利用心灵连接预判一个敌人的行动，使自己更容易命中该目标，并让目标更难命中自己。

实现与校验：

- 同一时间保存一个战斗目标；优势和劣势按通用规则处理；目标离开连接后结束。

### 10级：魔能邪咒 Eldritch Hex

- 特性 ID：`warlock-great-old-one-patron-eldritch-hex`
- 动作或触发：施放或维持邪术时
- 资源与恢复：依赖邪术/法术资源

强化六角诅咒一类的标记，使目标在更多相关豁免或心灵对抗中处于不利。

实现与校验：

- 保存被诅咒目标和选择的属性；不能把属性检定劣势错误应用到所有豁免。

### 10级：思想护盾 Thought Shield

- 特性 ID：`warlock-great-old-one-patron-thought-shield`
- 动作或触发：被动
- 资源与恢复：无次数限制

阻挡他人读取思想，并对心灵伤害提供防护或反制。

实现与校验：

- 区分思想读取、心灵通讯和心灵伤害；只对特性明确范围生效。

### 14级：创造奴仆 Create Thrall

- 特性 ID：`warlock-great-old-one-patron-create-thrall`
- 动作或触发：施放指定异怪召唤法术时
- 资源与恢复：含一次免费施放/长休

获得并强化异怪召唤法术，可用宗主力量进行一次免费施放，并改变该次召唤的专注或持续方式。

实现与校验：

- 绑定2024召唤法术和数据块；保存免费施放、专注例外、持续和召唤物行动。
