# 邪魔宗主 Fiend Patron

## 基本信息

- 子职 ID：`warlock-fiend-patron`
- 所属职业：[`warlock` 邪术师](warlock.md)
- 规则集：`5e-2024`
- 选择等级：3级
- 来源与边界：2024 Free Rules / SRD 5.2.1；开放规则，可整理到实现级
- 官方详情：[2024 Free Rules / SRD 5.2.1](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes)
- 最后核验：2026-07-27

## 玩法定位

通过击倒敌人获得临时生命，以邪魔运气修正检定，并逐步获得可切换抗性和单体放逐爆发。

## 特性详解

### 3级：黑暗祝福 Dark One's Blessing

- 特性 ID：`warlock-fiend-patron-dark-ones-blessing`
- 动作或触发：敌人生命降为0时
- 资源与恢复：无固定次数

自己令敌人生命降为0，或附近敌人被他人降为0时，获得等于魅力调整值加邪术师等级的临时生命，至少1点。

实现与校验：

- 校验目标是敌人、距离和归零事件；临时生命不叠加，只保留一组。

### 3级：邪魔法术 Fiend Spells

- 特性 ID：`warlock-fiend-patron-fiend-spells`
- 动作或触发：被动常备
- 资源与恢复：不占普通准备数

在邪术师特定等级自动常备一组邪魔主题法术，这些法术视为自己的邪术师法术。

实现与校验：

- 按等级解锁；不计入普通准备法术数量；法术必须绑定2024版本。

### 6级：黑暗幸运 Dark One's Own Luck

- 特性 ID：`warlock-fiend-patron-dark-ones-own-luck`
- 动作或触发：属性检定或豁免后、结果结算前
- 资源与恢复：魅力调整值次/长休，至少1次

为自己的一次属性检定或豁免追加1d10；看到原骰后使用，但每次掷骰只能使用一次。

实现与校验：

- 不能用于攻击检定；保存次数；在结果正式结算前触发。

### 10级：邪魔韧性 Fiendish Resilience

- 特性 ID：`warlock-fiend-patron-fiendish-resilience`
- 动作或触发：短休或长休后选择
- 资源与恢复：持续到下次选择

选择除力场外的一种伤害类型并获得抗性。

实现与校验：

- 保存当前类型；新选择覆盖旧选择；不得选择力场；抗性按通用规则不重复叠加。

### 14级：投掷地狱 Hurl Through Hell

- 特性 ID：`warlock-fiend-patron-hurl-through-hell`
- 动作或触发：每回合一次，攻击命中后
- 资源与恢复：长休一次；可消耗契约魔法槽恢复

迫使目标进行魅力豁免；失败时短暂消失并失能，非邪魔还承受大量心灵伤害，之后回到原位置附近。

实现与校验：

- 校验每回合一次、目标豁免、邪魔类型、返回空位和恢复资源；消失期间不在战场上。

## 兼容与校验

- 战役必须允许该来源，邪术师达到子职选择等级，且子职选择位尚未占用。
- 角色数据使用 `5e-2024`，不得引用2014同名宗主的数值或触发方式。
- 契约魔法槽、普通法术位、免费施放次数和独立资源池必须分开记录。
- 新旧同名或替代能力不得叠加；规则数据与自动化测试尚未实现。
