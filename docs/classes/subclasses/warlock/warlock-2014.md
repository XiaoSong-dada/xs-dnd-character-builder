- 1级开始契约施法，施法属性为魅力。

## 时间线

- 1级选择2项职业技能与异界宗主。

- 3级选择契约恩赐。
- 4、8、12、16、19级选择属性提升或专长。

宗主、祈唤与契约恩赐的商业效果当前为 `index-only`，可预览但会提示资料完整性。
