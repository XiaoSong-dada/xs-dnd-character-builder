## 特性详解

### 3级：剑圣之道 Path of the Kensei

- 特性 ID：`monk-kensei-path-of-the-kensei`
- 动作或触发：被动；选择剑圣武器并使用相关攻击
- 资源与恢复：达到等级时增加武器选择

获得剑圣武器熟练；近战中可借徒手攻击提高AC，远程攻击可用奖励动作追加伤害。

实现与校验：

- 保存合法武器列表；格挡需本回合持武器并徒手攻击；远程增伤只限剑圣武器。

### 6级：人剑合一 One with the Blade

- 特性 ID：`monk-kensei-one-with-the-blade`
- 动作或触发：使用剑圣武器命中时
- 资源与恢复：每回合可消耗气追加伤害

剑圣武器视为魔法武器；命中后可消耗气加入武艺骰伤害。

实现与校验：

- 魔法标签不改变伤害类型；每回合频率和气消耗正确追踪。

### 11级：磨砺锋芒 Sharpen the Blade

- 特性 ID：`monk-kensei-sharpen-the-blade`
- 动作或触发：奖励动作；强化剑圣武器
- 资源与恢复：消耗1至3气，持续一段时间

赋予武器相同数值的命中与伤害加值；已有魔法加值的武器通常不适用。

实现与校验：

- 校验武器现有加值；保存强化值与持续；新强化覆盖旧强化。

### 17级：百发百中 Unerring Accuracy

- 特性 ID：`monk-kensei-unerring-accuracy`
- 动作或触发：自己回合用武僧武器攻击未命中时
- 资源与恢复：每回合一次

重掷该次攻击，必须采用新结果。

实现与校验：

- 只限武僧武器攻击；每回合一次；新结果不可再次由本能力重掷。
