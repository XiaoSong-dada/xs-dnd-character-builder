## 特性详解

### 3级：元素协调 Elemental Attunement

- 特性 ID：`monk-elements-elemental-attunement`
- 动作或触发：奖励动作或武学资源激活
- 资源与恢复：消耗专注点并持续一段时间

激活后徒手打击可改为多种元素伤害、延长触及，并在命中时推动或拉近目标。

实现与校验：

- 记录持续和所选伤害；推动/拉拽需目标豁免；触及只在自己回合的攻击时扩展。

### 6级：元素爆发 Elemental Burst

- 特性 ID：`monk-elements-elemental-burst`
- 动作或触发：魔法动作；选择远处爆发点
- 资源与恢复：消耗专注点

在球形区域释放元素能量，目标敏捷豁免，失败承受多枚武艺骰伤害，成功减半。

实现与校验：

- 选择允许的元素类型；校验射程、区域、豁免和武艺骰随等级升级。

### 11级：元素步伐 Stride of the Elements

- 特性 ID：`monk-elements-stride-of-the-elements`
- 动作或触发：使用疾风步时
- 资源与恢复：依赖疾风步的专注点

疾风步同时赋予持续到回合结束的飞行与游泳速度，使武僧可跨越复杂地形。

实现与校验：

- 只在该次疾风步后生效；回合结束清除；飞行中失去速度时处理坠落。

### 17级：元素化身 Elemental Epitome

- 特性 ID：`monk-elements-elemental-epitome`
- 动作或触发：激活元素协调及使用疾风步时
- 资源与恢复：沿用相关专注点

获得多种元素抗性；元素协调的攻击更强，疾风步还会在移动经过敌人附近时造成元素伤害。

实现与校验：

- 抗性不叠加；每个敌人每回合受移动伤害次数受限；读取当前伤害类型。
