# 武僧（Monk）— 5e-2014

- 职业 ID：`class-2014-monk`
- 职业介绍：以气驱动的徒手武斗家：武艺骰让徒手与武僧武器不依赖装备，无甲防御提供 AC，气可换疾风连击、闪避与疾行。适合偏好高机动近战与控制节奏的玩家。
- 主要属性：敏捷、感知（5e 不全书「快速建卡」：最高属性分配给敏捷，次高分配给感知）
- 子职选择：3级
- 属性提升/专长：4、8、12、16、19级
- 当前状态：1—20级选择时间线已实现

玩家在1级选择2项职业技能及一种工具或乐器，3级选择宗派。气、武艺、反射闪避、百病不侵等自动能力不要求重复确认。

派生计算已支持 d8 生命骰、力量/敏捷豁免、敏捷与感知无甲防御、按等级提高的无甲移动以及敏捷攻击路线。
