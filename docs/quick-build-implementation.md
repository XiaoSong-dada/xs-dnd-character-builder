# 快速车卡实施状态

## 当前规则基线

正式应用当前只支持 `5e-2014`，目标为 1—20 级单职业移动端车卡。界面不显示规则版本开关，也不把 2024 内容作为兼容选项。旧 `5e-2024` 草稿从 v1 存储中只读隔离，可原样导出，不会自动转换或删除。

## 已完成纵向切片

- 12 个 2014 基础职业可浏览并参与玩法推荐；推荐只改变排序与徽标，不限制选择。玩法偏好与职业推荐已数据化：6 项偏好定义集中于 `rules/data/preferences-2014.ts`（偏好 ID 与草稿兼容），12 个职业带 `playStyleTags` 玩法标签；推荐引擎（`rules/recommend.ts`）按"关联属性 ∩ 主要属性"与"关联标签 ∩ 玩法标签"逐偏好生成可解释原因，`score` 只排序、`status` 不参与评分；第 2 步"当前推荐方向"与第 3 步排序实时一致，第 3 步职业成长速览由规则数据推导（生命骰、施法起始等级、子职等级、检查点），种族/背景推荐理由从属性加值与技能检查点推导，无职业特判。
- 9 个核心种族、对应子种族、13 个背景和 5 个正式背景变体可自由组合。
- 变体人类标记为“2014 可选规则”，并生成 1 级专长检查点。
- 属性来源按“基础值 → 种族 → 子种族 → 最终值”计算。
- 标准数组、27 点购点和自定义属性分别校验。
- 10 级战斗大师战士时间线覆盖职业技能、战斗风格、3 级子职与战技、4/6/8 级属性提升或专长、7/10 级新增战技；不存在武器精通。
- 野蛮人、武僧、游荡者已接入1—20级2014选择时间线、职业装备、豁免、无甲防御/移动或专精派生。
- 圣武士与游侠已接入1—20级选择时间线、职业装备、2级半施法、准备/已知法术校验，以及法术攻击和法术豁免 DC 来源。
- 法师已接入戏法、法术书、准备法术三层校验；邪术师已接入戏法、已知契约法术、宗主、祈唤与契约恩赐检查点。
- 独立法术步骤由 `SpellcastingConfig` 驱动，当前支持 `prepared`、`known`、`spellbook` 与 `pact` 四种模式；角色卡法术页签按环级分组完整展示已选法术（戏法、已准备/已掌握各环），法师额外展示法术书区块并标注"在书中/已准备"状态，计数复用规则层纯函数。
- 角色卡候选法术：`prepared`（牧师/德鲁伊/圣武士）与法师展示"可选未选"候选池（`rules/spellcasting.ts` 的 `getSpellCandidates` 派生）；角色卡可直接点击"准备/取消准备"切换已准备列表（受准备上限约束、满额禁用），写回 `SpellSelections`；`known`/`pact` 职业无候选（2014 规则平时不可更换）。
- 法术效果展开：`SpellRule` 新增 `description` 原创中文效果摘要字段，**全部 489 条法术（`basic-rules-2014` 361 + `xgte-2017-index` 95 + `tcoe-2020-index` 33）均已登记原创摘要**（施法时间/射程/持续时间/效果要点，版权合规转述）；新增通用可展开卡片 `components/ui/ExpandableOptionCard.vue`（右侧箭头按钮展开/收起、双击卡片展开并抑制选择、单击主体=选择、250ms 双击判定、`aria-expanded`/`aria-controls` 键盘可达、操作位 div 包裹 + 按钮固定高度）；**展开视觉即 `ExpandableOptionCard` 设计语言**（grid+overflow 容器、透明主按钮 + `›` 窄箭头、title-line 徽标位、单行省略摘要、dashed 分隔 + 与卡片同色展开区 + 标题行）；车卡施法步骤（戏法/法术书/按环分组）与角色卡法术页签（已选/法术书/候选池全部区块）的法术条目均接入展开；车卡职业步骤（第 3 步）的职业卡片同样复用 `ExpandableOptionCard` 展示"职业成长"速览展开（原页面私有组件 `ClassOptionCard` 已删除，职业页展开视觉与法术/种族/装备完全一致）。
- 12 个职业的 2014 起始装备分支、13 个背景固定装备与正式变体替换已接入；冒险套组会展开为具体物品和数量，护甲、盾牌与主武器提供可调整的推荐穿戴。
- 12 个职业的 114 项子职索引全部登记（2 项 DM 专用除外）；112 个玩家可用子职已按纵向切片接入：等级特性注册表、子职选择与互斥校验、子职派生钩子；未核验的具体效果保持 `index-only`。
- 子职特性界面：时间线选中子职后展示其等级特性列表；`requiresChoice` 特性（图腾/猎人/战技等）以 `subclass-feature` 检查点提供选择并持久化；角色卡"能力"页签新增"子职特性"区块；首批可核验派生（龙族血脉 AC/HP）已接入 `derive`。
- 2014 草稿已升级为 schema v3，物品栏记录数量、来源与装备数量；v2 草稿会保留旧物品并要求重新确认职业装备。
- 草稿保存、刷新恢复、JSON 导入导出、规则校验、依赖失效保留和角色卡预览已经接通。
- 角色卡导出：角色卡页底部「导出」弹层菜单提供 PDF / XLSX / JSON 三项。PDF 为自绘中文打印版面（`CharacterPrintSheet.vue`，Teleport 到 body，`@media print` + `window.print()` 输出 A4，`afterprint` 自动关闭）；XLSX 为 exceljs 自生成自动卡（`services/export-xlsx.ts`，动态 import 独立分包，中文工作表、冻结前两行）；JSON 复用 `CharacterJsonService.downloadDraft`。三种导出的数据统一来自 `features/character-export/build-export-data.ts` 同一份组装（数值全部来自 rules 派生，保证与页面一致）；导出不持久化到草稿。
- 车卡编辑流程与最终角色卡顶部可直接返回草稿首页；退出只关闭当前活动草稿，保留全部内容和当前步骤，之后可继续编辑。
- 首页角色条第三段信息分级展示：完成态显示职业名；进行中已选职业显示"职业 · 第N步"；未选职业显示"第N步 · 步骤名"（步骤文案来自公共 `STEP_META`，不再裸显 `currentStep` 英文 ID）。
- 主页站点信息：`src/config/site.ts` 为唯一读取 `import.meta.env` 的模块（`VITE_AUTHOR_NAME`/`VITE_GITHUB_URL`/`VITE_AUTHOR_TAGLINE`/`VITE_APP_VERSION`，可选）；首页 hero 底部渲染署名行"由 X 制作 · GitHub · v版本"，全部未配置时隐藏；模板见 `app/.env.example`。
- Docker 部署：`docker-compose.yml` 将根 `.env` 的 `VITE_*` 经 `build.args` 传入，`app/Dockerfile` builder 阶段 ARG/ENV 注入 `pnpm build`（Vite 构建期替换，nginx 运行时无需变量）；根 `.env.example` 为部署模板。
- 角色完成后支持升级/降级与重新编辑：角色卡提供入口（草稿首页角色条仅保留打开与删除，避免拥挤），等级调整弹窗支持 1—20 任意跳级并实时预览影响摘要（新增待补 / 将失效 / 需复查）；确认后升级自动跳转时间线补全新增检查点，降级作废超限选择（保留记录并标记失效）并给出针对性复查清单（熟练加值、属性提升/专长次数、战技数量、已知法术上限、子职特性、生命值上限）；存在失效或未完成检查点时角色卡显示"待补全"徽标；"重新编辑"一键进入车卡流程并智能定位到需处理步骤（否则进入属性步骤）。
- 种族与装备效果展开：`RaceRule` 新增 `description` 原创中文介绍（19 条种族/子种族全部登记，覆盖体型/速度/感官/语言/特性）；`EquipmentRule` 新增 `damageDice`/`damageType`（37 条武器登记伤害骰/类型/特性），全部 136 条装备 description 补齐（护甲 AC/力量需求/隐蔽劣势、工具用品用途）；车卡起源步骤（种族/子种族）、起始装备步骤（分组选项展开装备清单 + pick 行展开详情，`−/＋` 数量控件保留在操作位）与角色卡物品页签（条目化展开）均复用 `ExpandableOptionCard` 展开样式，与法术展开体验一致；背景不展开（另行立项）。
- HP、AC、先攻、熟练加值和攻击加值由纯函数派生并保留来源。

商业规则效果尚未核验的专长和战技保持 `index-only`。它们可用于预览，但会产生资料完整性警告。
