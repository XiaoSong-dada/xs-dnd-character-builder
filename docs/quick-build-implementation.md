# 快速车卡实施状态

## 当前规则基线

正式应用当前只支持 `5e-2014`，目标为 1—20 级单职业移动端车卡。界面不显示规则版本开关，也不把 2024 内容作为兼容选项。旧 `5e-2024` 草稿从 v1 存储中只读隔离，可原样导出，不会自动转换或删除。

规则层已为 2024 做好准备：双版本仓库（`rules/repositories.ts`）、草稿 schema v8 与两版共存（B03）、75 条 2024 专长目录及授予／前置／复选／属性上限能力（B04）、391 条法术目录与带法术专长（B05）、16 背景／10 物种／8 血统与语言标准表、背景属性分配（B06）均已接入并测试；背景工具／装备 ID 与 2024 职业时间线仍待 B07／B08 装配，因此界面入口保持关闭。
