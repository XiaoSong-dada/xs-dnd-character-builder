# 警觉（Alert）

- 稳定 ID：`feat-2014-alert`
- 规则集：`5e-2014`
- 类别：2014 专长，不使用 2024 专长类别
- 前置条件：无
- 可重复：否
- 来源：2014 Player’s Handbook
- 内容边界：商业规则内容，仅记录机械摘要、实现边界与官方入口
- 返回：[专长总索引](../../../dnd-feats.md)

## 定位与获得方式

2014 警觉代表角色长期保持戒备并能迅速应对危险。战役必须启用 2014 专长可选规则，角色才能在属性值提升等规则允许的时点选择它；变体人类等来源也可以在满足规则时授予 1 级专长。

获得时必须确认：

- 角色规则集为 `5e-2014`。
- 当前专长来源允许选择任意满足前置条件的 2014 专长。
- 角色尚未拥有 `feat-2014-alert`。

## 机械摘要

| 效果 | 稳定效果 ID | 摘要 |
| --- | --- | --- |
| 先攻强化 | `feat-2014-alert-initiative-bonus` | 为先攻检定提供固定的 `+5` 加值 |
| 保持戒备 | `feat-2014-alert-conscious-surprise-immunity` | 角色保持清醒时不会陷入突袭状态 |
| 应对隐匿攻击 | `feat-2014-alert-unseen-attacker-defense` | 敌人不能仅因角色看不见它而在攻击该角色时获得优势 |

## 实现与校验

- 固定 `+5` 是专长修正，不是熟练加值，也不随角色等级变化。
- “保持清醒”是防止突袭效果的必要条件；角色失去意识时不能继续应用该项保护。
- 对隐匿攻击者的防护只移除“攻击者未被角色看见”这一来源产生的优势；攻击者若还拥有其他独立优势来源，不能把所有优势一并取消。
- 本专长没有资源次数，也不需要休息恢复。
- 角色卡应分别显示先攻修正、突袭处理和未见攻击者处理，不能把三项效果压成一个不可解释的总数值。

## 选择提示

适合希望稳定提高首轮行动顺序、降低遭伏击风险的角色。它与敏捷较高的角色配合良好，但不提高敏捷属性，也不提供任何先攻交换能力。

## 兼容边界

- 不使用 [2024 警觉](../../5e-2024/origin/alert/alert.md) 的先攻熟练或交换先攻规则。
- 2014 与 2024 警觉不能因同名而共享 ID、合并效果或同时计算。
- 将旧角色转入 2024 时必须由 DM 决定保留旧专长、改用新版专长或建立其他兼容映射。
