# 警戒（Alert）

- 稳定 ID：`feat-2024-alert`
- 规则集：`5e-2024`
- 类别：起源专长（Origin Feat）
- 前置条件：无
- 可重复：否
- 来源：2024 Free Rules、SRD 5.2.1
- 内容边界：开放规则内容，采用项目原创表述整理到实现级
- 返回：[专长总索引](../../../../dnd-feats.md)

## 定位与获得方式

警戒适合希望更早行动并调整队伍出手顺序的角色。它可能由固定出身授予，也可以在物种、职业或其他规则明确给予“一个起源专长”时选择。

获得时必须确认：

- 专长来源允许取得起源类别，而不是仅允许通用、战斗风格或传奇恩惠。
- 角色尚未拥有 `feat-2024-alert`。
- 固定授予警戒的出身不需要再次建立第二份相同专长，只记录不同来源指向同一个已取得专长。

## 效果详解

### 先攻熟练

- 效果 ID：`feat-2024-alert-initiative-proficiency`
- 类型：先攻检定修正
- 资源与恢复：无
- 效果：角色进行先攻检定时，将熟练加值加入结果。
- 实现与校验：熟练加值来自角色等级；不能因其他来源也提供“先攻熟练”而重复加入多次。该效果是先攻检定来源，不改变敏捷属性或敏捷调整值。

1 级角色的熟练加值通常为 `+2`，因此基础计算为：

```text
先攻 = 敏捷调整值 + 熟练加值 + 其他允许叠加的修正
```

### 交换先攻

- 效果 ID：`feat-2024-alert-initiative-swap`
- 类型：战斗开始时的即时选择
- 触发：角色已经掷出先攻，但战斗顺序尚未开始执行。
- 目标：同一场战斗中的一名自愿盟友。
- 资源与恢复：不消耗长期资源；每次战斗开始时根据触发条件决定。
- 效果：交换双方本次战斗的先攻结果。
- 限制：角色或目标处于失能状态时不能交换；目标必须明确同意。
- 实现与校验：交换的是本场战斗中的先攻结果或排序位置，不是双方的敏捷值、熟练加值或永久先攻修正。交换完成后不应再次触发新的先攻检定。

## 选择与显示提示

- 新玩家提示：警戒不会让角色自动获得突袭免疫；这是 2014 同名专长的旧版效果，不能混入本文件。
- 角色卡应把熟练加值显示为“来源：警戒”，并把交换先攻作为战斗开始时的可用操作提示。
- 出身和人类物种都可能为同一角色提供专长来源，但同一个警戒专长不能重复取得；若规则允许另选起源专长，应进入重复处理流程。

## 兼容边界

- 不使用 [2014 警觉](../../../5e-2014/alert/alert.md) 的固定先攻加值、突袭限制或对隐匿攻击者的旧版处理。
- 跨版本采用必须由 DM 明确许可，并建立独立映射；不能同时叠加两个版本的警觉效果。
