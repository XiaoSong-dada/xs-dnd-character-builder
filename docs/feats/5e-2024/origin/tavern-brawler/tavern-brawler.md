# 酒馆斗殴者（Tavern Brawler）

- 稳定 ID：`feat-2024-tavern-brawler`
- 规则集：`5e-2024`
- 类别：起源专长（Origin Feat）
- 前置条件：无
- 可重复：否
- 来源：2024 Player’s Handbook
- 内容边界：商业规则内容，仅记录机械摘要、实现边界与官方入口
- 返回：[专长总索引](../../../../dnd-feats.md)

## 定位与获得方式

酒馆斗殴者强化徒手打击和临时武器使用，并允许在攻击动作中把命中的敌人推开。2024 水手出身固定授予该专长。

## 机械摘要

| 效果 | 稳定效果 ID | 摘要 |
| --- | --- | --- |
| 强化徒手伤害 | `feat-2024-tavern-brawler-enhanced-unarmed-strike` | 徒手打击造成伤害时使用 `1d4 + 力量调整值` |
| 徒手伤害重掷 | `feat-2024-tavern-brawler-damage-rerolls` | 徒手打击伤害骰出现 1 时可以重掷并使用新结果 |
| 临时武器熟练 | `feat-2024-tavern-brawler-improvised-weaponry` | 获得临时武器熟练 |
| 推离 | `feat-2024-tavern-brawler-push` | 攻击动作中的徒手打击命中并造成伤害时，可将目标推开5尺 |

## 实现与校验

- 强化徒手伤害是一种徒手打击伤害选项，不与其他基础徒手伤害公式直接相加。
- 伤害重掷只处理徒手打击的伤害骰；采用新结果，即使再次掷出 1。
- 临时武器熟练影响攻击检定是否加入熟练加值，不自动定义每件环境物品的伤害骰和武器属性。
- 推离效果每个角色回合只能使用一次，且必须是角色自己回合内攻击动作的一部分。
- 推离和徒手打击的擒抱、推撞等其他选项必须按动作规则区分，不能一次命中自动附送所有效果。
- 不能套用 2014 酒馆斗殴者的属性提升、擒抱奖励或旧版临时武器处理。

## 选择提示

适合经常徒手战斗、利用环境物品或需要调整敌人位置的角色。武僧等拥有其他徒手伤害公式的角色应选择适用的一种基础公式，而不是把骰值叠加。
