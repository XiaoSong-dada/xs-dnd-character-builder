# 魔法学徒（Magic Initiate）

- 稳定 ID：`feat-2024-magic-initiate`
- 规则集：`5e-2024`
- 类别：起源专长（Origin Feat）
- 前置条件：无
- 可重复：是，但每次必须选择不同的法术列表
- 来源：2024 Free Rules、SRD 5.2.1
- 内容边界：开放规则内容，采用项目原创表述整理到实现级
- 返回：[专长总索引](../../../../dnd-feats.md)

## 定位与获得方式

魔法学徒让角色从牧师、德鲁伊或法师法术列表中学习少量法术。侍僧、向导和学者出身分别固定提供对应列表的魔法学徒，其他来源允许自选起源专长时可以自行决定列表。

## 必选项

每次取得专长时必须完成：

1. 选择一个法术列表：牧师、德鲁伊或法师。
2. 从该列表选择两项戏法。
3. 从同一列表选择一项 1 环法术。
4. 从智力、感知或魅力中选择本专长法术的施法属性。

保存字段至少包括：

```text
spellListId
cantripIds[2]
level1SpellId
spellcastingAbility
```

## 法术与资源

| 效果 | 稳定效果 ID | 规则 |
| --- | --- | --- |
| 两项戏法 | `feat-2024-magic-initiate-cantrips` | 学会所选列表中的两项不同戏法 |
| 1环法术 | `feat-2024-magic-initiate-level-1-spell` | 该法术始终视为已准备 |
| 免费施放 | `feat-2024-magic-initiate-free-cast` | 每次长休前可免费施放所选1环法术一次 |
| 法术替换 | `feat-2024-magic-initiate-spell-change` | 升级时可按规则替换一项所选法术 |

- 戏法按正常戏法规则施放，不消耗“免费施放”次数。
- 1 环法术的免费施放次数在长休后恢复。
- 若角色拥有合适法术位，也可以使用法术位施放该 1 环法术。
- 免费次数、已准备状态和法术位必须分别记录，不能合并成一个布尔字段。

## 重复取得

- 该专长最多可按三个不同列表分别取得。
- 再次取得时，`spellListId` 不能与已有记录重复。
- 每次取得拥有独立的戏法、1 环法术、施法属性和免费施放资源。
- “牧师魔法学徒”“德鲁伊魔法学徒”“法师魔法学徒”是同一专长的不同选择记录，不应建立三个互不相关的专长定义。

## 升级替换

角色获得新等级时，可以把本专长选择的一项法术替换为同一法术列表、同一环阶的其他法术。替换必须保留所属专长实例，不能把牧师列表法术换成法师列表法术。

## 实现与校验

- 两项戏法必须不同，且所有法术必须来自所选列表和正确环阶。
- 施法攻击加值与豁免 DC 使用玩家选择的施法属性。
- 获得该专长不会自动提供法器、法术书、职业施法特性或额外法术位。
- 出身固定列表时必须锁定正确列表，但仍需完成具体法术和施法属性选择。
