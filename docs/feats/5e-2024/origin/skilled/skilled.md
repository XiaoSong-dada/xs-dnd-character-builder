# 熟练（Skilled）

- 稳定 ID：`feat-2024-skilled`
- 规则集：`5e-2024`
- 类别：起源专长（Origin Feat）
- 前置条件：无
- 可重复：是
- 来源：2024 Free Rules、SRD 5.2.1
- 内容边界：开放规则内容，采用项目原创表述整理到实现级
- 返回：[专长总索引](../../../../dnd-feats.md)

## 定位与获得方式

熟练让角色自由组合三项技能或工具熟练。2024 江湖骗子、贵族和书记员出身固定授予该专长，其他允许自选起源专长的来源也可以选择它。

## 必选项

每次取得专长时选择三项：

- 每项可以是技能或工具。
- 技能与工具可以任意组合，例如三项技能、两项技能加一项工具，或三项工具。
- 同一次取得中的三个选择必须互不重复。
- 保存时使用带类型的选择记录，不能只保存显示名称。

示例结构：

```text
choices:
  - type: skill
    id: perception
  - type: skill
    id: stealth
  - type: tool
    id: thieves-tools
```

## 重复取得

- 该专长可以取得多次，每次新增三项选择。
- 每次取得都要建立独立实例和来源。
- 普通熟练不能因为多个来源重复而叠加熟练加值；已经熟练的项目应提示重复，并按当前规则或 DM 决定是否改选。
- 该专长只提供普通熟练，不自动升级为专精。

## 实现与校验

- 候选只包括当前规则集定义的技能和工具；武器、护甲、语言和豁免熟练不能混入。
- 创建流程必须在三个有效选择全部完成后才视为专长配置完成。
- 显示时逐项标明“来源：熟练专长”，并保留出身、职业等其他来源。
- 专长重复取得时不能覆盖前一实例的选择。

## 选择提示

适合补足职业技能、探索能力或工具用途的角色。选择前应检查职业和出身已经提供的熟练，减少无效重复。
