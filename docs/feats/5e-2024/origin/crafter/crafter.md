# 巧匠（Crafter）

- 稳定 ID：`feat-2024-crafter`
- 规则集：`5e-2024`
- 类别：起源专长（Origin Feat）
- 前置条件：无
- 可重复：否
- 来源：2024 Player’s Handbook
- 内容边界：商业规则内容，仅记录机械摘要、实现边界与官方入口
- 返回：[专长总索引](../../../../dnd-feats.md)

## 定位与获得方式

巧匠适合希望扩展制造能力、降低日常采购成本并在休息时制作临时物品的角色。2024 工匠出身固定授予该专长，其他明确给予起源专长的规则也可以选择它。

## 必选项

取得专长时，从工匠工具中选择三个不同的工具熟练：

- 每个选择保存工具 ID、显示名和来源 `feat-2024-crafter-tool-proficiency`。
- 三项必须互不重复。
- 与其他来源重复时不能重复累计熟练加值；界面仍应保留全部来源并进入重复熟练处理。

## 机械摘要

| 效果 | 稳定效果 ID | 摘要 |
| --- | --- | --- |
| 工具熟练 | `feat-2024-crafter-tool-proficiency` | 获得三项不同的工匠工具熟练 |
| 采购折扣 | `feat-2024-crafter-discount` | 购买非魔法物品时按规则获得折扣 |
| 快速制作 | `feat-2024-crafter-fast-crafting` | 长休后使用合适工具制作一件规则表内的临时物品 |

## 实现与校验

- 采购折扣为符合条件的非魔法物品价格降低 20%；不能自动用于魔法物品、服务、雇佣、生活费用或规则未涵盖的交易。
- 折扣后的价格应由基础价格派生计算，并保留“工匠”作为修正来源；不能直接改写物品基础价格。
- 快速制作必须校验角色具备所需工具熟练和实际工具，并且目标位于该专长允许的快速制作清单。
- 快速制作物不是永久库存来源；其有效期应单独记录，并在下一次符合规则的长休节点失效。
- 制作规则与普通停工期制造是两条不同流程，不能用快速制作绕过普通制造的材料、时间或工具要求。

## 选择提示

适合重视工具玩法、旅行补给和装备准备的角色。该专长不会自动提供制造所有物品的配方，也不会让魔法物品获得折扣。
