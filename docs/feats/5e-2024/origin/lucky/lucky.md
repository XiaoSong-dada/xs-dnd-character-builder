# 幸运（Lucky）

- 稳定 ID：`feat-2024-lucky`
- 规则集：`5e-2024`
- 类别：起源专长（Origin Feat）
- 前置条件：无
- 可重复：否
- 来源：2024 Player’s Handbook
- 内容边界：商业规则内容，仅记录机械摘要、实现边界与官方入口
- 返回：[专长总索引](../../../../dnd-feats.md)

## 定位与获得方式

幸运提供随熟练加值增长的幸运点，用于改善自己的 d20 检定或干扰针对自己的攻击。2024 商人和流浪者出身固定授予该专长。

## 资源

| 字段 | 规则 |
| --- | --- |
| 资源 ID | `feat-2024-lucky-luck-points` |
| 最大值 | 角色熟练加值 |
| 恢复 | 完成长休后恢复至最大值 |
| 1级常见最大值 | 2 |

幸运点最大值是派生值，不能在角色升级后继续使用旧的固定上限。

## 机械摘要

| 效果 | 稳定效果 ID | 摘要 |
| --- | --- | --- |
| 幸运优势 | `feat-2024-lucky-advantage` | 消耗一点，使自己进行的 d20 检定具有优势 |
| 幸运干扰 | `feat-2024-lucky-disadvantage` | 消耗一点，使针对自己的攻击掷骰具有劣势 |

## 实现与校验

- 使用时机必须位于对应掷骰过程内，不能在结果已经结算后倒退消耗。
- 优势和劣势仍使用通用叠加规则：多个优势不会产生额外骰，优势与劣势同时存在时互相抵消。
- 幸运干扰只作用于以该角色为目标的攻击掷骰，不能用于任意敌人的豁免、属性检定或攻击其他目标的掷骰。
- 每次使用消耗一点幸运点；资源为 0 时应禁用操作并提示需完成长休。
- 不使用 2014 幸运专长的“三枚幸运点和额外 d20 选择”流程。

## 选择提示

幸运适合所有职业，尤其适合需要保护关键检定或降低敌人命中机会的角色。由于点数随熟练加值增长，角色升级后要重新计算上限。
