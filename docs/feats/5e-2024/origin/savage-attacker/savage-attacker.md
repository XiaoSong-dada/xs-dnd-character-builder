# 凶蛮攻击者（Savage Attacker）

- 稳定 ID：`feat-2024-savage-attacker`
- 规则集：`5e-2024`
- 类别：起源专长（Origin Feat）
- 前置条件：无
- 可重复：否
- 来源：2024 Free Rules、SRD 5.2.1
- 内容边界：开放规则内容，采用项目原创表述整理到实现级
- 返回：[专长总索引](../../../../dnd-feats.md)

## 定位与获得方式

凶蛮攻击者提高武器命中后的伤害稳定性。2024 士兵出身固定授予该专长，其他明确给予起源专长的规则也可以选择它。

## 效果

- 效果 ID：`feat-2024-savage-attacker-weapon-damage-choice`
- 触发：角色用武器命中目标并准备掷该武器的伤害骰。
- 频率：每个角色回合一次。
- 结果：将该武器的伤害骰掷两组，从中选择一组用于此次命中。
- 资源与恢复：不使用长期资源；“每回合一次”在角色下个回合开始时重置。

## 实现与校验

- 两组都是完整的武器伤害骰，不是先掷一组后决定“重掷”。
- 只比较和选择武器自身的伤害骰；属性调整值和其他固定修正只在选定后加入一次。
- 偷袭、神圣打击、法术附伤、暴击额外骰等非武器自身伤害骰不能默认并入两组重复掷骰。
- 必须由玩家选择采用哪组结果，不强制自动采用较高值。
- 每回合使用状态按角色回合跟踪，不按战斗轮或每次攻击重置。
- 非武器攻击、仅造成固定伤害的效果和未命中的攻击不能触发。

## 选择提示

适合经常用武器攻击、武器伤害骰较大的角色。它改善单次武器伤害的稳定性，但不会提供额外攻击，也不会提高攻击命中率。
