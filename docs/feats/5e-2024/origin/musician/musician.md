# 音乐家（Musician）

- 稳定 ID：`feat-2024-musician`
- 规则集：`5e-2024`
- 类别：起源专长（Origin Feat）
- 前置条件：无
- 可重复：否
- 来源：2024 Player’s Handbook
- 内容边界：商业规则内容，仅记录机械摘要、实现边界与官方入口
- 返回：[专长总索引](../../../../dnd-feats.md)

## 定位与获得方式

音乐家提供多项乐器熟练，并能在休息结束时以演奏鼓舞盟友。2024 艺人出身固定授予该专长。

## 必选项

取得时选择三种不同的乐器：

- 每项保存乐器 ID 和来源 `feat-2024-musician-instrument-training`。
- 三种乐器必须互不重复。
- 与其他来源重复时不重复累计熟练加值，但保留来源记录并进入重复熟练处理。

## 机械摘要

| 效果 | 稳定效果 ID | 摘要 |
| --- | --- | --- |
| 乐器训练 | `feat-2024-musician-instrument-training` | 获得三种自选乐器熟练 |
| 激励演奏 | `feat-2024-musician-encouraging-song` | 短休或长休结束时，为一定数量可听见演奏的盟友提供英雄激励 |

## 激励演奏

- 触发时机：完成短休或长休时。
- 需要角色实际使用一件已选择的乐器进行演奏。
- 可选择的盟友数量上限等于角色熟练加值。
- 目标必须位于规则允许的距离内并能听见演奏。
- 每个合格目标获得英雄激励；已经拥有英雄激励的目标不能非法叠加第二份。

实现时应保存本次休息、所用乐器和目标列表。目标数量上限随熟练加值派生，不能固定为 1 级时的两名盟友。

## 选择提示

适合希望在休息后稳定为队伍准备英雄激励的角色。该专长不会自动提供吟游激励骰、施法能力或吟游诗人职业特性。
