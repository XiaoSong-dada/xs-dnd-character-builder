# D&D 5e 2014 快速车卡辅助

一个移动端优先的 D&D 5e 2014 车卡 Web 应用，通过分步引导、自动计算和规则校验，帮助新玩家快速创建并使用角色卡。

## 当前支持

- D&D 5e 2014 规则集
- 1—20 级单职业角色
- 标准数组、27 点购点和自定义属性
- 职业推荐、种族与背景、升级时间线、装备及法术配置
- 角色数值自动计算与选择合法性校验
- 浏览器本地保存，并支持 PDF、XLSX、JSON 与完整角色包（ZIP，含头像/立绘）导出
- 可选角色头像与立绘：上传、焦点调整、从立绘生成头像，并随完整角色包跨设备迁移

当前暂不支持 2024 规则编辑、多职业、云同步和 DM 房规编辑器。

## v1.1.1

- 弹窗标题栏固定优化：编辑角色形象、调整等级等长内容弹窗的标题与关闭按钮固定在顶部，仅内容区滚动，不再随内容滚出视野。

## v1.1.0

- 新增可选角色头像与立绘：身份步骤和角色卡编辑模式可上传、调整焦点、从立绘生成头像，并同步展示在车卡首页、角色卡与跑团助手。
- 草稿升级为 schema v7，图片 Blob 独立保存在 IndexedDB；新增含头像/立绘的 ZIP 完整角色包导入导出，支持跨设备迁移，普通 JSON 导出不含图片。
- 支持车卡首页与跑团助手直接导入完整角色包；图片缺失或加载失败时自动隐藏，不显示占位图。


## 快速开始

项目代码位于 `app`，建议使用 Node.js 22 和 pnpm 10。

```sh
cd app
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

测试与构建：

```sh
cd app
pnpm test:run
pnpm build
```

## Docker 部署

复制环境变量示例并启动服务：

```sh
cp .env.example .env
docker compose up -d --build
```

默认访问地址为 `http://localhost:8080`，可通过根目录 `.env` 中的 `APP_PORT` 修改端口。
